## 1. โครงสร้าง "1 รายการสินค้า" (หัวใจ — จากใบจริง)
```
{N} {ประเภทงาน} ({ตำแหน่ง}) {(รุ่น/ชุด)?}              | 1 ชุด | {ราคาหัวข้อ} | {ราคาหัวข้อ}
      - {คำบรรยายบาน} ( มีมุ้ง... ) พร้อมกระจกติดตาย...      ← บล็อก A
      OPTION (1) : หากลูกค้าต้องการเปลี่ยนเป็น ... ราคาลดลง 7,000 บาท   ← บล็อก B (0..n)
      OPTION (2) : ...
      หมายเหตุ                                              ← บล็อก B' (optional)
      - ราคาที่เสนอรวม.../ไม่รวม...
      รายละเอียดงาน                                  | 1 ชุด | {ราคาจริง} | {ราคาจริง}   ← บล็อก C + ราคาที่ 2
      - อลูมิเนียม สี{...}
      - กระจก{...} หนา {x} มม.
      - มุ้ง{...} ผ้า{...}
      - {วัสดุเสริม เช่น สมาร์ทบอร์ด/ฉนวน/หลังคา ...}
```
**จุดผิดง่าย:**
- หัวข้อขึ้นด้วย **ประเภทงาน (ประตู/หน้าต่าง/กั้นห้อง) + (ตำแหน่ง)** แล้วต่อ tag รุ่นท้าย `(ชุดยูโร)` `(รุ่น SlimLux)`
- **ราคา = 1 ค่าต่อรายการ** อยู่แถวเดียวกับรายการ (ปกติ) · ถ้าข้อเดียวมีหลายราคา = กลุ่มแยกราคาสินค้าย่อย (group split, ฟีเจอร์เดิม) ทุกราคาบวกเข้า subtotal — ดู ข้อ 7 Q3
- จำนวนเขียน **"1 ชุด"** (บางงาน "1 ครั้ง"=ค่าเดินทาง)
- ราคา 2 ทศนิยม + comma เสมอ (`41,000.00`)

## 2. รายละเอียดงาน (สเปกวัสดุ) — จัดแบบ "ต่อชิ้นส่วน"
ใต้ label **"รายละเอียดงาน"** ทุกบรรทัดขึ้นด้วย "- " เรียงลำดับ:
1. **- อลูมิเนียม สี{...}** (สี+ลายอยู่บรรทัดเดียวกับวัสดุ เช่น "อลูมิเนียมลายไม้ สีไวท์โอ๊ค")
2. **- กระจก{ชนิด} หนา {x} มม.** (ความหนาติดกับกระจก เช่น "กระจกอินซูเลทใส 5 + air gap 8 + ใส 5 มม.")
3. **- มุ้ง{ชนิด} ผ้า{สี}**
4. **- {วัสดุเสริม}** บรรทัดละชิ้น พร้อมขนาด/สี/รุ่น
- เงื่อนไขอยู่ใต้ label **"หมายเหตุ"** แยกจาก "รายละเอียดงาน"
> หมายเหตุ: ที่พี่นัทเรียก "หมวด วัสดุ/สีอลู/สีกระจก/ความหนา" = ใบจริงรวมสี+ความหนาไว้กับวัสดุชิ้นนั้นๆ (ต่อบรรทัด) ไม่ได้แยก 4 หัวข้อ — ยึดแบบใบจริง (ดู ข้อ 7 Q4)

## 3. คอลัมน์ตาราง (4 คอลัมน์)
`# | รายละเอียด | จำนวน | ราคาต่อหน่วย | ยอดรวม`
- เลขข้อชิดซ้าย · บล็อกข้อความยาวอยู่คอลัมน์ "รายละเอียด"

## 4. หัวบิล + 5. ท้ายบิล — ❌ คงเดิม ไม่แก้
- หัวบิล / วันที่ / รูปแบบยอดรวม / ท้ายบิล = **ใช้ของเดิมที่มีอยู่** (พี่นัทบอกอ่านง่ายอยู่แล้ว)
- งานนี้ไม่แตะส่วนนี้ — แก้เฉพาะรายละเอียดสินค้า (ข้อ 1, ข้อ 2)

## 6. งานผสมหลายชนิด (กั้นห้อง/หลังคา)
- 1 ข้อแตกเป็น **ด้าน A, B, C … (ถึง M ได้)** แต่ละด้าน "- ด้าน X {งาน} ( คุณสมบัติ )"

## ★ กฎเพิ่มที่พี่นัทสั่ง (นอกเหนือใบจริง)
- ติดรหัสรุ่น tag **เต็ม** ต่อท้ายชื่อ: **(รุ่น M เซมิยูโร) / (รุ่น L ยูโร) / (รุ่น S สลิม)** + **ตัดคำซ้ำในชื่อทิ้ง**
  - ชื่อมี "เซมิยูโร"/"SMS" → ตัดออก แล้วใส่ "(รุ่น M เซมิยูโร)" เช่น "บานเลื่อน เซมิยูโร" → "บานเลื่อน (รุ่น M เซมิยูโร)"
  - ชื่อมี "ยูโร" → "บานเปิด ยูโร" → "บานเปิด (รุ่น L ยูโร)"
  - ชื่อมี "สลิม" → ตัดออก ใส่ "(รุ่น S สลิม)"
  - ชื่อเป็นโมเดล (X-series/Velora/SlimLux) → **คงชื่อโมเดล + ใส่ tag** เช่น "บานเปิด X-series (รุ่น S สลิม)" · "บานเปิด Velora (รุ่น S สลิม)" ✓ ยืนยันแล้ว
- ตัดตัวเลข spec range ออกจากใบ (เช่น Exhido "0.4-1.1 · H 1.8-3.0")
- **ตัด tag เวอร์ชัน "— Rx.x" ออกจากทุกชื่อสินค้า/ข้อความที่ลูกค้าเห็น** (พบ bug: imp29 ชื่อมี "— R3.2" หลุดออกใบ · ที่ Full-B ข้อ16 บ่นไว้) — เก็บ tag ในคอมเมนต์โค้ดได้
- **บานภายในทุกรุ่น (cat "เลื่อนภายใน" + X-series ทุกหมวด) = ใช้ภายใน ไม่กันน้ำ** (เฟรมล่างเรียบ/รางบนไม่มีรางล่าง) — ระบุในรายละเอียดถ้าจำเป็น ไม่ใช้พื้นที่โดนน้ำ/ภายนอก
- ตรวจสะกดผิดทั้งใบ: บานเฟียม→บานเฟี้ยม, สวงิ→สวิง, เลอืน→เลื่อน, บานเปลอืย→บานเปลือย, มานซิป→ม่านซิป, กนัหอ้ง→กั้นห้อง, อาบนํา→อาบน้ำ, ประตูประตู→ประตู

## 9. รหัสรุ่น M/L/S ต่อสินค้า (⏳ พี่นัทคอนเฟิร์ม)
