🔧 งาน 1 — ไล่หาจุดรก/บั๊กเอง (พบ 2 จุด แก้แล้ว)

① ปุ่มชุดซ้ำ บน+ล่าง → เหลือแถวเดียว

ทุกชุดเดิมมีปุ่ม "+ เพิ่มส่วน" + "+ ช่องแสงติดตาย" ซ้ำ 2 ที่ (บนและล่าง) = รก
แก้: ลบแถวล่าง .set-btns-bot เหลือแถวบนแถวเดียว (ยืนยัน DOM: ปุ่มจาก 2 → 1)

② 🔴 บั๊กร้าย: ปุ่มหลักคลิกไม่ได้ (curly quotes)

ปุ่ม "ส่งเข้าระบบ JR" + พรีวิว + ล้างทั้งหมด เขียนด้วย curly quotes (onclick=”...” แทน onclick="...") → onclick/style พังหมด คลิกไม่ทำงานในเบราว์เซอร์ (มาจากตอน restyle ปุ่ม)
แก้: curly → straight quotes ทั้ง 9 จุด · ยืนยันปุ่มทำงาน
⚠️ บทเรียน: เทส jsdom เดิม "ไม่จับ" เพราะเรียกฟังก์ชันตรง ไม่ได้คลิกปุ่ม → ตรงกับที่พี่นัทบอก "UX ผิดตั้งแต่ต้น"

👀 จุดที่อยากให้พี่นัทรีวิว

  • หน้าตา UI — เปิด preview ดูด้วยตา ว่าปุ่ม/เลย์เอาต์สวย/กดง่ายจริงไหม (โดยเฉพาะปุ่มที่เพิ่งแก้บั๊ก)
  • การกรอกฟอร์ม — ลองกรอกจริงดูว่ายัง "รก/งง" ตรงไหนอีก ชี้จุดมาได้ ผมจัดต่อ (ตอนนี้ตัดปุ่มซ้ำ + ซ่อนช่องราคาเอง + รวมกล่อง option แล้ว)
  • ผลสรุปงาน 2 — ใบออกข้อมูลครบทุกหมวด ไม่พบหมวดที่ขาด · ถ้าพี่นัทเทียบใบจริงแล้วเห็นว่ายังขาด field ไหน บอกตำแหน่งมา ผมเติมให้
