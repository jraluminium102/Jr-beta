## 6. ข้อเสนอแนะ (🟡 ที่ยังไม่เหมือน 100% — ต้องเพิ่ม data/feature)
1. **หัวบิลขวายังขาด 3 ช่อง**: ผู้ขาย / ผู้ติดต่อ / เบอร์โทร — เครื่องคิดราคามีแค่ "ชื่อลูกค้า + วันที่" ต้องเพิ่มช่องกรอกก่อนถึงจะโชว์ได้ (เป็นงานเพิ่ม field)
2. **ที่อยู่ลูกค้าเต็ม** (เลขที่/ตำบล/อำเภอ/จังหวัด/รหัสไปรษณีย์) — ใบจริงมี แต่เครื่องยังไม่มีช่องกรอก → แนะนำดึงจากทะเบียนลูกค้าในแอพ (customer_snapshot มีที่อยู่อยู่แล้ว) เมื่อออกใบผ่านระบบจริง
3. **หัว+ข้อมูลบริษัทซ้ำทุกหน้า + เลขหน้า "หน้าที่ X/Y"** — ใบจริง (ERP) ซ้ำทุกหน้า · ของเราหัวเต็มเฉพาะหน้าแรก (ข้อจำกัด HTML→PDF) แนะนำใช้ `<thead>` ซ้ำ หรือ render ผ่านตัวทำ PDF ที่รองรับ running header
4. **โลโก้**: ใบจริงใช้ "JR. ALUMINIUM" (กรอบโปร่ง) · ของเราเป็น "JR." แดงเอียง — ถ้าต้องการตรง ใช้ไฟล์โลโก้จริง
5. **คำอธิบายสินค้า "- ..." ใบจริงละเอียดกว่า** (เช่น "ประตูอลูมิเนียมลูกฟูกเรียบบานเปิดคู่ ( มีธรณีกันน้ำ )") — ของเราใช้ชื่อ product สั้น → ถ้าต้องการตรงต้องเสริมชื่อบรรยายในตาราง PRODUCTS
6. **OPTION ทางเลือก + หมายเหตุต่อรายการ**: ใบจริงมี "OPTION (1)(2): เปลี่ยนกระจก... ราคาลด X" และหมายเหตุงานรื้อ — ระบบรองรับ (มี groupOptText/หมายเหตุ) แต่ข้อมูลทดสอบยังไม่ได้ใส่
