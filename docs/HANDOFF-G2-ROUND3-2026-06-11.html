🔴 ต้องแก้

R3-1 บานเปิดยูโร: เพิ่มบาน +5,000/บาน (เดิม +14,000 เหมา)

มติ: บานเปิดคู่ยูโร = +5,000 ต่อบานที่เพิ่ม (ไม่ใช่ +14,000 เหมาเมื่อคู่)
  • จุด: L578 casement_euro ... addon:{kind:'door',extra:14000} → เปลี่ยนค่า extra เป็น 5,000
  • จุด: addonCalc (~L975) เดิม panels>=2 ? extra : 0 (เหมา) → ทำเป็น ต่อบาน: extra × (panels-1) (บานที่ 2 เป็นต้นไป บานละ 5,000)
  • เช็คซ้ำ: ยืนยันว่า "/บาน" = บานที่ 2,3,4… บานละ 5,000 (เช่น 3 บาน = +10,000)

R3-2 ช่องกรอกราคาประตูเอง (override) — รอสูตรจำนวนบาน

มติ: จำนวนบาน × ตร.ม. ยังไม่มีสูตร final → ทำช่องกรอกราคาประตูเองไว้ก่อน (เซลล์พิมพ์ราคาถูกได้ทันที) · พอสูตรจริงมาค่อยเปลี่ยนเป็น auto
  • เพิ่ม input "ราคาประตู (กรอกเอง · บาท)" ในออปชั่น "ทำเป็นประตู" ของระแนง (ranae o-doortype ~L2454) + ระแนงเลื่อน bar_slide (o-bsdoor ~L2414)
  • ถ้ากรอก > 0 → ใช้ค่ากรอกแทน basePrice(ประตู) (override) · ถ้าว่าง → ใช้ auto เดิม
  • ใช้ pattern เดียวกับช่อง override ราคา / gatewood ที่มีอยู่แล้ว
  • หมายเหตุในใบ: ราคาประตูตามที่กรอก

R3-4 ราวกันตก imp1–imp6: เปลี่ยนชื่อ + เพิ่มออปชั่น

จุด: L655-660 (ชื่อ) · ใบจริงระบุแค่ "ราวกันตกกระจก" (ไม่แยกต่อเปลือย/ไม่ต่อเปลือยในชื่อ) · ตัด "บันได/ทำยากสุด/(ก)(ข)"
idชื่อใหม่ออปชั่น
imp1ราวกันตกกระจกเฉียง หมุดแปะข้าง + (ออปชั่นกล่อง/ยูอลู) ราวมือจับด้านบนหมุดสแตนเลสสีเงิน
imp2ราวกันตกกระจกเฉียง พร้อมวางยูเหล็ก ครอบอลูรับกระจกล่าง + (ออปชั่นกล่อง/ยู) ราวมือจับบนเลือกสีอลู 3 สี (ขาว/เทา/ดำ)
imp3ราวกันตกกระจกเฉียง พร้อมเสาตั้งและราวจับบนอลูมิเนียมเลือกสีอลู 3 สี
imp4ราวกันตกกระจกตรง หมุดแปะข้าง + (ออปชั่นกล่อง/ยูอลู) ราวมือจับด้านบนหมุดสแตนเลสสีเงิน
imp5ราวกันตกกระจกตรง พร้อมวางยูเหล็ก ครอบอลูรับกระจกล่าง + (ออปชั่นกล่อง/ยู) ราวมือจับบนเลือกสีอลู 3 สี
imp6ราวกันตกกระจกตรง พร้อมเสาตั้งและราวจับบนอลูมิเนียมเลือกสีอลู 3 สี
  • เพิ่มออปชั่น ราวมือจับด้านบน (กล่อง / ยู อลูมิเนียม) — ทุกตัว
  • imp2,3,5,6 (47.2/47.4) เพิ่ม เลือกสีอลู 3 สี (ขาว/เทา/ดำ)
  • imp1,4 (47.1/47.3) ระบุ หมุดสแตนเลสสีเงิน ในรายละเอียด

✅ ยืนยันแล้ว — ไม่ต้องแก้

เรื่องมติ
บานเฟี้ยม จำนวนบานสูตรปัจจุบัน max(พื้นที่×9,000, 15,000×บาน) = บานเยอะ ราคาขึ้น → ถูกต้องแล้ว (พี่นัทยืนยัน "ต้องแพงขึ้น") · ไม่แก้
