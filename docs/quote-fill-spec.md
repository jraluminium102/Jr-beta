## 0. เป้าหมาย
ให้เซลล์กรอก "ตัวเลือกต่อชนิดบาน" ครบ → ข้อความในใบสมบูรณ์ ไม่ตกหล่น ลำดับคำสม่ำเสมอ
- **ต้นฉบับเฟิร์น = ซูเปอร์เซ็ต** (ลิสต์ทุกตัวเลือกที่เป็นไปได้) · **ใบจริงใช้แค่บางส่วน**
- หลักการ: ตัวเลือกที่ใบจริงใช้บ่อย = ทำเป็น control + (บังคับ/เลือก) · ตัวที่ไม่ค่อยใช้ = optional

## 1. โครงสร้าง 1 รายการ (ยึดจากใบจริง)
```
[N] [หัวข้อ: ตำแหน่ง/ห้อง] ([ชุดยูโร])              | จำนวน | ราคา/หน่วย | ยอดรวม
  - [บรรยายชนิดบาน + คุณสมบัติ + (มุ้ง) + พร้อมกระจกติดตาย...]
  - ด้าน A/B/C... (เฉพาะกั้นห้อง/งานผสม)
  OPTION (1) : เปลี่ยนเป็น ... (ราคา ±x บาท)
  หมายเหตุ
  - ราคาที่เสนอรวมงานรื้อ.../ดรอปพื้น... (ลูกค้าเตรียมวัสดุ)
  รายละเอียดงาน
  - อลูมิเนียม [สี/รุ่น]
  - กระจก [ชนิด หนา]
  - มุ้ง [ชนิด] (เฟรม[สี]/ผ้าไฟเบอร์[สี])
  - [วัสดุผนัง/หลังคา/ฝ้า]
```
ลำดับ: **หัวข้อ → บรรยายชนิดบาน → OPTION → หมายเหตุ → รายละเอียดงาน(วัสดุ)**
- หมายเหตุงานรื้อ/ดรอปพื้น = วาง**ใต้แต่ละข้อ** (ไม่รวมท้ายใบ) · **ตัดตัวเลขราคาต่อหน่วยทิ้ง** (ใบจริงไม่โชว์)

## 6. ❓ OPEN QUESTIONS — รอพี่นัทเคาะ (ห้ามเดา)
1. **PC Door** ชื่อในวงเล็บ: เฟิร์น="Parallel Casement Door" · ใบจริง="Panoramic door" → ใช้คำไหน?
2. **ชนิดการเปิด** (เลื่อนสลับ/เปิดคู่กลาง/ลากจูง) โค้ดปิด `if(false)` ไว้ — เปิดใช้ของเดิม หรือทำ dropdown ใหม่? (ใบจริงใช้จริงทุกใบ → ควรเปิด)
3. **"คาดตาราง"** — ใบจริงใช้บ่อย → เพิ่มเป็น option (checkbox/dropdown) ไหม? คิดเงินเพิ่มไหม?
4. ของที่เฟิร์นมีแต่ใบจริง 3 ใบไม่ใช้ (บานเฟี้ยม/YKK/Tostem/มุ้งม้วน/หลังคาดีไลท์-โพลีตัน-ชินโค/รางน้ำ PVC-โซ่/งานไฟ) → ทำเป็น optional (ไม่บังคับ) ใช่ไหม?
5. **ราคางานบริการ** (งานไฟ/รื้อ/กรีดพื้น) — เก็บตัวเลขคิดภายใน แต่**ไม่พิมพ์ราคาต่อหน่วยในใบ** (ตามใบจริง) ใช่ไหม?
6. **ระดับบังคับกรอก** — hard (ไม่ครบ gen ไม่ได้ + ไฮไลท์แดง) หรือ soft (เตือนแต่ gen ได้)?
7. **ธรณี/หลังเต่า/Drop Seal** — เพิ่มเป็น dropdown ต่อบานเปิด/เฟี้ยม คิดเงินไหม (ราคาอยู่ที่ไหน)?

## 7. เฟสที่เสนอ (หลังเคาะ Q)
- **เฟส 1** ของที่ใบจริงใช้บ่อย + ขาดในฟอร์ม: ชนิดการเปิด(เปิด if(false)) · รางล่างกันน้ำ/รางเตี้ย · ธรณี · คาดตาราง · ชุดล็อคกุญแจ
- **เฟส 2** หลังคา option chain (แป/ปลาย/รางน้ำ→โซ่-ท่อ + สีย่อย) + สีพิเศษรวมทั้งงาน
- **เฟส 3** งานบริการ (งานไฟ/รื้อ/กรีดพื้น) + บังคับกรอก (validation)
- **เฟส 4** optional ที่ใช้น้อย (YKK/Tostem/มุ้งม้วน/ดีไลท์-โพลีตัน-ชินโคสีย่อย)

## 8. Vocabulary มาตรฐานต่อชนิดบาน (คำที่ใบใช้จริง — ยึดเป็นข้อความพิมพ์)
- **บานเลื่อน:** `ประตูบานเลื่อน{สลับ/เปิดคู่กลาง/ลากจูง/เดี่ยว/ไร้ราง}{ราง: รางล่าง(รุ่นกันน้ำ)/(รุ่นรางเตี้ย 7 มม.) · รางบน(รุ่นโชว์ราง)} แบ่ง N บาน (เสริมคานซัพพอร์ทรุ่น{โชว์/ซ่อน}คาน [และฝังรางยูกันบานแกว่ง N ราง]) พร้อมกระจกติดตายด้าน{ข้าง/บน} (มีคาดตาราง)`
- **บานเปิด:** `ประตูบานเปิด{เดี่ยว/คู่} (มีธรณี{กันน้ำ}/ไม่มีธรณี/มีธรณีหลังเต่า และ Door Drop Seal) (มีคาดตาราง) พร้อมกระจกติดตายด้าน...` · บานทึบ = `ประตูอลูมิเนียมลูกฟูกเรียบบานเปิด...` · `ปิดทึบด้วยอลูมิเนียมลูกฟูกเรียบ + คิ้วอลูมิเนียมวิ่งรอบด้านล่าง`
- **บานเฟี้ยม:** `ประตูบานเฟี้ยม{อิสระ}(รุ่นรางกันน้ำ) แบ่ง N+N บาน (เสริมคานซัพพอร์ทรุ่นโชว์คาน และฝังรางยูกันบานแกว่ง N ราง)`
- **หน้าต่าง:** `หน้าต่างบาน{เลื่อนสลับ/เลื่อนเปิดคู่กลาง/เปิด/กระทุ้ง/ยก} (มีมุ้ง...) พร้อมกระจกติดตายด้าน... (มีคาดตาราง)`
- **หลังคา:** `หลังคา{ไวนิล/โพลีตัน/ชินโคไลท์/กระจกลามิเนต/เมทัลชีท}{สี/รุ่น} {ยื่นปลาย/ต่อปลาย} (แปเดี่ยว/แปคู่) โครงอลูมิเนียม [เสริมเพลทเหล็กรับล่าง+เหล็กดึงบน] พร้อมรางน้ำอลูมิเนียม + ตะแกรงกันใบไม้ และมี{ท่อน้ำทิ้ง PVC 2.5"/โซ่รางน้ำลายดอกทิวลิป N จุด} {ปล่อยปลาย/ไม่มีรางน้ำ}`
- **มุ้ง (addon):** `(มีมุ้ง{เฟรมเล็ก/เฟรมใหญ่/จีบ/นิรภัย})` + รายละเอียด `- มุ้ง{...} (เฟรมสี{...}/ผ้าไฟเบอร์{เทา/ดำ})`
- **กั้นห้อง:** 1 รายการไล่ `- ด้าน A / ด้าน B ... (ถึงด้าน M)` ราคารวมก้อนเดียว
- หน่วยทุกชนิด = **"1 ชุด"** · ส่วนลด = รายการแยกราคา 0.00 หักท้ายบิล
