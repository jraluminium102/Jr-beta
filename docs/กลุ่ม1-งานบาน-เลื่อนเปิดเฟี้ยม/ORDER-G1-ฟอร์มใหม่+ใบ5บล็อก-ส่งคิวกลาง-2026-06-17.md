## 🟢 กลุ่ม A — งานจัดวาง/ข้อความ (ปลอดภัย · ไม่แตะ calc · ทำก่อน)
1. **คาดตาราง** ย้ายขึ้นใต้มุ้ง (ของหลัก · ออกจากกล่องพับ)
2. **มือจับ → "ล็อค"** (ไม่มี/มีล็อค/มีล็อค+กุญแจ) · มือจับแบบละเอียด (สแตนเลส/HYDA/Metro) ย้ายไปกล่อง "OPTION ทางเลือกลูกค้า"
3. **ขนาด** สลับลำดับ → กว้าง / สูง / **จำนวนบาน / ชุด** (บานก่อนชุด)
4. **ของไม่บ่อยพับ** กล่อง "อุปกรณ์เสริม": ครอบวงกบ(ทั้งชุด) / ฝังรางยู / ดรอปพื้น / ธรณี / เสริมคาน / รื้อ
5. **ใบเสนอราคา 5 บล็อก เก็บหัว** (`itemDetail` L5069): เอา "มุ้ง+ขนาด" ออกจาก prodName (L5176-5184 + บานเลื่อน _slideName) · **ไม่เพิ่มบานหลักซ้ำในรายการ** (หัวบอกแล้ว · พี่นัทย้ำ) · เป้า = SAMPLE-G1
6. **3 จุดเคาะใบ (พี่นัทเลือกแล้ว):** ก = หัวข้อ **"รายละเอียด"** (สั้น) · ข = **ใส่ขนาดในหัว** · ค = สีอบพิเศษ **รหัสเดียว** (ช่อง `.i-colorcode` รับทั้งรหัส/ชื่อสีอยู่แล้ว)
7. **ผนังเบาสเปกเต็ม** (registry #8 · wall_ext/wall_int L699-700): ภายนอก="สมาร์ทบอร์ด+ฉนวน+โครงเหล็กชุบซิงค์1.2มม.+คร่าวซี-ไลน์" · **ภายใน="ยิปซั่ม"+ฉนวน+คร่าวซี-ไลน์** (ไม่ใช่สมาร์ทบอร์ด · ตรวจ grep ยังไม่ลง)

## 🔴 กลุ่ม B — แตะ calc/engine (เสี่ยงราคา · ระวัง golden · ทำหลัง A)
8. **ดีดัพ OPTION ซ้ำ 4 ตัว** (มุ้ง/มือจับ/กระจก/สีอลู เหลือที่เดียว · "เปลี่ยน X" รวมในกล่อง OPTION) — แตะ logic การคิดราคา option · เทสว่าราคา OPTION ยังถูก
9. **⭐ บานผสมคิดราคาตามชนิดจริง (มติพี่นัท: อัปเกรด engine)** — จุดเสี่ยงสุด:
   - **ปัญหาเดิม:** `calcSubItemPrice` (L4068) คิดบานผสมทุกตัว **เป็น fixed_glass เสมอ** → ผสมบานทำงาน(เปิด/เลื่อน) ราคาผิด
   - **แก้:** ให้คิดราคาตาม **ชนิดจริงของบานย่อย** (เปิด/เลื่อน/เฟี้ยม/กระทุ้ง/ติดตาย) ผ่าน calcUnit ของ product ชนิดนั้น
   - subItems เก็บฟิลด์ใหม่: `kind`(ชนิด) · `open/fix`(แบ่งบาน) · `mosq`(มุ้ง) · `grid`(คาดตาราง+เส้นนอน/ตั้ง · **คิดเงินตามสูตร**) · `fprice`(ราคาแยก override) · `ftext`(แก้ข้อความบนใบ) · `note`
   - เพิ่ม UI ต่อบานย่อย: "ปรับ"(แบ่งบาน/มุ้ง/หมายเหตุ) + "จัดเต็ม"(คาดตาราง/ราคาแยก/แก้ข้อความ) ตาม DRAFT-v7
   - บาน "อื่นๆ"(custom) = ไม่รู้ชนิด → ต้องกรอก `fprice` เอง
   - จุดแก้: `SUBITEM_TYPES` L3984 · `addSubItem` L3991 · `readSubItems` L4055 · `calcSubItemPrice` L4068 · render บานย่อยในใบ L5997
