1) หลักการคิดราคา (ทุกแบบใช้ร่วม)

ขั้นวิธี
1. เรต/ตร.ม.rateOf(พื้นที่) = หาเรตจาก tier ตามพื้นที่ (ต่ำกว่า tier แรก = ใช้เรต tier แรก)
2. ราคาฐานพื้นที่monoRate = พื้นที่ × เรต · บังคับ monotonic (พื้นที่มากขึ้นยอดไม่ต่ำกว่าขอบ tier ก่อน)
3. หลายบาน (floor)ถ้าบาน>1: floor = monoRate(พื้นที่/บาน) × (1 + 0.67×(บาน−1)) — บานแรกเต็มราคา บานถัดไป 0.67/บาน (ยกเว้นบานเปิดยูโร ceLinear)
4. coremax(ฐาน+addon, floor, min)
5. ส่วนเพิ่ม+ กระจก + สีอลู + ออปชั่น (มือจับ/โช๊ค/คาดตาราง/ครอบวงกบ/มุ้ง ฯลฯ)
6. ราคาขายปกติ roundUp(core+extras) = ปัดขึ้นพัน · บานเปิดยูโร Math.round (ปัดร้อยที่ฐานแล้ว)

3) วิธีคิดราคาฐาน + ตัวอย่าง (รายแบบ)

บานเลื่อน (bucket)

ราคา = max(min, พื้นที่ × เรตตาม tier) · หลายบานใช้ floor 0.67

ตัวอย่าง บานเลื่อนยูโร 1.80×2.00 = 3.60 ตร.ม. 1 ชุด: tier [3.5–4.5]=6,300 → 3.60×6,300 = 22,680 (≥ min 7,500) → ปัดขึ้นพัน = 23,000

บานเปิด ยูโร/โซลิด (ceLinear · convention B)

กรอก กว้างรวม × สูง + จำนวนบาน · พื้นที่บาน = (กว้าง×สูง)÷บาน · ฐาน/บาน = 15,000 + max(0, พื้นที่บาน−1.2) × 4,166.67 ปัดขึ้นร้อย × บาน · ไม่มีเพดาน · ไม่ใช้ floor

ตัวอย่าง บานเปิดยูโร กว้างรวม 1.80 × สูง 2.10, 2 บาน: พื้นที่รวม 3.78 · /บาน = 1.89 → 15,000 + (1.89−1.2)×4,166.67 = 15,000+2,875 = 17,875 → ปัดขึ้นร้อย 17,900 × 2 = 35,800
1 บาน 0.90×2.10 = 1.89: 17,900 · 4 บาน รวม 3.60×2.40 (/บาน 2.16): 15,000+(2.16−1.2)×4,166.67=19,000 ×4 = 76,000

X-series/Velora/D-series = bucket tier ปกติ (XOPEN/VELORA/DSERIES) ไม่ใช่ ceLinear

บานกระทุ้ง (bucket AWN + addon)

ราคา = max(10,000, พื้นที่×เรต AWN) + บานที่ 2+ × 2,900 · Tilt&Turn +5,000/บาน

0.90×1.10 = 0.99 ตร.ม. 1 บาน: tier [0.8–1.1]=14,400 → 0.99×14,400 = 14,256 (≥10,000) = 14,256

บานเฟี้ยม (fold)

ราคา = max(พื้นที่×9,000, 15,000×บาน) · X-series fold_flat = max(36,000, พื้นที่×12,000)

4 บาน 3.60×2.40 = 8.64 ตร.ม.: max(8.64×9,000=77,760, 15,000×4=60,000) = 77,760

เลื่อนภายใน (area_rate + addon ตามบาน)

ราคา = พื้นที่×เรต + addon[จำนวนบาน] (รางบน 4,000/10,000/16,000/22,000 · SlimLux …/20,000/28,000) · floor รางบน 14,000/บาน

รางบนซ้อน 2 บาน 2.00×2.20 = 4.40 ตร.ม.: 4.40×4,800(tier) + addon[2]=10,000 = 21,120+10,000 = 31,120 (เทียบ floor 14,000×1.67=23,380 → ใช้ตัวมากกว่า)

บานยก (lift)

พื้นที่≤1.5→20,000 · ≤2.0→23,000 · เกิน→max(23,000, พื้นที่×8,500) · เกิน 10 ตร.ม.=ห้ามรับงาน

กระจกติดตาย (FIX) · บานเปลือย (FRAMELESS) · ดัดโค้ง · PC · ผนังเบา

กระจกติดตาย 1.50×2.00 = 3.00: tier [2.5–3]=6,000 → 3.00×6,000 = 18,000 · ผนังเบาภายนอก 3.00×1.50=4.50: tier[3–4.5]=4,500 → 20,250 (≥13,500)

ลูกฟูก/คอมโพสิททึบ (per ตร.ม. · กรอกกว้าง×สูง)

ลูกฟูก 1 ทาง 1.80×2.00 = 3.60: 3.60×3,500 = 12,600 + สีผิว (เช่น ลายไม้สต๊อก +2,500/ตร.ม. = +9,000)

5) ปัดเศษ + จุดเช็คซ้ำ

  1. สีชุบ — min 16,000 ไม่มีเรตต่อพื้นที่ · ต้องลูกค้าเห็นตัวอย่างจริง
