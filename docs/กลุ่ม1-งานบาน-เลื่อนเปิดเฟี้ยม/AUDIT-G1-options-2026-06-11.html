🔴 Leak ตัดชัวร์ (7 รายการ)

  • คาดตาราง (o-gridmark) — โผล่ใน ติดตาย / บานเปลือย / shower / ดัดโค้ง / บานยก / บานหมุน
    เงื่อนไขปัจจุบัน: if(!p.grid && !['หลังคา','ฝ้า-ผนัง'].includes(p.cat)) → กว้างเกินไป
    ควรเพิ่ม && _isPaneCat หรือ whitelist เฉพาะ cat ที่เปิด-ปิดได้จริง
  • ดรอปพื้น (o-dfm) — โผล่ใน บานเปลือย / shower / ดัดโค้ง / บานยก / บานหมุน
    เงื่อนไข: if(!areaOnly && !p.zipscreen) … if(!p.cabinet && !p.future_tech) — ตัดตู้แต่ไม่ตัด shower/บานเปลือย
  • ฝังรางยู (o-uchannel) — โผล่ใน shower / บานเปลือย / ดัดโค้ง / บานยก / บานหมุน / ราวบันได
    เงื่อนไข: if(!['หลังคา','ฝ้า-ผนัง'].includes(p.cat) && !p.cabinet && !p.future_tech) — ยังกว้างเกิน
  • ครอบวงกบ (o-fcsides/o-fcm) — โผล่ใน shower / ดัดโค้ง / บานยก / บานหมุน / ราวบันได (เส้นที่ 1 ใน !areaOnly)
    shower ไม่มีวงกบอลูแยก · ดัดโค้งวงกบพิเศษ · ราวบันไดไม่มีวงกบ
  • งานเสริม/วิศวกรรม (o-extrawork) — โผล่ทุก cat รวมถึง ราวบันได / ระแนง / ฝ้า-ผนัง ที่มีช่องแยกแล้ว
    ไม่ได้ตัด (กว้างเกิน) — ควร render เฉพาะ G1/G2 cat หรือ whitelist ชัด
  • รื้อของเดิม (o-removeold) — โผล่ทุก cat เช่นเดียวกัน (ไม่มีเงื่อนไขกรอง) — เป็น global แต่ควรซ่อนใน ราวบันได/เสริม
  • แผ่นทึบล่าง (o-solidlower) — โผล่ใน เลื่อนภายใน (cat อยู่ใน _isPaneCat แล้ว) แต่ "เลื่อนภายใน" ติดตั้งในบ้าน ไม่มีแผ่นทึบล่าง ควรตัดออกจาก _isPaneCat หรือเพิ่ม exclude
