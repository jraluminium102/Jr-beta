ส่วน 5 — วิธีกรอก + การคิดราคา (ครบ 7 กลุ่ม) คู่มือย่อ

กลุ่ม 1 — บาน / กระจก

วิธีกรอก: เลือกแบบ → กรอก กว้าง×สูง (เมตร) → จำนวนบาน + จำนวนชุด → เลือกสีอลู + กระจก → ออปชั่น (มือจับ/โช้ค/มุ้ง/ครอบวงกบ)
area = กว้าง × สูง ราคาฐาน = max(min, area × เรตตามขนาด) ← method 'bucket' (บานส่วนใหญ่) + addon (บานคู่/บานที่ 2/รางเลื่อน) + กระจกพิเศษ(GLASS.s × area) + สีพิเศษ ราคาขาย = ปัดขึ้นพันบาท(ผลรวม) พิเศษ: เฟี้ยม=max(area×9,000, 15,000×บาน) · บานยก≤1.5→20,000 ≤2.0→23,000 · เปลือยประตู=ติดตาย+8,000/บาน
ตัวอย่าง: บานเลื่อนยูโร 2×2 ม. 2 บาน สีขาว กระจกเขียว6มม. → ฐาน 25,200 + addon 10,000 = 36,000 บาท/ชุด

กลุ่ม 2 — ระแนง / รั้ว / ราวกันตก

วิธีกรอก: เลือกแบบระแนง (rn1–rn92) → กรอก กว้าง×สูง (สูงปัดขึ้นช่วงอัตโนมัติ) → เลือกสีผิว · ราวกันตก imp1-6: กรอก "ความยาว" ในช่องกว้าง + เลือกราวจับ
ระแนง (per_sqm): ขาย = (เรต + สีต่อตร.ม.) × area ราวกันตก (per_length_tier): ขาย = ความยาว × เรตตามช่วงยาว + ราวจับ(ยู 500/กล่อง 600 ต่อม.)
ตัวอย่าง: บังตา rn1 3×2 ม. สีซาฮาร่า → (3,300+300)×6 = 21,600 → ปัด 22,000 บาท

กลุ่ม 3 — หลังคา / ฝ้า-ผนัง

วิธีกรอก: กรอก กว้าง×ยาว (พื้นที่) → ออปชั่น (หลังคาเลื่อน/ฉนวน/รางน้ำ/ปิดปลาย/เสา)
หลังคา (bucket): ขาย = max(min, area × เรตตามชนิด) ไวนิล/ดีไลท์ min 28,000 (ROOF_STD) · โพลีตัน 30,000 · ลามิเนต 45,000 เมทัลชีท/ชินโคไลท์ min=0 เรตตามรุ่น
ตัวอย่าง: หลังคาไวนิล 5×3 ม. → 15 × 6,000 = 90,000 บาท

กลุ่ม 4 — ตู้ / ฝาตู้

วิธีกรอก: กรอก กว้าง×สูง + ลึก → ประเภทตู้/จำนวนบาน/ชั้น/วัสดุชั้น/ผนังหลัง
หน้าตู้ = (เรตตามพื้นที่/บาน + สี) × บาน + (บาน-1)×5,500 + ผนัง(2×ลึก×สูง×4,000) + พื้น(กว้าง×ลึก×4,000) + ชั้น(กระจก1,000/อลู1,200)
ตัวอย่าง: ตู้ 2×2.4 ลึก0.6 2บาน 3ชั้นอลู → ≈ 51,000 บาท

กลุ่ม 5 — มุ้ง

วิธีกรอก: 2 ทาง — (ก) เพิ่มเป็น addon ในบาน (เลือกบานหลัก→⚙→มุ้ง) (ข) เพิ่มเป็นรายการแยก กรอกขนาดเอง · เฟรมต้องเลือกประตู/หน้าต่าง (min ต่าง)
จีบ (bucket): ขาย = max(min, area × เรต) เฟรม (screen_addon): ขาย = max(min/บาน × บาน, area × เรต) imp21 ประตู 2,400/หน้าต่าง 1,200 · imp23 ประตู 7,200/หน้าต่าง 4,800
ตัวอย่าง: มุ้งเฟรมใหญ่ imp23 ประตู 2 บาน 2.4×2.4 → max(14,400, 20,160) → 21,000 บาท

กลุ่ม 6 — กั้นห้องกระจก

วิธีกรอก: กดปุ่ม "เพิ่มชุดกั้นห้องกระจก" → เพิ่มบานย่อย (เลือกได้ทุกแบบ: เลื่อน/เปิด/ติดตาย/หลังคา) → กรอกขนาดแต่ละบาน → สี+กระจกคุมจาก master row ทั้งชุด (auto-label ด้าน A/B/C/D)
ราคาชุด = ผลรวมราคาแต่ละบานย่อย (คิดตามสูตรของบานนั้นๆ ปกติ) — ไม่มีราคาเหมา

กลุ่ม 7 — ม่านซิป

วิธีกรอก: กรอก กว้าง×สูง → กลุ่มลูกค้า (ปลีก×2.0/โครงการ×1.75) → รุ่น (auto/Z100/Z120/Z145D/Z120W) → ผ้า (%โปร่ง) → ระบบควบคุม (มือดึง/มอเตอร์)
area = max(กว้าง×สูง, ขั้นต่ำรุ่น) · landed = area × ราคาผ้า + ค่าระบบควบคุม(×2 ถ้า 2 ชั้น) ขาย = ปัดร้อย(landed × ตัวคูณกลุ่มลูกค้า) · *ค่าติดตั้ง 5,000+600/ตร.ม. บวกที่ระดับใบ ไม่รวมต่อชิ้น
