สรุปรูปแบบ UX — ฟอร์มกรอกงานหลังคา/ฝ้า/ผนัง (G3)

14 มิ.ย. 2026 · ดีไซน์หน้ากรอก (ยึดแม่แบบ G1) · เน้นปุ่ม/ชิป กรอกไว เห็นราคาทุกจุด · คู่กับ "สรุป-G3-ราคาออปชั่นเสริม" + ดราฟกดเล่น

📋ลำดับการกรอก (บนลงล่าง)

1เลือกกลุ่มงาน — ปุ่ม G1–G7 (หลังคา = G3)
2เลือกชนิดงาน — ปุ่มการ์ด 6 กลุ่ม → กดแล้วโชว์รุ่นย่อยเป็นชิป
ไวนิล/ดีไลท์ · โพลีตัน/กระจก · เมทัลชีท · ชินโคไลท์ · ฝ้า · ผนัง
3กรอกขนาด — หลังคาใช้คำ "ยาว × ยื่น" (ไม่ใช่กว้าง/สูง) + จำนวนชุด
4วัสดุมุง · สี — ชิปเลือกสี (ต่างตามวัสดุ) ฟรี
5โครงสร้าง — แป (เดี่ยว/คู่) · โครง (อลู/เหล็กชุบ) ฟรี
6ออปชั่นหลัก — หลังคาเลื่อน / ต่อปลายวัสดุที่ 2 (กดแล้วมีกล่องย่อยกรอกรายละเอียด)
7ปลายหลังคา · รางน้ำ — เลือกอย่างเดียว: ปล่อย / มีรางน้ำ / ปิดปลายกันน้ำ
8อุปกรณ์เสริมหลังคา — กดติ๊กที่ใช้ (เสา/คาน/ครอบ/ซ่อนสโลป) แต่ละอันมีช่องกรอกย่อย
9OPTION ลูกค้า — เลือกหมวด → กดเติมรายการ → แก้/ลบ/กรอกราคาเองได้
10หมายเหตุ / ตำแหน่ง
11ออปชั่นทั้งใบ — ปรับทุกชุดทีเดียว (ท้ายสุด)

💰เห็นราคา 4 จุด ตลอดการกรอก (หัวใจของดีไซน์)

1บนปุ่ม/ชิป
กดออปชั่นไหน ราคาขึ้นตรงปุ่มนั้นทันที
2มุมขวาหัวข้อทุกกล่อง
ยอดรวมของกล่องนั้น โชว์เสมอ (แม้ ฿0)
3พรีวิวใบเสนอราคา (ท้ายฟอร์ม)
แยกราคาทุกบรรทัด: ฐาน + ออปชั่น + OPTION → รวม/ชุด
4แถบรวมล่างจอ
ยอดรวมทั้งใบ อัปเดตสด ติดล่างตลอด

✨ฟีเจอร์เด่น (กรอกง่าย ไม่งง)

ปุ่มชนิดงาน → รุ่นย่อย

กดการ์ดกลุ่มใหญ่ก่อน แล้วค่อยเลือกรุ่น — ไม่ต้องเลื่อนดรอปดาวน์ยาว 24 รุ่น

กรองออปชั่นตามแบบ

แต่ละชนิดงานโชว์เฉพาะออปชั่นที่มีจริง (หลังคาโชว์รางน้ำ/คาน · ฝ้าโชว์ฉนวน) — ไม่รก

กล่องย่อยกรอกรายละเอียด (sub-panel)

กดออปชั่น → กล่องครีมโผล่ให้กรอก (เช่น รางน้ำ → ชนิด+ความยาว · คาน → รุ่น+ยาว) + ช่องราคาแก้เองได้

ปลายหลังคาเลือกอย่างเดียว

ปล่อย / รางน้ำ / ปิดปลาย — เลือกได้แค่ทางเดียว กันคิดราคาซ้อนกัน · ความยาวเริ่มต้น = ด้านยาวหลังคา

ทุกช่องราคาแก้ได้

ราคาที่ระบบคิดให้เป็นค่าตั้งต้น เซลล์ปรับได้หน้างาน

🗂️3 รูปแบบฟอร์ม (ตามชนิดงาน)

หลังคา

  • ยาว × ยื่น
  • วัสดุมุง + สี
  • แป / โครง
  • หลังคาเลื่อน
  • ปลายหลังคา/รางน้ำ
  • อุปกรณ์เสริม

ฝ้า

  • กว้าง × สูง
  • รุ่น/สี (ฝ้าอลู crate)
  • ฉนวน
  • ฝ้าเฉียง
