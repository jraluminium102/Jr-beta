🟡 v2 (ทำต่อถ้าพี่นัทอยากได้สีพิเศษ — ยังไม่ต้องทำตอนนี้)

ต้นทางระแนงมีสี อบสีพิเศษ / อบสีลายไม้ (คิด +บาท/ตร.ม.) แต่ v1 นี้ตัดออก ใช้สีอลูมาตรฐานอย่างเดียว
ถ้าจะเพิ่มสีพิเศษ ต้องทำ 3 อย่าง (แยกธง กันพังของเดิม):
  1. ใส่ fin:{...} ใน 3 product (ยกค่าจาก rn1/rn13/rn17)
  2. ทำ UI เลือกสีในกล่องฝ้าธงC (ตอนนี้ใช้ .o-ceilcolor แบบ crates — fin ใช้ .o-finish คนละกลไก)
  3. แก้ ceilCalc ให้ส่ง optC.finish เข้า calcUnit (ตอนนี้ส่งแค่ ckolor/insul) — engine บวกที่ L1539 opt += finish×area
แนะนำ: ปล่อย v1 (สีมาตรฐาน) ขึ้นก่อน · v2 ค่อยทำเป็นธงแยกตอนพี่นัทเคาะว่าต้องการสีพิเศษจริง
