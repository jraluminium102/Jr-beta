1. สรุปดีไซน์ (มติพี่นัท 11 มิ.ย.)

รวมรางน้ำเป็น "ชุดเดียว" ใต้ปลายหลังคา=รางน้ำ — ไม่สร้างหัวข้อใหม่:
  • เมื่อเลือก ปลายหลังคา = รางน้ำ → โชว์ (ในกล่องระบบรางน้ำเดิม): ชนิดราง 3 แบบ (อลู S 1,000/ม. · สแตนเลส M 2,000/ม. · สแตนเลส L 3,000/ม.) + ความยาว(ม.) + ระบบ ท่อ/โซ่ + สี + ตะแกรง + ท่อ PVC (เดิม)
  • ความยาว default = ความกว้างหลังคา (เติมให้อัตโนมัติ · เซลล์แก้ได้ เช่นราง 2 ด้าน)
  • ตัดช่อง "รางน้ำ" ในแถบของเสริมทิ้ง (ย้ายมารวมที่ปลายหลังคาแล้ว)
  • คิดเงิน = เรตชนิดราง × ความยาว (สเปกข้อ 33 "รางน้ำ 1,000/ม.")
หลักฐาน: สเปก รายการสูตรราคาประเมิน_ฉบับเต็ม.md ข้อ 33 "ของเสริมหลังคา: รางน้ำ 1,000/ม." · ใบจริง: มีรางน้ำแพงกว่าปล่อยปลาย (คุณนก 43,000 vs 30,000) · ดีคือ calc มี o-rfgut × o-rfgutlen อยู่แล้ว — แค่ย้าย control + ตั้ง default

3. calc — ไม่ต้องแก้ ✓

gr = (rfgut)×(rfgutlen) มีอยู่แล้วในบล็อกของเสริมหลังคา (msgs.push 'รางน้ำ '+fmt(gr)) · readItem อ่าน .o-rfgut/.o-rfgutlen (class เดิม) → ย้าย control แต่ class เดิม = calc/readItem ไม่ต้องแก้
เลิกแนวทางเดิม (auto w×1,000) — ใช้ o-rfgut × o-rfgutlen แทน (ยืดหยุ่นกว่า เลือกชนิด+กรอกยาวได้)

4. genQuote — รวมบรรทัดรางน้ำ (กันซ้ำ + ตรงใบจริง)

ปัญหา: ตอนนี้จะมี 2 บรรทัดรางน้ำ
"รางน้ำ (ท่อ สีขาว)…" (จาก rfend) + "รางน้ำอลูมิเนียม" (จาก rfgut FIX-1) → ต้องรวมเป็นบรรทัดเดียว

4.1 ใส่ชนิดราง (อลู/สแตน) ใน _gutterLine (L3574–3582)

// เพิ่มก่อนคิด _gutterLine
const _gmat = (parseFloat(_os.rfgut)||0)>=2000 ? 'รางน้ำสแตนเลส' : 'รางน้ำอลูมิเนียม';
// แล้วเปลี่ยน 'รางน้ำ (...)' → _gmat+' (...)'
_gutterLine = _gmat+' (โซ่ลาย'+_pat+' สี'+_col+')';   // โซ่
_gutterLine = _gmat+' (ท่อ สี'+_col+')';              // ท่อ

4.2 ลบบรรทัดรางน้ำซ้ำใน _rfExtra (L3610)

if(_f('rfgut')>0 && _f('rfgutlen')>0) _rfExtra += '\nรางน้ำอลูมิเนียม';  // ← ลบ (รวมใน _gutterLine แล้ว)
ผล detail: "รางน้ำอลูมิเนียม (ท่อ สีขาว) + ตะแกรงพลาสติกกันใบไม้ สีดำ" — ใกล้ใบจริง "รางน้ำอลูมิเนียม + ตะแกรง…"

5. ผลกระทบราคา (ตัวอย่าง · อลู S 1,000/ม.)

เคสความยาวราง (=กว้าง)รางน้ำเดิม → ใหม่
ไวนิล 4×3 ปลายรางน้ำ4 ม.4×1,000=4,00072,000 → 76,000
ไวนิล 6×3.5 ปลายรางน้ำ6 ม.6×1,000=6,000~116,000 → 122,000
สแตนเลส M (6 ม.)6 ม.6×2,000=12,000+12,000
ปลายปล่อย (ไม่มีราง)—0เท่าเดิม
