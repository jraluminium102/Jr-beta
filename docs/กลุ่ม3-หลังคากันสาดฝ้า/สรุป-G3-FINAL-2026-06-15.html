5.2 ตัวอย่างหลังคาเลื่อน (6×3 ม. · 4 บาน เลื่อน)

ฐาน ไวนิล 18 ตร.ม. = 99,000
บาน 4 บาน → พื้นที่เลื่อน auto = 18 × 4/(4+1) = 14.4 ตร.ม. → ROOF_SLIDE เรต 4,700/ตร.ม.
เพิ่มหลังคาเลื่อน = (4,700 − 5,500) × 14.4 = −11,520 → (ตัดส่วนเลื่อนจากฐาน + คิดเรตเลื่อน)
+ มอเตอร์ 14.4 ตร.ม. → tier 28,000/ตัว
รวมประมาณ 99,000 + ส่วนต่าง + 28,000 ≈ ~127,000–141,000 (ขึ้นกับ input จริง)

5.3 ตัวอย่างหลังคาผสม (ไวนิล + เมทัล IMP8)

ไวนิล 13 ตร.ม. + เมทัล IMP8 5 ตร.ม. (รวม 18 ตร.ม.)
ส่วนไวนิล: monoRate(13, ROOF_STD) = 13 × 5,500 = 71,500
ส่วน IMP8: monoRate(5, IMP8) = max(28,000 ฐาน, 5 × 6,400) = 32,000 → ใช้ monoRate จริง
รวม = max(28,000, 71,500 + 32,000) = 103,500 → ปัดขึ้นพัน = 104,000
