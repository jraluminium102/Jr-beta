1) ลำดับฟอร์ม (บน → ล่าง) · 10 ขั้น

Profile A — หลังคา (roof / rooflam) · ใช้มากสุด

1กลุ่มงาน — ปุ่ม G1–G7 (G3 active)
2ชนิดงาน — ปุ่มการ์ด 6 กลุ่มหลัก (ไวนิล/ดีไลท์ · โพลีตัน/กระจก · เมทัลชีท · ชินโคไลท์ · ฝ้า · ผนังเบา) → ชิปรุ่นย่อย (เช่น ไวนิล/ดีไลท์ 2 รุ่น · เมทัล 8 รุ่น · ชินโค 6 รุ่น)
3ขนาด — ยาว (ม.) × ยื่น (ม.) · จำนวนชุด label: ยาว×ยื่น
4วัสดุมุง · สี — ชิปสีวัสดุ (ฟรี · label เท่านั้น) · ลามิเนต = ฟิล์ม 3 ตัว + ความหนา 2 ตัว
5โครงสร้าง — แป (แปคู่/แปเดี่ยว) + โครง (อลู/เหล็กชุบ) ฟรี · label
6ออปชั่นหลัก — หลังคาเลื่อน (toggle → sub-panel) · ต่อปลายวัสดุที่ 2 (toggle → sub-panel)
7ปลายหลังคา — ปล่อย / มีรางน้ำ (→ sub-panel ชนิดราง+ยาว) / ปิดปลาย (→ กรอกยาว) เลือกได้อย่างเดียว
8อุปกรณ์เสริมหลังคา — ดรอปดาวเดียว (toggle chip+sub-panel): รางน้ำ · ปิดปลายกันน้ำ · ครอบท่อ PVC · คานเหล็กถัก · เสาแผง · เสา 4"×8" · รื้อของเดิม
9OPTION ลูกค้า (ต่อชุดนี้) — เลือกหมวด → รายการย่อย → กดเติม · แก้/ลบ/กรอกเองได้
10ตำแหน่ง / หมายเหตุ
11ออปชั่นทั้งใบ (ท้ายสุด · หมวดเหมือนข้อ 9 · ±/ชุด คิดทีเดียว)
฿แถบราคารวม ติดล่างตลอด (sticky)

Profile B — ฝ้า (ceil / ceilalu) · ช่องน้อยกว่า

1–2เลือกกลุ่ม → ชิปรุ่น: ฝ้าฉาบเรียบ / ฝ้าอลู ตัวซี 15ซม. / ฝ้าไม้เทียม remood
3ขนาด — กว้าง × สูง (ม.) label: กว้าง×สูง
4สี/รุ่น — ฝ้าอลู: ขาว-ดำ (2,100) / ลายไม้ (2,700) · ฝ้าไม้เทียม: มาตรฐาน (2,600) / ลายไม้ (2,800) · ฝ้าฉาบเรียบ: ฉาบเรียบมาตรฐาน
5โครงสร้าง — อลู / เหล็กชุบ ฟรี
6ออปชั่นหลัก — ฉนวนกันร้อน/เสียง (+600/ตร.ม.) · ทาสี (กรอกเอง)
7อุปกรณ์เสริม — ครอบวงกบ · รื้อของเดิม
8–11OPTION ลูกค้า → ตำแหน่ง/หมายเหตุ → ออปชั่นทั้งใบ → แถบราคา (เหมือน profile A)

Profile C — ผนังเบา (wall) · คล้าย G1

1–2เลือกกลุ่ม → ชิปรุ่น: ผนังเบาภายนอก / ผนังเบาภายใน / ISOWALL
3ขนาด — กว้าง × สูง (ม.)
4รุ่น/ความหนา — สมาร์ทบอร์ด 12มม. / สมาร์ทบอร์ด 20มม. / เวเทอร์บล็อค 9มม. (ISOWALL: ความหนา+สี)
5โครงสร้าง — อลู / เหล็กชุบ
6ออปชั่นหลัก — ฉนวนกันร้อน/เสียง · ทาสี (กรอกเอง)
7อุปกรณ์เสริม — ครอบวงกบ · รื้อของเดิม (เหมือน G1)
8–11OPTION ลูกค้า → ตำแหน่ง/หมายเหตุ → ออปชั่นทั้งใบ → แถบราคา

2) การโชว์ราคา — 4 ระดับ (หัวใจของดีไซน์)

ระดับโชว์ที่ไหนทำอะไร
① บนชิปทุกออปชั่นที่กดติดขึ้น ฿ ตรงชิปทันที · อุปกรณ์เสริมที่มี sub-panel โชว์ยอด sub-panel
② ต่อกล่องมุมขวาหัวข้อทุก section (.secsum)subtotal ของกล่องนั้น โชว์เสมอ (แม้ ฿0)
③ พรีวิวใบเสนอราคาการ์ดขอบแดง 2px ท้ายฟอร์มแยกราคา: ฐาน (บอกพื้นที่ ตร.ม.) + แต่ละออปชั่น + OPTION + รวม/ชุด + ออปชั่นทั้งใบ + ยอดรวม
④ แถบรวมล่างจอ stickyยอดรวมทั้งใบ realtime + label "ยอดรวมทั้งใบ (เดโม)"
กฎราคา G3: คำนวณได้ทันที = ฐานบาน (bucket: max(min, monoRate(พื้นที่, RATES[key]))) · หลังคาเลื่อน (สูตรขั้นบันได+tier+มอเตอร์) · รางน้ำ (เรต/ม.×ยาว) · คานเหล็กถัก (เรตรุ่น×ยาว) · เสา (จำนวน×เรต) · ครอบท่อ (⌈ยาว/1.5⌉×1,500) · ปิดปลาย (1,000/ม.) · ต่อปลายวัสดุ 2 (monoRate เฉพาะส่วน) · ฟรี (label) = สีวัสดุมุง / แป / โครง / ฉาบเรียบรุ่น / รุ่นผนัง · ทุกช่องราคา แก้ได้

4) ออปชั่นสำคัญ — ต่างจาก G1

ออปชั่นประเภทรายละเอียดราคา

5) ฟีเจอร์ดีไซน์สำคัญ

ฟีเจอร์รายละเอียด
ปุ่ม 6 กลุ่ม → ชิปรุ่นการ์ดไอคอน+ชื่อ+จำนวนรุ่น (grid 3 คอลัมน์) · ตัวเลือก=พื้นแดง · ชิปรุ่นโผล่ข้างล่างทันที · เมทัล/ชินโคมีชิปรุ่นเยอะ (8/6 รุ่น) เลื่อนได้
กรอง profile ตามชนิดงานroof/rooflam = ฟอร์มหลังคาเต็ม · ceil/ceilalu = ฝ้า (ตัดแป/หลังคาเลื่อน/ปลายหลังคา) · wall = ผนัง (ตัดแป/หลังคาเลื่อน) · ครบ 10+ ขั้นเสมอ แต่โชว์เฉพาะที่เกี่ยว
sub-panel ออปชั่นหลังคากด toggle chip → กล่องย่อยโผล่: หลังคาเลื่อน(จำนวนบาน/มอเตอร์) · รางน้ำ(ชนิด/ยาว) · คาน(รุ่น/ยาว) · เสา(จำนวน) · ปิดปลาย(ยาว) · ราคา auto คำนวณในแผง แก้ได้
ปลายหลังคา 3 ทาง exclusiveเลือกได้ทีละอย่าง (radio-style) · ปล่อย / รางน้ำ / ปิดปลาย · ที่เหลือ clear · ต่างจาก chip อื่นที่ toggle อิสระ
ต่อปลายวัสดุที่ 2toggle → เลือกวัสดุ2 + กรอกพื้นที่ส่วนที่2 · ราคาคิดแยก (monoRate ส่วน2) · พื้นที่หลัก = รวม − ส่วน2 (auto)
หลังคาเลื่อน autoกดติด → sarea ดึงจากขนาดหลัก (ยาว×ยื่น) · มอเตอร์ auto qty จากพื้นที่ (≤3.5→18k / ≤14→28k / ≤40→36k / >40→72k)
ลามิเนต sub-optioncfg='rooflam' → โชว์ฟิล์ม (ใส/เขียว/กันร้อน) + ความหนา (4+4 / 5+5) แทนชิปสีปกติ
OPTION แบบหมวดเลือกหมวด 6 หมวด (สี/วัสดุ · กันร้อน · รางน้ำ/ระบาย · งานเหล็ก/โครง · งานเพิ่ม · ส่วนลด) → รายการย่อย → กดเติม แก้/ลบ/กรอกเอง
ฝ้าอลู/ไม้เทียม crateราคา = max(10, พื้นที่) × crates[สี] · ไม่ใช้ bucket · min = ขั้นต่ำ 10 ตร.ม. auto
