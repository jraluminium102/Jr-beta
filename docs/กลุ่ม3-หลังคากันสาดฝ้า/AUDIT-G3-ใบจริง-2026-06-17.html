1) ตารางสรุปรายมิติ

มิติรายการที่ตรวจใบจริง (ต้นแบบ)ระบบออกสถานะ
A1 5 บล็อก หลังคา — เรียงบน→ล่าง หัวรายการ → งาน → OPTION (แดง) → หมายเหตุ → รายละเอียด(สเปค) หัวรายการ → งาน → รายละเอียด (ไม่มีหัวข้อ OPTION/หมายเหตุแยก) 🟡 เคาะ
A2 5 บล็อก ฝ้าฉาบเรียบ — เรียง หัวรายการ → งาน (ฝ้า+ฝ้าเฉียง) → หมายเหตุ → รายละเอียด หัวรายการ → "รายละเอียดงาน" → ฝ้าฉาบเรียบ+ฝ้าเฉียง (ไม่แยกบล็อก) 🟡 เคาะ
A3 5 บล็อก ผนังเบา — เรียง หัวรายการ → งาน (แผ่น+โครง+ฉนวน) → หมายเหตุ → รายละเอียด (สีอลู/กระจก) หัวรายการ → "รายละเอียดงาน" → แผ่น+โครง+ฉนวน รวมกัน ✅ (ไม่มีหัวข้อ OPTION) 🟢 ตรง
B1 ชินโค สี+รหัส ใบเฟริล OPTION ชินโคไลท์ HC-N828 Modern Grey ระบุ "รุ่น HC-N828 สี Modern Grey" ในบรรทัด OPTION หัวรายการ = "ชินโคไลท์ 6 มม. รุ่น Heat Cut ยื่นปลาย (แปคู่)" · รายละเอียด: ไม่มีสีเลย (ขาด "สีหลังคา: HC-N828 Modern Grey") 🔴 ขาด
B2 ดีไลท์ DG7 ดีไลท์ DG7 สีเทาโมเดิร์น ใบจริงระบุสีดีไลท์ในรายละเอียดงาน รายละเอียด: "สีหลังคา: DG7 สีเทาโมเดิร์น" ✅ 🟢 ตรง
B3 รางน้ำ + ตะแกรง ใบนก รายการ 3 (โรงรถ): รางน้ำอลู + ตะแกรงพลาสติกกันใบไม้ สีดำ "รางน้ำอลูมิเนียม + ตะแกรงพลาสติกกันใบไม้สีดำ" บรรทัดเดียว เคส B: ปล่อยปลาย/ไม่มีรางน้ำ (chip รางน้ำไม่ active) — ขาดรางน้ำ+ตะแกรง 🔴 bug chip
B4 โซ่รางน้ำ ลายทิวลิป ใบนก รายการ 3,4,7: "โซ่รางน้ำ ลายดอกทิวลิป สีน้ำตาล จำนวน N เส้น" ข้อความตรงแบบนี้ เคส C: "โซ่รางน้ำ ลายดอกทิวลิป จำนวน 2 เส้น" — ขาด "สี__" (เคสนี้ขาด "สีน้ำตาล") 🔴 ขาดสีโซ่
B5 ท่อน้ำทิ้ง PVC ใบนก รายการ 1: "ท่อน้ำทิ้ง PVC 2.5" สีดำ" · ใบเฟริล รายการ 2: "ท่อน้ำทิ้ง PVC 2.5 นิ้ว สีดำ" บรรทัดแยก ใต้รางน้ำ เคส B/J: ท่อ PVC ไม่ออก (ขาดบรรทัด) — ออกแค่รางน้ำ แต่ท่อหาย (ดู quote เคส B) 🔴 ขาดท่อPVC
B6 ซ่อนสโลป ใบนก รายการ 7: "แผ่นคอมโพสิตสโลปหลังคา สีดำ" บรรทัดรายละเอียดในส่วนงาน "ซ่อนสโลปหลังคาด้วยคอมโพสิต สีดำ" ✅ (ถ้อยคำต่างนิดหน่อย) 🟡 ถ้อยคำต่าง
B7 เสริมเพลทเหล็กล่าง + เหล็กดึงด้านบน ใบเฟริล รายการ 2: "เสริมเพลทเหล็กรับล่างและเหล็กดึงด้านบน" ข้อความรวม 1 บรรทัด เคส J: "เสริมเพลทเหล็กล่าง (รับล่าง)" + "เหล็กดึงด้านบน" แยก 2 บรรทัด 🟡 แยกบรรทัด ≠ รวม
B8 แปเดี่ยว/แปคู่ ใบจริง: "แปเดี่ยว" หรือ "แปคู่" ในหัวรายการ ข้อความในหัว เคส A: "(แปเดี่ยว)" ✅ · เคส E: "(แปคู่)" — default แปคู่ ต้องเช็คกรณีไม่กด chip ว่าถูกไหม 🟢 ตรง
B9 ผนัง — โครงเหล็กชุบซิงค์ ใบสุจินต์ รายการ 1,3,4,5: "โครงเหล็กชุบซิงค์(ไร้สนิม)" "โครงเหล็กชุบซิงค์(ไร้สนิม)" ในรายละเอียดงาน "โครงเหล็กชุบซิงค์ (ไร้สนิม) หนา 1.2 มม. พร้อมโครงคร่าวซี-ไลน์เสริมแรง" ✅ — ตรง + มีข้อมูลเพิ่ม 🟢 ตรง (มีรายละเอียดมากกว่า)
B10 ผนัง — ฉนวน 3" ใบสุจินต์: "ฉนวนกันความร้อนและกันเสียง หนา 3"" บรรทัดแยก "ฉนวนกันความร้อนและกันเสียง หนา 3"" ✅ 🟢 ตรง
B11 ผนัง — สมาร์ทบอร์ด หนา + ทาสีรองพื้น ใบสุจินต์: "แผ่นสมาร์ทบอร์ด หนา 12 มม. พร้อมทาสีรองพื้นสีขาว" ข้อความตรงแบบนี้ "แผ่นสมาร์ทบอร์ด หนา 12 มม. พร้อมทาสีรองพื้นสีขาว" ✅ 🟢 ตรง
B12 หลังคา — โครงเหล็กชุบซิงค์ (หลังคาไวนิล) ใบสุจินต์ รายการ 12: "หลังคาไวนิล ยื่นปลาย โครงเหล็กชุบซิงค์(ไร้สนิม)" ข้อความในงาน "โครงเหล็กชุบซิงค์ (ไร้สนิม)" ✅ (เคส I) 🟢 ตรง
C1 ราคา ฝ้าฉาบเรียบ ใบนก OPTION ฝ้าใต้หลังคา 3.26×1.52 = ~4.96 ตร.ม. = 10,000 บาท OPTION เพิ่ม 10,000 บาท Engine render 4×3.26 = 13.04 ตร.ม. → 16,000 บาท (ขนาดต่างกัน · ไม่ใช่ bug ราคา) 🟡 ขนาดต่าง

2) จุดผิด/ขาด รายละเอียด (🔴→🟡→🟢)

🔴 จุดผิดแน่ — ต้องแก้

BUG-1: ชินโคไลท์ — ขาด "สีหลังคา" ในรายละเอียด
ใบจริง OPTION ใบเฟริล: "หลังคาชินโคไลท์รุ่น HC-N828 สี Modern Grey"
ระบบออก (เคส E): รายละเอียดไม่มี "สีหลังคา: HC-N828 Modern Grey" เลย — มีแค่ "สีโครง: อบขาว"
Root cause: L5795 เขียน if(_rfColor) _spec.push('สีหลังคา: '+_rfColor) แต่ chip สีชินโคไลท์ เขียนค่าลง .o-rfcolor ไม่สำเร็จใน jsdom (ต้องเช็คว่า chip click ยิง value จริงไหม · หรือ _os.rfcolor ว่าง)
ผลกระทบ: ทุกชินโคไลท์ที่ไม่ได้กรอก colorcode จะไม่มีสีในใบ (เช็คซ้ำ)
BUG-2: รางน้ำ + ตะแกรงกันใบไม้ ไม่ออก (chip ไม่ active)
เคส B (รางน้ำ + ท่อดำ): ระบบออก "ปล่อยปลาย/ไม่มีรางน้ำ" ทั้งๆที่กด chip "รางน้ำ"
ใบจริง (นก/เฟริล): "รางน้ำอลูมิเนียม + ตะแกรงพลาสติกกันใบไม้ สีดำ" บรรทัดเดียว
Root cause: jsdom clickChip ไม่ยิง event ถูกต้อง — แต่เคส C/D ที่กด chip "โซ่" เห็น "โซ่รางน้ำ" ออก แสดงว่า chip "รางน้ำ (ท่อ)" อาจมีปัญหาการ fire event ใน jsdom ต้องเปิดเว็บจริงยืนยัน (เช็คซ้ำ D)
BUG-3: ท่อน้ำทิ้ง PVC 2.5" สีดำ — ไม่ออกในใบ
ใบนก รายการ 1: "ท่อน้ำทิ้ง PVC 2.5" สีดำ" · ใบเฟริล รายการ 2: "ท่อน้ำทิ้ง PVC 2.5 นิ้ว สีดำ"
ระบบ (เคส B, J): ไม่พบบรรทัด "ท่อน้ำทิ้ง PVC" เลยในใบที่ออก
Root cause: L5742 if(_os.rfdrain) _drainLine = '\nท่อน้ำทิ้ง PVC 2.5″ สี'+_os.rfdrain — ต้องเลือก drain color ก่อน (ชิป drain ใน .o-rfdrain) · ไม่มี default drain · ใบจริงมีท่อเสมอเมื่อมีรางน้ำ
ข้อเสนอแก้: ตั้ง default .o-rfdrain = "ดำ" เมื่อเลือก roofend=รางน้ำ + ท่อ
BUG-4: โซ่รางน้ำ — ขาด "สี" ในประโยค
ใบนก: "โซ่รางน้ำ ลายดอกทิวลิป สีน้ำตาล จำนวน 2 เส้น"
ระบบ (เคส C): "โซ่รางน้ำ ลายดอกทิวลิป จำนวน 2 เส้น" — ขาด "สีน้ำตาล"
Root cause: L5730-5732: branch โซ่ สร้าง _gutterLine = _gmat+'(โซ่ลาย'+_pat+' สี'+_col+')' แต่โซ่แยกบรรทัด (_rfExtra L5764) ไม่มีสี
เส้นโซ่ที่แยก (rfchain) ออกจาก L5764: "โซ่รางน้ำ ลายดอกทิวลิป จำนวน N เส้น" — ขาด "สี__"
ข้อเสนอแก้: L5764 เพิ่ม สี: '\nโซ่รางน้ำ ลายดอก'+_os.rfgutchainpat+' สี'+(_os.rfgutchaincolor||'น้ำตาล')+' จำนวน '+_n('rfchain')+' เส้น'

🟡 น่าสงสัย — เช็คซ้ำ

Q1: 5 บล็อก หลังคา — OPTION block ยังไม่แยก
ใบจริง: OPTION มีหัวข้อ "OPTION (1) : หากลูกค้าต้องการ..." (สีแดง/ตัวหนา)
ระบบออก: ไม่เห็น OPTION block แยก ในเคสที่ render (อาจเป็นเพราะไม่ได้กรอก OPTION ในสคริปต์) — เช็คซ้ำด้วยการกด OPTION ในเว็บจริง
Root cause ที่สงสัย: commit 9a34f5e merge ใบ 5 บล็อก — ต้องยืนยันว่า OPTION text field ของ G3 render ถูกบล็อก OPTION ใน quoteContent
Q2: ซ่อนสโลป — ถ้อยคำต่างจากใบจริง
ใบจริง (นก รายการ 7): "แผ่นคอมโพสิตสโลปหลังคา สีดำ" (อยู่ใน "รายละเอียดงาน")
ระบบออก: "ซ่อนสโลปหลังคาด้วยคอมโพสิต สีดำ" (อยู่ในส่วนงาน บน)
สถานะ: ถ้อยคำต่าง · ความหมายเดียวกัน · แต่ใบจริงเขียนว่า "แผ่นคอมโพสิต" ชัดกว่า (เช็คซ้ำ)
Q3: เสริมเพลท + เหล็กดึง — รวมหรือแยกบรรทัด
ใบจริง (เฟริล): "เสริมเพลทเหล็กรับล่างและเหล็กดึงด้านบน" (1 บรรทัดรวม)
ระบบออก: แยก 2 บรรทัด — "เสริมเพลทเหล็กล่าง (รับล่าง)" และ "เหล็กดึงด้านบน"
สถานะ: ไม่ผิดร้ายแรง แต่รูปแบบต่างจากใบจริง (เช็คซ้ำ)
Q4: โพลีตัน — "สีขาวขุ่น (Opal 103)" vs ใบจริง "หนา 3 มม. สีขาวขุ่น( Opal 103 )"
ระบบออก: "สีหลังคา: Opal 103 สีขาวขุ่น (แสงผ่าน 20%)" — มีข้อมูล "แสงผ่าน 20%" ที่ใบจริงไม่มี
ใบจริงเขียน: "หลังคาโพลีตัน หนา 3 มม. สีขาวขุ่น( Opal 103 )"
สถานะ: "แสงผ่าน 20%" อาจไม่จำเป็นในใบลูกค้า (เช็คซ้ำ)
Q5: ฝ้าฉาบเรียบ — โครงสร้าง 5 บล็อก ยังเป็น "รายละเอียดงาน" รวม
ใบสุจินต์ รายการ 12: ฝ้าฉาบเรียบ อยู่ใน "หัวรายการ" ไม่ได้แยกบล็อก
ระบบออก (เคส G): "รายละเอียดงาน" → ฝ้าฉาบเรียบ + ฝ้าเฉียงตามแนวหลังคา — แต่ label หัวข้อยังเป็น "รายละเอียดงาน" ไม่ใช่ 5 บล็อก
สถานะ: commit 9a34f5e อาจยังไม่แยก OPTION block ให้ฝ้า (เช็คซ้ำในเว็บจริง)

3) ตัวอย่าง quoteContent จาก engine จริง

เคส A — หลังคาโพลีตัน แปเดี่ยว ปล่อยปลาย

จุดที่ 1 หลังคาโพลีตัน 3มม. ยื่นปลาย (แปเดี่ยว) (5 × 2 ม.) - โครงอลูมิเนียม - ปล่อยปลาย/ไม่มีรางน้ำ รายละเอียด - สีหลังคา: Opal 103 สีขาวขุ่น (แสงผ่าน 20%) - สีโครง: อบขาว

เคส C — หลังคาโพลีตัน รางน้ำ + โซ่ทิวลิป 2 เส้น (🔴 ขาดสีโซ่)

จุดที่ 1 หลังคาโพลีตัน 3มม. ยื่นปลาย (แปเดี่ยว) (6 × 4.5 ม.) - โครงอลูมิเนียม - โซ่รางน้ำ ลายดอกทิวลิป จำนวน 2 เส้น ← ขาด "สีน้ำตาล" - ปล่อยปลาย/ไม่มีรางน้ำ ← chip รางน้ำไม่ active ใน jsdom (ต้องเช็คเว็บจริง) รายละเอียด - สีหลังคา: Opal 103 สีขาวขุ่น (แสงผ่าน 20%) - สีโครง: อบขาว ใบจริง (นก รายการ 3) ต้องเป็น: - รางน้ำอลูมิเนียม + ตะแกรงพลาสติกกันใบไม้ สีดำ - โซ่รางน้ำ ลายดอกทิวลิป สีน้ำตาล จำนวน 2 เส้น

เคส E — ชินโคไลท์ imp15 HeatCut (🔴 ขาดสีหลังคา)
