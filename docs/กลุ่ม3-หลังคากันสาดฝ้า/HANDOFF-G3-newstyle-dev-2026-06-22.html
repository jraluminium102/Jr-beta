0) กฎเหล็กกันพัง (ทำก่อน-หลังเสมอ)

  1. git pull --rebase --autostash origin main ก่อนแตะไฟล์ (ดึงงาน G1 คิวกลางล่าสุด)
  2. node scripts/golden-snapshot.mjs ก่อนแก้ → จด baseline (150 ราคา ทุกกลุ่ม)
  3. แก้เฉพาะโซน G3 · ห้ามแตะ engine ราคาที่กลุ่มอื่นใช้ร่วม (colorPrice/rateOf/roundUp/basePrice — ใช้ได้ ห้ามแก้นิยาม)
  4. node scripts/golden-snapshot.mjs หลังแก้ → 150 ราคาต้องตรง baseline (เพี้ยน=หยุด ตรวจ)
  5. เทส G3 ของจริงเทียบดราฟ (section 7) → add → commit → pull --rebase → push HEAD:main
⚠ G3 ใช้ engine ร่วม (calcUnit/ceilCalc/colorPrice). แก้ที่ "การประกอบ UI + การเรียก" เท่านั้น · อย่าแก้สูตร/เรตใน RATES/COLORS (กลุ่มอื่นพัง)

1) โครงฟอร์ม — 3 กล่องหลัก + ลากข้ามกล่อง

กล่องเนื้อหาลากได้
① สเปกหลักกลุ่มวัสดุ → รุ่น → (ความหนา/ฟิล์ม/กระจก) → สีวัสดุมุง → สีโครง L1/L2/L3 → แป → โครงสร้าง → ขนาด(ยาว×ยื่น×ชุด) → ยืนยันตัวอย่าง → รางน้ำ (การ์ด)การ์ด "รางน้ำ" ลากข้ามกล่องได้
② ออปชั่นหลักการ์ด: โครงเหล็กเสริม · ฝ้าในตัว · หลังคาเลื่อน · หลังคาผสม✅ ลากเรียง+ข้ามกล่อง
③ ออปชั่นเสริมการ์ด: หมายเหตุมาตรฐาน · งานเสริม/อื่นๆ✅ ลากเรียง+ข้ามกล่อง
ลากเรียง: ใช้เครื่องมือลาก-เรียงตัวเดิมที่กลุ่มอื่นมี (ลากได้ทั้งมือถือ) · default order (พี่นัทจัด): กล่อง② [โครงเหล็ก, ฝ้า, เลื่อน, ผสม] · กล่อง③ [หมายเหตุ, อื่นๆ] · มีปุ่ม "คัดลอกลำดับ" ส่งกลับได้

2) สินค้า + ปุ่ม/ชิป (ดึงจาก index.html จริง · ห้ามเดา)

กลุ่มวัสดุรุ่น (ชิป)ความหนาสีวัสดุมุง (ต่อรุ่น)
ไวนิล/ดีไลท์ไวนิล VG · ดีไลท์—ไวนิล: เทา/ขาว/น้ำตาล · ดีไลท์: DG-2 ฟ้าคราม/DG7 เทาโมเดิร์น
เมทัลชีทPVC EPS · เหล็ก EPS · ฟอยล์ PU · เหล็ก PUเลือกความหนา 1"/2" → สลับชุด product (1"=imp7/9/11/13 · 2"=imp8/10/12/14) แล้วเลือกรุ่นย่อย (engine L3738)น้ำตาล/ขาว/เทา

โพลีตัน/กระจกโพลีตัน 3มม. · กระจกลามิเนตลามิเนต: ฟิล์ม[ใส/เขียว/กันร้อน] + กระจก[4+4/5+5]โพลีตัน 8 สี (Clear101…Green Metallic504) · ลามิเนตไม่มีสีมุง

4) สีโครงอลูมิเนียม L1/L2/L3 (ระบบสีต่อข้อ · มาตรฐานใช้ทุกกลุ่ม)

ระดับทำอะไรราคา / ที่โผล่ในใบ
L1 สีทั้งใบหลังคาใช้สีเดียวกับ "สีทั้งใบ" ของใบเสนอราคาcolorPrice(สีทั้งใบ, area) · บวกในยอด · โชว์ "สีโครง: X" ใน รายละเอียด (อบขาว=ฟรี)
L2 เปลี่ยนเฉพาะข้อนี้2 โหมด🟢 สีจริง (คอนเฟิร์ม) = เป็นสีของข้อนี้ · colorPrice บวกยอด · โชว์รายละเอียด
🔵 ออปชั่น = บรรทัด "เปลี่ยนสีโครง จาก[ทั้งใบ]เป็น[L2] ราคาเพิ่ม/ลด Z" ใน ช่อง OPTION · ไม่บวกยอด
L3 ต่อจาก L2เปลี่ยน สีโครง หรือ ชนิดวัสดุมุงบรรทัด "เปลี่ยน[สีโครง/วัสดุมุง] จาก[ค่า L2]เป็น[L3] ราคาเพิ่ม/ลด Z" ใน ช่อง OPTION · ไม่บวกยอด
  • ราคา = colorPrice(ci, area) (สี · COLORS 13 ตัวเดิม) หรือ roofBase ส่วนต่าง (วัสดุมุง)
  • Z = ส่วนต่าง (signed): บวก→"ราคาเพิ่ม" · ลบ→"ราคาลดลง" (กลับคำอัตโนมัติ)
  • noSum: โหมดออปชั่น (L2-🔵) + L3 → โชว์เฉพาะกล่อง OPTION · ไม่รวมในยอด/แตกราคา (ลูกค้ายังไม่เลือก)
เทสจริงในดราฟ: L2🟢ซาฮาร่า→ยอด 78,480 (รวม) · L2🔵→ยอด 72,000 (ไม่รวม) + OPTION "เพิ่ม 6,480" · L3 วัสดุไวนิล→PVC EPS "ลดลง 2,000"

5) ใบเสนอราคา — 5 กล่อง (ลำดับตายตัว)

  1. ① รายการ = หัวงาน "หลังคา[กันสาด/เลื่อน] [รุ่น] (ยาว×ยื่น ม.)" + บรรทัด default: โครงสร้าง+แป · รางน้ำ · ท่อทิ้ง · เสา4"
  2. ② OPTION (ของเสริม) = ชุดเลื่อน/มอเตอร์/ฝ้า/หลังคาผสม/โครงเหล็ก + บรรทัดสลับสี L2🔵/L3 (+/-)
  3. ③ หมายเหตุ = หมายเหตุมาตรฐานที่ติ๊ก (แก้/เพิ่ม/คงค้างได้)
  4. ④ รายละเอียดงาน = default: สีโครง · วัสดุมุง+สี · (กระจกลามิเนต)
  5. ⑤ แตกราคา = รายบรรทัด + รวม (ไม่รวมบรรทัด noSum)
บรรทัด spec สลับ ① รายการ ↔ ④ รายละเอียด ได้ (ปุ่ม ⇄ ในดราฟ) · default ตามดราฟ · ส่ง dev ตั้ง default นี้

6) จุดแก้ใน index.html (ระวัง shared)

  • ฟอร์มหลังคา (สร้างชิป/การ์ด/ลาก) — โซน roof form (ราว L4870+ · o-roof*)
  • genQuote หลังคา (5 กล่อง + swap option line) — โซน roof quote (ราว L6500+)
  • เรียกใช้: calcUnit(หลัก) · ceilCalc(ฝ้า) · colorPrice(สีโครง) · roofBase/doorStructBase — เรียกได้ ห้ามแก้นิยาม
  • สีต่อข้อ L1/L2/L3 — reuse กลไกสีทั้งใบ/coOverride ของ G1 (#global-color / .i-color / colorDrillRender) ถ้ามี · ไม่สร้างใหม่ซ้ำ

7) Acceptance — "รอบเดียวผ่าน" (เช็กให้ครบก่อนปิด)

  • golden 150 ราคา = baseline (ไม่มีกลุ่มอื่นพัง)
  • ปุ่ม/ชิป/การ์ด + default order = ดราฟ 100% (กลุ่มวัสดุ/รุ่น/สีต่อรุ่น/ความหนาชินโคล็อก/ลามิเนตซ่อนสีมุง)
  • ราคาหลัก 7 เคส (section 3.1) ตรงเป๊ะ · แป/โครงเหล็ก = ไม่ขยับยอด · ฝ้า 4 ชนิดตรง ceilCalc
  • สีโครง: L1 ตามทั้งใบ · L2🟢บวกยอด/🔵ไม่บวก+OPTION · L3 +/- ไม่บวก (ทดสอบเพิ่ม+ลด)
  • ใบ 5 กล่อง ลำดับถูก · swap line อยู่ OPTION · ⑤ แตกราคาไม่รวม noSum
  • เทียบสายตากับดราฟ (mirror) — หน้าตาเหมือน
แนะนำ: ทำ scripts/check-g3.mjs (ลอก check-g1) ใส่ EXPECTED จากดราฟ → รัน 1 คำสั่ง เห็น 🔴 ที่ยังไม่ตรง = ปิดงานเมื่อ 🔴 เหลือ 0
