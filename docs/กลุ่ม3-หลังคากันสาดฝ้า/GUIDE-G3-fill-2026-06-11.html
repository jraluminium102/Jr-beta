คู่มือกรอกใบเสนอราคา — กลุ่ม G3 (หลังคา / ฝ้า / ผนัง)

สำหรับคุณเฟิร์น · สอนกรอกครบทุกสินค้า ทุกช่อง 100% · เครื่องคิดราคา JR R3.9 · 11 มิ.ย. 2026
อ่านสัญลักษณ์ก่อน: ●คิดเงิน = กรอกแล้วราคาขึ้น · ●รวมแล้ว/ฟรี = ลงใบแต่ไม่บวกเพิ่ม · ●แสดงเฉยๆ = แค่พิมพ์ลงใบ ไม่กระทบราคา · ราคาปัดขึ้นหลักพันเสมอ

ส่วนที่ 1 — ขั้นตอนพื้นฐาน (เหมือนกันทุกสินค้า)

1
กดแท็บด้านบนสุด ใบเสนอราคา — ออปชั่นเต็มอยู่แท็บนี้ (อย่าใช้ “คิดเร็ว” เพราะใส่ของเสริมไม่ได้)
2
พิมพ์ ชื่อลูกค้า / งาน ในช่องบนสุด (เช่น “คุณสมชาย — บ้านเดี่ยว”)
3
กดปุ่ม + เพิ่มชุดถัดไป เพื่อเพิ่ม 1 รายการ (1 ชุด = 1 จุดงาน)
4
ช่อง กลุ่มงาน เลือก หลังคา / ฝ้า-ผนัง
5
ช่อง แบบ เลือกสินค้า (เช่น “หลังคา ไวนิล”) · ช่อง ตำแหน่ง พิมพ์ที่ติดตั้ง (เช่น “หลังคากันสาด หน้าบ้าน”)
6
กรอก กว้าง (ม.) และ สูง (ม.) — ระบบคิดพื้นที่ ตร.ม. × เรตให้อัตโนมัติ
7
ใส่ออปชั่นตามสินค้า (ดูส่วนที่ 2–4) → เสร็จกดปุ่มแดง ส่งเข้าระบบ JR — ออกใบเสนอราคา

ส่วนที่ 2 — หลังคา (ไวนิล · ดีไลท์ · โพลีตัน · ลามิเนต · เมทัลชีท · ชินโคไลท์)

หลังคาทุกชนิดใช้ช่องเหมือนกัน ต่างกันแค่ “สี/ฟิล์ม” ตามวัสดุ · ช่อง “ของเสริมหลังคา” ต้องกดแถบเขียว ＋ ของเสริมหลังคา ก่อนถึงจะเห็น

2.1 ช่องหลัก (เห็นทันทีหลังเลือกหลังคา)

ช่องตัวเลือกคิดเงิน?ลงใบว่าอะไร
สีวัสดุมุงไวนิล: สีเทา/ขาว/น้ำตาล · ดีไลท์: DG-2 ฟ้าคราม/DG-4 เทาโซล่าร์ · โพลีตัน: Opal 103/Clear 101/Bronze 107/… (8 สี)แสดงเฉยๆ“หลังคาไวนิล สีขาว” / “โพลีตัน … Opal 103 สีขาวขุ่น”
ชนิดฟิล์ม + ความหนา (เฉพาะลามิเนต)ฟิล์ม: ใส/เขียว/กันร้อน · หนา: 4+4 / 5+5 มม.แสดงเฉยๆ“หลังคากระจกลามิเนตใส ฟิล์มกันร้อน หนา 4+4 มม.”
สีเมทัลชีท / สีชินโคไลท์ (เฉพาะ imp)เมทัล: น้ำตาล/ขาว/เทา · ชินโค: Light Grey/Modern Grey · (เว้น “— ระบุสี —” = ไม่ลงสี)แสดงเฉยๆ“…รุ่น Heat Cut สี Light Grey”
แปแปเดี่ยว / แปคู่แสดงเฉยๆ“…ยื่นปลาย (แปคู่)”
โครงสร้างโครงอลูมิเนียม / โครงเหล็กชุบซิงค์เท่ากัน“โครงอลูมิเนียม สีอบขาว” / “โครงเหล็กชุบซิงค์ (ไร้สนิม)”
ปลายหลังคาปล่อย / รางน้ำ (เลือกรางน้ำ → เปิดช่องระบบรางน้ำ)รวมแล้วปล่อย→“ปล่อยปลาย/ไม่มีรางน้ำ” · รางน้ำ→บรรทัดรางน้ำ
ระบบรางน้ำ (เมื่อปลาย=รางน้ำ)ท่อ (สี ขาว/ดำ) / โซ่ (ลาย ทิวลิป-โลตัส + สี ขาว/น้ำตาล)รวมแล้ว“รางน้ำ (ท่อ สีขาว) + ตะแกรงพลาสติกกันใบไม้ สีดำ”
ตะแกรงกันใบไม้ติ๊ก (default ติ๊กไว้)รวมแล้ว“+ ตะแกรงพลาสติกกันใบไม้ สีดำ”
ท่อน้ำทิ้ง PVC 2.5″ไม่มี / สีดำ / ขาว / เทารวมแล้ว“ท่อน้ำทิ้ง PVC 2.5″ สีดำ”

2.2 หลังคาเลื่อน (ติ๊ก “ทำเป็นหลังคาเลื่อน”)

ช่องตัวเลือกคิดเงิน?ลงใบว่าอะไร
ทำเป็นหลังคาเลื่อนติ๊ก → เปิดช่องจำนวนบาน/มอเตอร์●คิดเงิน“ระบบหลังคาเลื่อน N บาน (มอเตอร์ N ตัว)”
จำนวนบานเลื่อนกดชิป 2 / 3 / 4 / 6 หรือปุ่ม − +●คิดเงินจำนวนบานในบรรทัดเลื่อน
มอเตอร์จำนวนตัว (ราคาออโต้ตามพื้นที่เลื่อน · กด “แก้ราคา” ถ้าต้องการพิมพ์เอง)●คิดเงินจำนวนมอเตอร์
ทำได้ทุกชนิดหลังคา (รวมเมทัลชีท + ชินโคไลท์)

2.3 หลังคาผสม 2 วัสดุในจุดเดียว (แถบส้ม “+ ต่อปลายวัสดุที่ 2”)

ช่องตัวเลือกคิดเงิน?ลงใบว่าอะไร
ต่อปลายวัสดุที่ 2เลือกหลังคาอีกชนิด (เช่น ไวนิลหลัก + ต่อปลายลามิเนต)●คิดเงิน“ต่อปลาย หลังคากระจกลามิเนต (พื้นที่ N ตร.ม.)”
พื้นที่ส่วนที่ 2กรอก ตร.ม. ของวัสดุที่ 2●คิดเงินคิด = วัสดุหลัก×(พื้นที่รวม−พื้นที่2) + วัสดุ2×พื้นที่2 (เรตแยก)

2.4 ของเสริมหลังคา (กดแถบเขียว ＋ ของเสริมหลังคา)

ช่องวิธีกรอกราคาลงใบว่าอะไร
รางน้ำ (เสริม)เลือกอลู S/สแตน M/สแตน L + ยาว(ม.)1,000–3,000/ม.“รางน้ำอลูมิเนียม”
คานเหล็กถักเลือกรุ่น1/2/3 + ยาว(ม.)2,400–4,400/ม.“คานเหล็กถัก”
เสาแผงกรอกจำนวนต้น4,000/ต้น“เสาแผง (เสริมเหล็กภายใน) จำนวน N ต้น”
เสา 4″x8″กรอกจำนวนต้น2,000/ต้น“เสา 4″x8″ จำนวน N ต้น”
โซ่รางน้ำกรอกจำนวนเส้น3,000/เส้น“โซ่รางน้ำ ลายดอกทิวลิป จำนวน N เส้น”
ปิดปลายกันน้ำกรอกยาว(ม.)1,000/ม.“ปิดปลายกันน้ำ”
ครอบท่อ PVCกรอกยาว(ม.)1,500/1.5ม.“ครอบท่อ PVC”
ซ่อนสโลปเลือกคอมโพสิต 3มม. / สมาร์ทบอร์ด 6มม. + สูง + ยาว/ด้าน + จำนวนด้าน3,500–4,000/ตร.ม.“ซ่อนสโลปหลังคาด้วยคอมโพสิต”
ปิดซ่อนรางกรอกกว้าง(ซม.) + สูง(ซม.) + ยาวรวม(ม.)ตามพื้นที่“ปิดซ่อนราง”
ครอบคานกรอกกว้างห่อ(ม.) + ยาวคาน(ม.)ตามพื้นที่“ครอบคาน”
วัสดุปิดรอยต่อแผ่นหลังคาติ๊ก + เลือกสี (ขาว/ดำ/เทา)แสดงเฉยๆ“วัสดุปิดรอยต่อแผ่นหลังคา สีขาว”
เสริมเพลทเหล็กล่าง / เหล็กดึงด้านบนติ๊กฟรี“เสริมเพลทเหล็กล่าง (รับล่าง)” / “เหล็กดึงด้านบน”

ส่วนที่ 3 — ฝ้า (ฝ้าอลู ไทยทิพย์ · ฝ้าไม้เทียม remood · ฝ้าฉาบเรียบ)

สินค้า / ช่องตัวเลือกคิดเงิน?ลงใบว่าอะไร
ฝ้าอลู ไทยทิพย์ — สีขาว-ดำ (2,100/ตร.ม.) / ลายไม้ (2,700/ตร.ม.)●ตามสี“ฝ้าอลูมิเนียม ไทยทิพย์ สีขาว-ดำ”
ฝ้าไม้เทียม remood — สีมาตรฐาน (2,600) / ลายไม้-สีอื่น (2,800)●ตามสี“ฝ้าไม้เทียม remood สีมาตรฐาน(ขาว-ซิลเวอร์)”
ฝ้าฉาบเรียบ — ทาสีทาสีขาว / ทาสีรองพื้นสีขาว / ไม่ทาแสดงเฉยๆ“ฝ้าฉาบเรียบ พร้อมทาสีขาว”
ฝ้าฉาบเรียบ — ฝ้าเฉียงตามแนวหลังคาติ๊กเท่ากัน“ฝ้าเฉียงตามแนวหลังคา”
ฝ้าฉาบเรียบ — ฉนวน 3″ติ๊ก+600/ตร.ม.“ฉนวนกันความร้อนและกันเสียง หนา 3″”
ฝ้าอลู/ไม้เทียม คิด ขั้นต่ำ 10 ตร.ม. (พื้นที่ต่ำกว่า 10 คิดที่ 10) · ฝ้าฉาบเรียบขั้นต่ำ 12,000 บาท

ส่วนที่ 4 — ผนัง (ISOWALL · ผนังเบาภายนอก · ผนังเบาภายใน)

สินค้า / ช่องตัวเลือกคิดเงิน?ลงใบว่าอะไร
ทุกผนัง — โครงโครงอลูมิเนียม / โครงเหล็กชุบซิงค์ (ไร้สนิม)เท่ากัน“โครงเหล็กชุบซิงค์ (ไร้สนิม)”
ทุกผนัง — ฉนวน 3″ติ๊ก+600/ตร.ม.“ฉนวนกันความร้อนและกันเสียง หนา 3″”
ISOWALL — ความหนา10 / 5 / 7.5 ซม. (ผนังใช้ 10 ซม.)แสดงเฉยๆ“แผ่น ISOWALL หนา 10 ซม.”
ISOWALL — สีพิมพ์เอง (เช่น ขาว)แสดงเฉยๆ“…สีขาว”
ผนังเบา นอก/ใน — สมาร์ทบอร์ดหนา12 / 20 มม. (ผนังใช้ 12 · 20=งานพื้น)แสดงเฉยๆ“แผ่นสมาร์ทบอร์ด หนา 12 มม.”
ผนังเบา นอก/ใน — ทาสีทาสีขาว / ทาสีรองพื้นสีขาว / ไม่ทาแสดงเฉยๆ“…พร้อมทาสีรองพื้นสีขาว”
ผนังทุกชนิดขั้นต่ำ: ISOWALL 7,000 · ผนังเบา 13,500 บาท

ตัวอย่างกรอกเต็ม 1 รายการ

โจทย์: หลังคากันสาดหน้าบ้าน ไวนิล 6×3.5 ม. มีรางน้ำท่อสีขาว + ท่อทิ้งดำ + เสาแผง 2 ต้น + ซ่อนสโลปคอมโพสิต

กรอก: แท็บ ใบเสนอราคา → กลุ่มงาน หลังคา/ฝ้า-ผนัง → แบบ หลังคา ไวนิล → กว้าง 6 สูง 3.5 → สีวัสดุมุง สีขาว → ปลายหลังคา รางน้ำ → ระบบ ท่อ สีขาว → ท่อ PVC สีดำ → กดแถบ ＋ ของเสริม → เสาแผง 2 → ซ่อนสโลป คอมโพสิต สูง 0.3 ยาว 6 ด้าน 2

ได้: ราคา ฿153,000 (ฐาน 21 ตร.ม. = 115,500 + เสาแผง 8,000 + ซ่อนสโลป 29,400 → ปัดขึ้นพัน) · ใบลงครบทุกบรรทัด
