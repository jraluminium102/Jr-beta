# ผูกสโตร์ ↔ คิดราคา 4.0 — ที่ทำไปแล้ว และที่ยังค้าง

อัปเดต 27 ส.ค. 2569

## สรุปตัวเลข

| ตอน | บรรทัดที่ "ผูกอะไรไม่ได้เลย" |
|---|---|
| ตอนเจ้าของท้วง | 272 |
| แก้หน้าตรวจให้นับถูก (มีรหัสแล้ว / ผูกตารางราคากลาง / ผูกราคากล่อง) | 148 |
| แยกค่าแรงออก (ไม่ใช่ของในสโตร์) | 130 |
| ผูกเพิ่มจริง (บานกระทุ้ง 8 · ชื่อ+ราคาตรงเป๊ะ 55 · รอบ 3 อีก 11) | **81** |

ที่เหลือ 81 บรรทัด = **สโตร์ไม่มีของนั้นจริง ๆ** หรือ **มีแต่ไม่ชัดว่าตัวไหน**

## วิธีที่ใช้ผูก (ไม่เดา)

สโตร์มีแถวผู้ขาย **"ถอดทุน R4.0"** 76 รายการ — ตั้งชื่อตรงกับบรรทัดในสูตรคิดราคา และราคาเท่ากันเป๊ะ
เป็นแถวที่ทำไว้ให้แก้ราคาทุน R4.0 อยู่แล้ว → ผูกเข้าไปได้เลย ราคาวันนี้ไม่ขยับสักบาท
กติกาที่ใช้: **ชื่อตรงเป๊ะ + ราคาตรงเป๊ะ เท่านั้น** ชื่อคล้าย/ราคาต่าง = ไม่ผูก

## ③ ไม่ต้องผูก (ตั้งใจแล้ว)

- **ค่าแรง/ค่าบริการ 18 บรรทัด** — ค่าแรงผลิต/ติดตั้ง · ค่าเปิดตู้อบ · ค่าดัดโค้ง · ปัดขึ้นหลักร้อย
  ไม่ใช่ "ของ" หน้าตรวจแยกป้ายให้แล้ว (ยกเว้น **ค่ากรีดราง** ที่สโตร์มีแถวจริง JR00202 → ผูกแล้ว)
- **ราคาบาน (สั่งร้านอื่น)** บานเปิดดัดโค้ง — ของสั่งนอก ใช้ธง "ไม่สต็อก สั่งใหม่"
- **ใบระแนง/กล่อง A/กล่อง B/โครงดาม/เส้นฝ้า/ฉากเก็บขอบ** — ราคามาจากตารางกล่องระแนงกับตารางฝ้าอยู่แล้ว
- **ชินโคร์ Nature/Shade/Prime/Grand** — ยังไม่มีราคาทุน (รอกรอก Excel) ไม่เกี่ยวกับการผูกสโตร์

## ⑤ ⚠ เรื่องเงิน — ราคาสูตร vs ราคาสโตร์ ไม่ตรงกัน 39 บรรทัด (ระบบใช้ราคาสโตร์อยู่แล้ว)

พวกนี้ **ผูกสโตร์ไว้ก่อนหน้านี้แล้ว** ระบบเลยคิดด้วยราคาสโตร์ ไม่ใช่ราคาในชีตถอดทุน
ไม่ได้เกิดจากงานรอบนี้ แต่เพิ่งเห็นชัดเพราะหน้าตรวจนับถูกแล้ว

### ตัวที่ต้องเช็คด่วนที่สุด

**Velora บานเปิด — บานพับ อาจคิดเกิน 4 เท่า**

| | |
|---|---|
| สูตรคิดราคา | 110 บาท × **4 ตัว/บาน** = 440 /บาน |
| ชีตถอดทุน | 440 /บาน |
| สโตร์ JR00560/JR00561 "บานพับ velora เวโลร่า" | **440 ต่อ "ชิ้น"** |
| ระบบคิดจริงตอนนี้ | 440 × 4 = **1,760 /บาน** |

440 ในสโตร์ตรงกับ "ยอดต่อบาน" เป๊ะ → น่าจะกรอกราคาชุด 4 ตัวลงในช่องราคาต่อชิ้น
**ถ้าใช่** ต้องแก้ราคาสโตร์เป็น 110 (หรือใส่ per = 4 ในสูตร) — ตอนนี้ Velora ทุนเกินไป 1,320/บาน
**ถ้าบานพับตัวละ 440 จริง** ก็ถูกแล้ว ไม่ต้องแก้ แต่ชีตถอดทุนเก่าไป
