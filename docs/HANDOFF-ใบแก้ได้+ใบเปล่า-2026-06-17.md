# HANDOFF — ใบเสนอราคา: แก้ได้ทั้งใบ + ใบเปล่า · 17 มิ.ย. 2026

> ต่อยอดของเดิม (qEdit) — เพิ่มแค่ "เพิ่ม/ลบแถว" + "ใบเปล่า" · ดราฟ: `public/DRAFT-ใบแก้ได้+ใบเปล่า-2026-06-17.html`
> 🔑 **มติพี่นัท: การแก้ = ชั่วคราว เฉพาะใบนั้น · ไม่บันทึกไปรอบหน้า** (กันการแก้ลูกค้าเก่าติดใบลูกค้าใหม่)

## ของเดิมที่มีแล้ว (ไม่ต้องทำใหม่)
- `toggleQuoteEdit()` (L5144) ปุ่ม "✎ แก้ทุกข้อความ" — แก้ ชื่อ/รายละเอียด/ราคา/เงื่อนไข/หัวบริษัท (contenteditable) · เก็บ override ใน `_nameOv`/`_detOv`
- ปุ่ม reset (`qResetBtn`) · พิมพ์/PDF (`window.print` L500)

## ที่ต้องเพิ่ม
### 1. เพิ่ม/ลบ แถว (core — ใช้ทั้ง 2 เรื่อง)
- โหมดแก้ (qEdit on) → โชว์ปุ่ม **"+ เพิ่มแถว"** (ท้ายตาราง) + **🗑 ลบ** (ท้ายแต่ละแถว)
- แถวที่เพิ่ม = เก็บใน array ชั่วคราว (เช่น `_extraRows[]`) · render ต่อท้ายใน genQuote · ทุกช่อง contenteditable เหมือนแถวปกติ
- ลบแถว = mark hidden/ตัดออกจาก render (ชั่วคราว · ไม่แตะ item จริง)

### 2. ใบเปล่า (= เรื่อง ข)
- ปุ่ม **"📄 เริ่มใบเปล่า"** → genQuote ออกใบว่าง (ไม่มี item) + เปิด qEdit + ใส่ 1 แถวเปล่าให้เริ่มกรอก · หัวบริษัท/เงื่อนไขมาตรฐานคงไว้ (แก้ได้)

### 3. 🔑 ล้างเมื่อขึ้นใบใหม่ (สำคัญสุด — ไม่ติดรอบหน้า)
- เมื่อ **ล้างฟอร์ม / เลือกลูกค้าใหม่ / เริ่มใบใหม่** → **เคลียร์ `_nameOv` `_detOv` `_extraRows` + ปิด qEdit**
- หา จุดที่ reset ฟอร์ม/เปลี่ยนลูกค้า แล้วเรียก clear overrides ด้วย (เดิมอาจไม่ได้ล้าง override → edit เก่าติดมา = บั๊ก)

### 4. ป้ายเตือน
- โหมดแก้เปิด → โชว์แถบ "✏️ การแก้เฉพาะใบนี้ · ไม่บันทึกถาวร · เริ่มใบใหม่=ล้างหมด"

## เช็คหลังแก้
- ☐ กดแก้ → เพิ่มแถว/ลบแถว/แก้ทุกช่องได้ · พิมพ์ PDF ออกถูก
- ☐ ใบเปล่า → ว่าง + กรอกมือ + พิมพ์ได้
- ☐ **ขึ้นใบใหม่/ลูกค้าใหม่ → การแก้+แถวเพิ่ม หายหมด** (กลับค่าเครื่องคิด)
- ☐ golden ไม่กระทบ (นี่เป็นชั้น display/override · ไม่แตะ engine ราคา)
