0. หลักการเดียว (ห้ามพลาด)

เปลี่ยนแค่ หน้าตา control (UI) — ไม่แตะ logic/ราคา/ใบ. วิธี:

  • ไม่ลบ <select> เดิม — แค่ style="display:none;"
  • ชิป (ปุ่ม) เป็นหน้ากาก → กดแล้ว set value กลับเข้า select เดิม + ยิง change
  • มี helper พร้อมใช้แล้ว: chSetChip(this,'ชื่อ-class-ไม่มีจุด') (บรรทัด ~2139) — ใช้ตัวนี้เลย
  • ห้ามเปลี่ยน value หรือชื่อ class ที่ logic อ่าน (readItem/calcQuote)
ทำไมราคายังอัปเดตเอง: บรรทัด ~2309 ผูก change→calcQuote ให้ทุก input/select ในกล่อง opts อยู่แล้ว → ชิปยิง change ผ่าน chSetChip ราคาคำนวณใหม่อัตโนมัติ ไม่ต้องเติม onchange เอง

2. เรียงลำดับใหม่ + รวบเป็นกล่องเดียว

ของ "ตู้อลู" 6 ช่องกระจาย → รวบเป็นกล่อง "รายละเอียดตู้" เรียง "นี่คืออะไร" ก่อน:

  1. ประเภทตู้ (ชิป) — เลือกก่อน เพราะตั้ง สูง/ลึก ให้อัตโนมัติ
  2. จำนวนบานหน้าตู้ (ชิป)
  3. ชนิดชั้น (ชิป)
  4. ลึก / จำนวนชั้น (number · ป้าย auto) — แถวเดียว 2 ช่อง
  5. +ผนังหลัง (checkbox/pill)

ฝาตู้: ประเภท (ชิปอยู่แล้ว) → สีฝาตู้ (ดรอปดาวน์) — ตามเดิม

3. ⚠ จุดที่ต้องระวังที่สุด — listener auto สูง/ลึก ของ cabtype

บรรทัด ~2754 มี listener: เมื่อ .o-cabtype เปลี่ยนเป็น shoe → set .i-h=2.0, .o-depth=0.4 · ถ้าไม่ใช่ → .i-h=2.4, .o-depth=0.6

เพราะชิปยิง change ผ่าน chSetChip → listener นี้ยังทำงานครบ ✅ แต่ ต้องเทสยืนยัน: กดชิป "ตู้รองเท้า" แล้ว สูง/ลึก ต้องเด้งเป็น 2.0/0.4 จริง

4. Pattern โค้ด (ก็อปวางได้)

แทนที่ <select class="o-cabdoors">...</select> เดิมด้วย ชิป + select ซ่อน:

// ในกล่อง "รายละเอียดตู้" — ตัวอย่าง จำนวนบาน (o-cabdoors)
h+='<label class="opt" style="width:100%;">จำนวนบานหน้าตู้'
 +'<div class="chip-group chip-sm">'
 +'<button type="button" class="chip" data-val="1" onclick="chSetChip(this,\'o-cabdoors\')">1 บาน</button>'
 +'<button type="button" class="chip on" data-val="2" onclick="chSetChip(this,\'o-cabdoors\')">2 บาน</button>'
 +'<button type="button" class="chip" data-val="3" onclick="chSetChip(this,\'o-cabdoors\')">3 บาน</button>'
 +'</div>'
 +'<select class="o-cabdoors" style="display:none;"><option value="1">1 บาน</option><option value="2" selected>2 บาน</option><option value="3">3 บาน</option></select>'
 +'</label>';

ทำซ้ำแบบเดียวกันกับ .o-cabtype (2 ชิป) และ .o-shelfmat (3 ชิป) · ชิปตัว default ใส่ class on · select ซ่อนคง selected ให้ตรงกัน · อ้างอิงชิปที่ทำสำเร็จแล้วในไฟล์: .o-slidelock (~2459), .o-bottomrail (~2448)

helper มีอยู่แล้ว (อย่าเขียนใหม่): chSetChip(btn, selectClass) บรรทัด ~2139 — มันหา .ch การ์ดเดียวกัน, ปลดชิปพี่น้องที่อ้าง selectClass เดียวกัน, ใส่ on, แล้ว set value + ยิง change(bubbles) ให้ select ซ่อน · scope ปลอดภัยต่อหลายการ์ด

7. Definition of Done

  • render ครบทั้ง 2 สินค้า — ชิปโผล่เฉพาะที่ควร ไม่หลุดไปสินค้าอื่น
  • node test/quote-fidelity.mjs PASS (ราคา/ใบ ไม่เพี้ยนเทียบ baseline)
  • readItem ยังอ่าน .o-cabdoors / .o-cabtype / .o-shelfmat value เดิมครบ
  • listener auto สูง/ลึก (cabtype) ยังทำงานหลังเปลี่ยนเป็นชิป
  • พี่นัทกดดราฟผ่าน + เทียบหน้าจริงตรงดราฟ
เตือน dev:
  • ห้ามแตะ value: 1/2/3 (cabdoors), wardrobe/shoe (cabtype), ""/alu/glass (shelfmat) — logic + readItem อ่านตรงตัว
  • สีฝาตู้ .o-ftcolor = label/ราคาพิเศษ → อย่าเปลี่ยนเป็นชิป (12 ตัว)
  • ชิป default ต้องตรงกับ selected ของ select ซ่อน (กันค่าตั้งต้นเพี้ยน)
