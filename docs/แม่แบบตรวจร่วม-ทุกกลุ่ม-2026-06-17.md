> รวม "ความผิดพลาดที่เจอจริงแต่ละกลุ่ม" → เช็คลิสต์เดียว · **ทุกแชท A เอาไปตรวจกลุ่มตัวเอง + ตรวจสลับกลุ่มกัน** (กันผิดซ้ำ/สลับ)
> วิธีใช้: เปิดไฟล์นี้ → ไล่ติ๊กทีละข้อกับกลุ่มของตัว → เจอ = ส่งคิวกลาง · ออกแบบฟอร์มให้ตรง "แม่แบบ" ด้านล่าง

## 🚨 PART 1 — เช็คลิสต์ "บั๊ก" (เรียงตามอันตราย)

### 🔴 1. บั๊กการเงิน — option บวกยอดจริงไหม (เจอบ่อยสุด!)
- เจอจริง: **G5 สีกรอบมุ้งเฟร + ครอบวงกบมุ้ง = โชว์ในใบแต่ไม่บวกเงิน** (undercharge) · เคยเจอ **มุ้ง addon ไม่เข้า sell** (มิ.ย.)
- ✅ วิธีเช็ค: ทุก option ที่ "มีราคา" → ติ๊กแล้ว **ยอดรวมต้องขึ้นจริง** (เทียบ golden ก่อน-หลัง) · ระวัง `return` ก่อนโค้ดคิดเงิน
- **ทุกกลุ่มต้องเช็คข้อนี้** — เป็นบั๊กที่เงียบและแพงสุด

### 🔴 2. คำเตือน "ภายใน" หลุดขึ้นใบลูกค้า
- เจอจริง: **G5 "ห้าม PC" / "ตัด PC"** หลุดขึ้นใบ (เป็นกฎจับคู่ภายใน ไม่ใช่สเปคลูกค้า)
- ✅ เช็ค: ชื่อสินค้า/ออปชั่นมีคำเตือน logic (ห้าม.../ตัด.../เช็ค KC) โผล่ในใบไหม → ตัดออก (logic กันที่ deny_with/allow_with)

### 🟡 3. typo / ชื่อผิด
- เจอจริง: G5 "รุ่ง"→"รุ่น" · G3 "Grang"→"Grand" · ดีไลท์ DG-4→DG7
- ✅ เช็ค: อ่านชื่อสินค้า/สีทุกตัวในกลุ่ม

### 🟡 4. สีพิเศษ "มีรหัส" ไหม
- เจอจริง: G3/G4 สีอบพิเศษ/ชุบ ต้องระบุรหัสสีในใบ (hasCode)
- ✅ เช็ค: สีที่ไม่ใช่มาตรฐาน → ใบมีช่อง/คำว่า "รหัส" ไหม

## 🧬 PART 3 — แม่แบบฟอร์มมาตรฐาน (ทุกกลุ่มจัดให้ตรงนี้)
ลำดับในฟอร์มกรอก (บนสุด→ล่าง):
1. **เลือกชนิด/รุ่น** = ชิป (drill ถ้าเยอะ) · ไม่ดรอปดาวน์ยาว
2. **ขนาด** (กว้าง/สูง/ชุด)
3. **สี/กระจก** = เลือกทีละชั้น + จุดสี (รายบาน) · ทั้งใบ = ดรอปดาวน์เล็กบนสุด
4. **ออปชั่นใช้บ่อย** (มือจับ·ล็อค·มุ้ง·คาดตาราง) = เปิดกลุ่มไว้ · ชิป
5. **ออปชั่นใช้น้อย** (ครอบวงกบ·ดรอปพื้น·ธรณี·รื้อ) = พับ
6. **OPTION ทางเลือกลูกค้า** = โชว์เลย กดประเภท→เลือก→คิดราคา
7. **หมายเหตุ** = ติ๊กหลายข้อ (preset กลาง)
8. **ใบออก** = 5 บล็อก (รายการบน/รายละเอียดล่าง) · ปุ่มแก้ทั้งใบ (ชั่วคราว ไม่ติดรอบหน้า)
