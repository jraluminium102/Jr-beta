🟡 P2 — ควรแก้

  1. P2-1หัวข้อ hard-code “พร้อมมุ้งจีบ” — เลือกชนิดอื่น (นิรภัย/ม้วน) แต่หัวข้อยังขึ้น “จีบ”. แก้: ใช้ชื่อชนิดจริงจาก mosqId. ไฟล์ ~บรรทัด 2847.
  2. P2-2ราวกันตก: ชนิดกระจก + ราวเหล็ก — ใบจริงใช้เทมเปอร์ 10/12 แต่ระบบออก “ใส 6”; และไม่มี “ราวกันตกเหล็ก”. แก้: ให้ราวเลือกชนิด/ความหนากระจกได้ + เพิ่ม variant เหล็ก. (เช็คซ้ำว่าราวเปลี่ยนกระจกได้อยู่แล้วหรือไม่)
  3. P2-3งานประกอบที่ขาด — พัดลมดูดอากาศ 8"+ฝาครอบกันแมลง, เสริมโครงรับม่าน, โฟเมก้า/กระจกเงา 2 ด้าน. แก้: เพิ่มเป็น option/preset หรืออย่างน้อยทำ custom_item ให้กรอกง่าย.

🟦 P3 — ปรับให้เหมือนจริงขึ้น

  1. P3-1ครอบวงกบเป็น option “จำนวนด้าน” ต่อบาน (3/4 ด้าน) แทน product แยกบรรทัด — ใบจริงเขียนรวมในด้านนั้น.
  2. P3-2รายละเอียดหลังคาละเอียดขึ้น — ท่อ PVC ขนาด/สี, โซ่ลาย/สี/จำนวนจุด, “ปล่อยปลายไม่มีราง / ยื่นปลาย”, เสริมเพลทเหล็ก/เหล็กดึง (ตอนนี้ตายตัว “โซ่ลายโลตัส สีน้ำตาล”).
  3. P3-3รุ่นมือจับเฉพาะ (HD182/X-J/Berin/SlimLux/Digital X2) + “โชว์คาน/ซ่อนคาน” เป็น label — อิงลิสต์ในเอกสาร QC ที่มีราคาครบ.
  4. P3-4ชื่อสีลายไม้ ให้ตรงคำลูกค้า (Golden Teak SMS, ไวท์แบมบู KL19022WD) — ตอนนี้ต้องไปทาง “ลายไม้อบพิเศษ + รหัส”.
  5. P3-5เดินไฟดาวน์ไลท์ N ดวง เจาะจงจำนวน (ตอนนี้ generic 2 ดวง).
