ชั้นข้อมูลใบจริงเขียนอะไร (ตัวอย่าง)ระบบออกอะไรผลroot cause
1. ชื่อโซนรายการ"ประตูหน้าบ้าน (ชุดยูโร)", "Shower ห้องน้ำโซนสระ ชั้น1""ประตู โถงหน้าบ้าน", "หน้าต่าง ห้องนอนใหญ่"✅ชื่อชุด/โซน รองรับ
2. บรรยายเต็มประโยค"บานเลื่อนสลับรางล่าง (รุ่นกันน้ำ) แบ่ง 2 บาน + กระจกติดตายด้านข้าง + มุ้งนิรภัย""บานเลื่อนรางล่าง (รุ่นกันน้ำ) แบ่ง 4 บาน (มีมุ้งจีบ) (รุ่น L ยูโร) (3.6×2.4 ม.)"✅ประกอบจากชื่อ+addon+ขนาด ได้
3. OPTION ทางเลือก"หากเปลี่ยนเป็น...ราคาลดลง 4,000 บาท" (×2 ต่อรายการ)"OPTION : เปลี่ยนเป็นกระจกลามิเนต...ราคาเพิ่มตามจริง"✅oc-row free text + ราคา ±
4. หมายเหตุมาตรฐาน"ราคาที่เสนอรวมงานรื้อประตูเดิม/ดรอปพื้น...แต่ไม่รวมวัสดุ (ลูกค้าเตรียมให้)" + "ไม่รวมเจาะเสาใส่ Digital Door Lock" — มีทุกรายการมีแค่ช่องโน้ตอิสระ (พิมพ์เอง) — ไม่มี template เงื่อนไข🔴 ขาดgenQuote ไม่มี standard remark · checkbox รื้อ ไม่ผลิตย่อหน้าเงื่อนไข
5a. รายละเอียด: อลู/สี"อลูมิเนียมลายไม้ สีไวท์โอ๊ค""อลูมิเนียม สีดำ / ลายไม้ (ไวท์โอ๊ค มีในระบบ)"✅COLORS มีไวท์โอ๊ค/สักทอง/โอ๊ค
5b. รายละเอียด: กระจก"กระจกเทมเปอร์ใส 6/10/12 มม.", "ลามิเนต 4+4 กันร้อน""กระจกใส/เขียว หนา 6 มม." (เลือกชนิดได้ครบ)✅GLASS มีครบ
5c. รายละเอียด: สีเฟรมมุ้ง"มุ้งจีบ (เฟรมลายไม้สีไวท์แบมบู (KL19022WD)/ผ้าไฟเบอร์ดำ)""มุ้งจีบ ผ้าไฟเบอร์ดำ" — ไม่มีสีเฟรม🔴 ขาดสีเฟรมมุ้งไม่ถูก render ลงใบ (ตรงบั๊ก BUG-001/F-07)
5d. รหัสสีเฉพาะ"ไวท์แบมบู (KL19022WD)" (รหัสรุ่น)มีแค่ชื่อสี ไม่มีรหัสรุ่น (KL19022WD = ไม่พบ)🟡 บางส่วนCOLORS ไม่เก็บรหัสรุ่น/ชื่อย่อย
6. งานหลายด้าน A-Fหลังคากันสาด ด้าน A-F (เปลือยสวิง/ราวกันตกกระจกสลับกัน) + หลังคาลามิเนตยื่นปลาย ปล่อยปลาย/ไม่มีรางน้ำกั้นห้อง/หลายด้าน auto-label A/B/C + หลังคา + ปล่อยปลายไม่มีรางน้ำ (แก้แล้ว)🟡 เช็คซ้ำต้องยืนยันว่าได้ถึงด้าน F + ราวกันตกกระจกต่อด้าน (verify รอบเต็ม)

สรุป Gap (จาก pilot ใบเดียว)

🔴 GAP-1 — หมายเหตุมาตรฐานหายทั้งหมด (ตัวการหลักที่ทำให้ "ไม่เหมือนใบจริง")

ใบจริงมีย่อหน้าเงื่อนไขใต้ทุกรายการ (รวมงานรื้อ/ดรอปพื้น · ไม่รวมวัสดุ · ไม่รวมเจาะเสา Digital Door Lock) — ระบบไม่มีเลย
  • เสนอแก้: ทำชุด "หมายเหตุมาตรฐาน" (template ตามชนิดงาน) ให้ติ๊กเลือก/auto ใส่ลงใบ · มีช่องแก้ข้อความได้

🔴 GAP-2 — สีเฟรมมุ้งไม่ขึ้นในรายละเอียดงาน

ใบจริงระบุสีเฟรมมุ้ง + ผ้า · ระบบออกแค่ผ้า → ตรงกับบั๊ก BUG-001/F-07 ที่เจอใน QA
  • เสนอแก้: render สีเฟรมมุ้งลง "รายละเอียดงาน" (ผูกกับ optSel สีกรอบมุ้งที่เพิ่งเพิ่ม)

🟡 GAP-3 — รหัสสี/ชื่อรุ่นย่อยไม่มี

สีไม้หลักมี (ไวท์โอ๊ค/สักทอง/โอ๊ค) แต่ไม่มีรหัสรุ่น (เช่น ไวท์แบมบู KL19022WD)
  • เสนอแก้: เพิ่มชื่อรุ่น/รหัสในตาราง COLORS (เฉพาะที่ใบจริงใช้บ่อย)

สิ่งที่ระบบทำได้ดีแล้ว (ไม่ต้องแก้)
