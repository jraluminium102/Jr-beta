จุดที่ 1 — ชื่อหัวข้อ OPTION ยังผิด (กระทบทุกหลังคา · พี่นัทเห็นหน้าจอ)

ตอนนี้ (ผิด)＋ OPTION ทางเลือกลูกค้า (เปลี่ยนกระจก/มุ้ง/สี/มือจับ/หลังคา · คิดราคาให้)
ควรเป็น (หลังคา)＋ OPTION ทางเลือกลูกค้า (เปลี่ยนสี / วัสดุมุง / หลังคา · คิดราคาให้)

เหตุ: แก้แค่ตัวเลือกใน dropdown (ocCatOptions) แล้ว แต่ "ชื่อหัวข้อ" (.oc-block > summary) ยัง hardcode คงที่ทุกสินค้า ใน template addItem (ราว L2334)

วิธีแก้ (ทำให้ชื่อ sync ตามสินค้า เหมือน dropdown): เพิ่มท้ายฟังก์ชัน buildItemOpts(d) — หลังสร้าง .i-opts เสร็จ (จุดที่ .o-roofend ถูกสร้างแล้ว):

var _ocSum = d.querySelector('.oc-block>summary');
if(_ocSum){
  var _isRoof = !!(d.querySelector('.o-roofend') || d.querySelector('.o-roofbatten'));
  _ocSum.textContent = _isRoof
    ? '＋ OPTION ทางเลือกลูกค้า (เปลี่ยนสี / วัสดุมุง / หลังคา · คิดราคาให้)'
    : '＋ OPTION ทางเลือกลูกค้า (เปลี่ยนกระจก/มุ้ง/สี/มือจับ/หลังคา · คิดราคาให้)';
}

// ใช้ _isRoof เงื่อนไขเดียวกับ ocCatOptions → ชื่อหัวข้อกับ dropdown ตรงกันเสมอ · buildItemOpts รันทุกครั้งที่เปลี่ยนสินค้า ชื่ออัปเดตตามกลุ่มเอง

จุดที่ 2 — label "รางน้ำ" ขัดกับมติ (รางน้ำต้องคิดเงิน)

ตอนนี้ (ขัด)ปลายหลังคา → "รางน้ำ (รวมในราคาหลังคา)" · แต่ "ชนิดราง อลู S 1,000/ม." คิดเงินจริง → ข้อความขัดกัน
แก้เป็น"รางน้ำ (คิดตามชนิด/ความยาว)"

เหตุ: มติพี่นัท = เรตหลังคาเป็น "ราคาเปล่า" · รางน้ำคิดเพิ่ม 1,000/ม. × ความยาว (FIX-13) · ข้อความ "(รวมในราคาหลังคา)" เป็นของเก่าค้าง ทำให้เข้าใจผิดว่าฟรี

วิธีแก้: ในตัวสร้างชิป "ปลายหลังคา" (roof end option · ราว L2662) แก้ string

'รางน้ำ (รวมในราคาหลังคา)'  →  'รางน้ำ (คิดตามชนิด/ความยาว)'

// แก้แค่ข้อความ ไม่แตะ calc — ราคารางน้ำคิดจากกล่อง "ชนิดราง × ยาว" อยู่แล้ว (ถูกต้อง)

เช็คหลังแก้

เลือก "หลังคา ไวนิล" (กลุ่ม 3) → (1) หัวข้อ OPTION = "เปลี่ยนสี / วัสดุมุง / หลังคา" · (2) ปลายหลังคา = "รางน้ำ (คิดตามชนิด/ความยาว)" · (3) node test/quote-fidelity.mjs = PASS (ราคาไม่เปลี่ยน เพราะแก้แค่ label)
