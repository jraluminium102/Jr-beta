C. ปลายหลังคา = 3 ตัวเลือก เลือกอย่างเดียว (มติพี่นัท · แตะ logic)

เดิม o-roofend มี 2 ค่า: ปล่อย / รางน้ำ · "ปิดปลายกันน้ำ" (o-rfeave) แยกอยู่ในของเสริม (L2678) · มติ: รวมเป็น 3 ตัวเลือก single-select เพราะปลายหลังคาเลือกได้แบบเดียว

① เปลี่ยน o-roofend เป็น 3 ค่า:

ปลายหลังคา:  ปล่อย  |  มีรางน้ำ  |  ปิดปลายกันน้ำกระเด็น   // เลือกได้อย่างเดียว (ชิป/segmented)
  • ปล่อย → ไม่มีราง ไม่มีปิดปลาย
  • มีรางน้ำ → โชว์กล่องรางน้ำ (o-guttersys-wrap: ระบบระบาย ท่อ/โซ่ + ชนิดราง o-rfgut + ความยาว)
  • ปิดปลายกันน้ำกระเด็น → โชว์ความยาว (ใช้ o-rfeave เดิม 1,000/ม.) · ย้าย o-rfeave ออกจากของเสริม (L2678) มาที่นี่

② ช่องความยาว 1 ช่อง ใช้ร่วม · default = ความยาวหลังคา (i-w = ด้านยาว)

logic ราคา (สำคัญ):
— ถ้า "มีรางน้ำ" → ราคา = เรตราง (o-rfgut) × ความยาว
— ถ้า "ปิดปลายกันน้ำกระเด็น" → ราคา = 1,000 × ความยาว (สูตร o-rfeave เดิม)
— ถ้า "ปล่อย" → 0
ทั้ง 2 แบบกรอก "ความยาว" ช่องเดียวกันได้ (เพราะเลือกอย่างเดียว) · default เติม i-w (ด้านยาว) ให้อัตโนมัติ ตอนเลือก "มีรางน้ำ"/"ปิดปลายกันน้ำ" (onchange เดิมเติม gl.value=iw.value อยู่แล้ว ใช้ pattern เดียวกัน)
readItem/calc: อ่าน o-roofend 3 ค่า → branch ราคาให้ถูก · o-rfeave ไม่อยู่ในของเสริมแล้ว (อ่านจากกล่องปลายหลังคาแทน) · ระวัง quote text genQuote (~L3768) ให้ลงใบตามตัวเลือกที่เลือก

E. รางน้ำรุ่น M = อลูมิเนียม (ไม่ใช่สแตนเลส) · มติพี่นัท

① label ชนิดราง (o-rfgut · L2672):

<option value="2000">สแตนเลส M 2,000/ม.</option>
<option value="2000">อลูมิเนียม M 2,000/ม.</option>   // value/ราคา 2,000 เท่าเดิม เปลี่ยนแค่ชื่อวัสดุ

② ข้อความวัสดุในใบ (genQuote · L3777):

const _gmat = (parseFloat(_os.rfgut)||0)>=2000 ? 'รางน้ำสแตนเลส' : 'รางน้ำอลูมิเนียม';
const _gmat = (parseFloat(_os.rfgut)||0)>=3000 ? 'รางน้ำสแตนเลส' : 'รางน้ำอลูมิเนียม';
// เดิม: 2000(M)+3000(L)=สแตนเลส · ใหม่: เฉพาะ 3000(L)=สแตนเลส · 1000(S)+2000(M)=อลูมิเนียม
เช็คซ้ำ (พี่นัทยืนยันแล้วว่าเปลี่ยนแค่ชื่อ): ราคา รุ่น M คงเดิม 2,000/ม. — ถ้าอลูมิเนียมควรถูกกว่าสแตนเลส ค่อยแจ้งแก้ value ทีหลัง
หมายเหตุ: "ปิดซ่อนราง" (o-rfgcw/ch/cl) ไม่ต้องแตะ — คงเดิมทุกอย่าง (พี่นัทยืนยัน)
