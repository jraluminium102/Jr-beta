5. Checklist UX กดเว็บจริง (สำหรับพี่นัท/ux-designer เปิดเว็บ live กดเช็ค)

หมายเหตุ: รายการด้านล่างเป็น checklist สำหรับ กดเว็บจริง เท่านั้น · JR Audit Agent ไม่เคลมว่าตรวจ UX เองได้ (ต้องคน/browser จริง)

กลุ่ม A: Format ใบออก

เปิดใบเสนอราคาตัวอย่าง → ตรวจว่ามีตาราง # | รายละเอียด | จำนวน | ราคาต่อหน่วย | ยอดรวม ครบ
เปรียบกับ QT2025070050 (ชวลิต)
ตัวเลขเป็นคำไทยใต้ตาราง (เช่น "หนึ่งล้านแปดแสน..." ตรงกับยอดจริง)
ตรวจ 2 ใบ: มียอด VAT 7% และ VAT 0%
ช่องเซ็น "ในนาม" โผล่ครบ ทั้งช่องลูกค้าและช่องบริษัท
หัวบริษัท logo/ที่อยู่/เบอร์โทร ถูกต้อง
VAT toggle: สลับ VAT 0% ↔ 7% → ตาราง summary อัปเดตถูกต้อง

กลุ่ม B: ความครบของออปชั่น

เพิ่มรายการ "บานเลื่อน ยูโร" → กรอกขนาด → ตรวจว่า option มุ้ง / มือจับ / ดรอปพื้น / ครอบวงกบ โผล่ครบ
เพิ่มรายการ "บานเฟี้ยม ยูโร" → ตรวจว่า option คานซัพพอร์ท / รางยู โผล่หรือไม่ (ถ้าไม่โผล่ = ต้องใช้ custom_item)
กลุ่ม G6 เพิ่มห้อง → กรอก 3+ ด้าน → ตรวจว่าออก PDF แยกห้องครบ
เพิ่ม custom_item → กรอกชื่อ "งานต่างจังหวัด" ราคา 49,000 → โผล่ในใบเป็นบรรทัดแยก
เลือกมือจับ C-mech → กรอก note "HD182 60ซม. สีดำ" → โผล่ในรายละเอียดใบ

กลุ่ม C: ราคา / ส่วนลด

กรอกส่วนลดค่าประเมิน 2,000 → ตรวจว่ายอดรวมลดถูกต้อง
กรอกส่วนลด % + ส่วนลดบาท พร้อมกัน → ยอดรวมคำนวณถูกต้อง
ราคา roof_chain (โซ่รางน้ำ) 3,000/เส้น × 2 = 6,000 → ตรวจ
ดรอปพื้น = 5,000 สำหรับช่วงแรก (เช็คสูตรกับ pricelist)

กลุ่ม D: UX / มือถือ

เปิดบนมือถือ (iPhone/Android) → กรอกขนาดได้ → ราคาอัปเดต → ไม่มี layout พัง
กลุ่ม G6 เพิ่มห้องใหม่ → ลบห้อง → ยอดรวมอัปเดตถูกต้อง
พิมพ์/บันทึก PDF บนมือถือ → ได้ไฟล์ PDF ที่อ่านได้ ไม่แตกหน้า

กลุ่ม E: รายการที่ต้อง custom_item (ตรวจ flow)

เพิ่ม "รายการกรอกเอง" → กรอกชื่อ "Skylight ห้องนอนใหญ่ชั้น 2" ราคา 57,000 → โผล่ในใบถูกต้อง
ทดสอบ flow สำหรับสินค้าที่ไม่มีในระบบ
เพิ่ม "ชุดกุญแจมาสเตอร์คีย์ 4 บาน" ผ่าน custom_item → โผล่ถูกต้อง
เพิ่ม "พัดลมดูดอากาศ 8" ผ่าน custom_item → โผล่ถูกต้อง
