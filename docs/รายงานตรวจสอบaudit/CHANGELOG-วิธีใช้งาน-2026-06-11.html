📌 ส่วน A — ของใหม่ที่เปลี่ยน "วิธีกรอก" (อ่านก่อนลองเล่น)

จุดเหล่านี้ หน้าตา/วิธีกดเปลี่ยนไป จากเดิม — ราคาและผลในใบเหมือนเดิม แต่กรอกเร็วขึ้น/แตะง่ายขึ้นบนมือถือ

A1. ฟอร์มกรอกบาน (G1) — เรียงใหม่ + ปุ่มชิป

ลำดับช่องใหม่: กลุ่มงาน → แบบ (เลื่อนขึ้นมาเป็นช่องที่ 2 แล้ว ไม่ต้องเลื่อนหา) → ประเภท → ด้าน/ตำแหน่ง → กว้าง×สูง → …

ช่องที่เป็น "ปุ่มชิป" แทน dropdown (กดปุ่มเลย ไม่ต้องเปิด dropdown):
ประเภท: ประตูหน้าต่าง  ·  ราง: รางกันน้ำรางเตี้ย  ·  ชุดล็อค: มีกุญแจไม่มีกุญแจ
เสริมคาน · แผ่นทึบล่าง · ครอบวงกบ · สีกรอบมุ้ง = ปุ่มชิปเหมือนกัน
ปุ่มที่เลือกอยู่จะเป็นสีแดง · กดปุ่มอื่นเพื่อเปลี่ยน

A2. มือจับ — กล่องเดียว "ติ๊กได้หลายแบรนด์พร้อมกัน" 🆕

เดิมมือจับ 4 ช่องโผล่พร้อมกันงงๆ · ตอนนี้รวมเป็น กล่องสีเหลือง กล่องเดียว

วิธีใช้:
  1. ติ๊กแบรนด์ที่ลูกค้าใช้ (ปุ่มชิป): Cmechดิจิตอลสแตนอร่ามX-series (ฟรี)รุ่นอื่น ✎
  2. ติ๊กแบรนด์ไหน → ช่องเลือกของแบรนด์นั้นโผล่ขึ้นมาให้กรอก
  3. ติ๊กได้หลายอันพร้อมกัน (เช่น ดิจิตอลล็อค + มือจับดึงสแตนอร่าม ในบานเดียว) → ราคาบวกรวมทุกอันที่ติ๊ก
  4. กดปุ่มซ้ำ = ปิดแบรนด์นั้น → ช่องหาย + ราคาตัวนั้นออก (ตัวอื่นที่ติ๊กไว้ยังอยู่)
✓ ยังไม่ติ๊กอะไร = ฟอร์มสั้น ไม่มีช่องมือจับรก · X-series = ฟรี ไม่บวกเงิน

A3. มุ้ง — กล่องเดียว "เลือกชนิดก่อน ค่อยโผล่รายละเอียด" 🆕

เดิมช่องมุ้ง (ผ้า/ขนาด/สีกรอบ) โผล่หมดแม้ยังไม่เลือกมุ้ง · ตอนนี้รวมเป็น กล่องสีฟ้า

วิธีใช้:
  1. เลือกชนิดมุ้งก่อน — ถ้าเลือก "ไม่ใส่" = รายละเอียดทั้งหมดซ่อน (ฟอร์มสั้น)
  2. เลือกมุ้งแล้ว → โผล่: ขนาดมุ้ง (เว้นว่าง = auto ตามบาน) · ผ้ามุ้ง · สีกรอบ (ชิป)
  3. 🆕 ลักษณะการเปิดมุ้ง — ถ้าเลือก "มุ้งเฟรมเล็ก" (imp21) หรือ "มุ้งเฟรมใหญ่" (imp23) จะมีชิปให้เลือก: เปิดเลื่อนกระทุ้งยก
✓ ลักษณะการเปิด = แค่ระบุในใบ ("มุ้งเฟรมเล็ก บานเลื่อน") ไม่กระทบราคา · มุ้งชนิดอื่น (ติดตาย/จีบ/ม้วน) ชิปนี้จะไม่โผล่

A4. โซลิดลูกฟูก — คิดราคาเองอัตโนมัติ + ช่องแสง

เดิมต้องกรอกราคาเอง (ลืม = ใบต่ำผิด) · ตอนนี้ คิดให้อัตโนมัติ
• โซลิด ทู = ลูกฟูก 2 ฝั่ง · โซลิด วัน = 1 ฝั่ง (คิดให้เลย)
• ถ้ามี ช่องแสง (กระจกด้านบน) → กรอกพื้นที่ช่องแสง (ตร.ม.) ในช่อง "ช่องแสง" → คิดกระจกเฉพาะส่วนนั้น

A5. ดัดโค้ง — กระจกดัดโค้งอัตโนมัติ

เลือกสินค้าดัดโค้ง → ระบบ ตั้งกระจกเป็น "ดัดโค้ง" ให้เลย (กันลืม ราคาขาด) · ถ้าเผลอเปลี่ยนเป็นกระจกธรรมดาจะมีคำเตือน 🛑

A6. OPTION ทางเลือกลูกค้า — เลือก/พิมพ์เอง + ราคาเอง หลายอัน 🆕

ในแต่ละรายการมีปุ่ม "＋ เพิ่ม OPTION ทางเลือกลูกค้า"

วิธีใช้: กดเพิ่ม → เลือกหมวด (กระจก/มุ้ง/สี/มือจับ/หลังคา/อื่นๆ) → เลือกรายการสำเร็จรูป หรือพิมพ์เอง → ใส่ ±ราคา → กดเพิ่มได้หลายอัน (ปุ่ม ✕ ลบ)
ระบบเติม "OPTION :" หัวบรรทัดให้เอง + บวกราคาเข้ายอด

A7. แก้ข้อความในใบได้ทุกบรรทัด (โหมดแก้ไข)

ที่หน้าใบเสนอราคา กดปุ่ม "✎ แก้ราคา/ข้อความ" → แก้ได้: ชื่อรายการ · ราคา/หน่วย · รายละเอียดงานทั้งก้อน (เพิ่ม/ลบบรรทัดได้)
เว้นว่าง = กลับไปใช้ข้อความอัตโนมัติ

A8. ระแนงขายเดี่ยว — การ์ดเทียบราคา "ปัด/ต่อ" 🆕 (G2)

กรอกขนาดระแนงเสร็จ → โผล่ "วิธีตัดระแนง (มีผลต่อราคา)" เป็น 2 การ์ดเทียบราคาทันที:
🔵 ปัดไม่ต่อ (เนียน) = ราคาสูงกว่า ไม่มีรอยต่อ  ·  🟢 ต่อสูงจริง (ประหยัด) = "ถูกกว่า X บาท" มีรอยต่อ
เซลล์เห็น 2 ราคาเทียบกัน เสนอลูกค้าปิดการขายได้เลย · default = ปัดไม่ต่อ

A9. จุด default / กฎใหม่ที่ต้องรู้

เรื่องของใหม่
สีอลูมิเนียม defaultสีอบขาว ทุกสินค้า (รวมระแนง) · สีอื่นเลือกเองได้
"คิดราคาเหมา"เอา checkbox ออกแล้ว → ใช้ แก้ราคาตรงในโหมดแก้ไข ✎ แทน
ระแนง "ไม่โครง"ขายเดี่ยวไม่ได้ — dropdown ขายเดี่ยวเหลือแต่รุ่น "รวมโครง" (ไม่โครงใช้ในประตูรั้ว/ติดบานได้)
ฝังรางยู ↔ ธรณีหลังเต่าติ๊กรางยู → หลังเต่ากดไม่ได้ (เลือกซ้อนไม่ได้)
