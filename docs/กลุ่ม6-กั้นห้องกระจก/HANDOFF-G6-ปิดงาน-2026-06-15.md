## 📏 กติกาให้ "ไว + จบ" (สำคัญสุด)
1. **ปิด scope** — งานที่เหลือ = ตาราง P0 เท่านั้น · เจอของใหม่ → จดลง backlog **ไม่แก้กลางรอบนี้** (นี่คือเหตุที่ลากยาว)
2. **"จบ" = P0 ครบ + เทสเขียว + พี่นัทกดผ่าน 1 รอบ** — ไม่ใช่ "เหมือนดราฟทุก pixel" · แยก "ราคาถูก+ใบครบ" (ต้องมี) ออกจาก "หน้าตาเป๊ะ" (P1 ทีหลัง)
3. **1 ธง = 1 commit เล็ก** · ทำ P0-1 → เทส → commit → ค่อย P0-2
4. **รีวิวรอบเดียวจบ** — พี่นัทเทียบรูป list ครบทุกจุดทีเดียว → dev แก้รวด → เช็คซ้ำ 1 ที (อย่า drip ทีละจุด = ลูปไม่จบ)
