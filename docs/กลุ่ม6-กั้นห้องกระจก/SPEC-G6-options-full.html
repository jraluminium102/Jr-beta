3. Pattern HTML/JS ที่ต้องใช้

3.1 ชิป sync กับ hidden select (pickOne)

ชิปทำหน้าที่ UI เท่านั้น — select ซ่อน (display:none) เป็น source of truth สำหรับ readItem

/* ตัวอย่าง: o-bottomrail */
<div class="chips">
  <button class="chip sm on" data-val="กันน้ำ" onclick="chSetChip(this,'o-bottomrail')">รางกันน้ำ</button>
  <button class="chip sm" data-val="เตี้ย" onclick="chSetChip(this,'o-bottomrail')">รางเตี้ย 7 มม.</button>
</div>
<select class="o-bottomrail" style="display:none;" onchange="calcQuote();">
  <option value="กันน้ำ" selected>รางล่าง (กันน้ำ)</option>
  <option value="เตี้ย">รางล่าง (รางเตี้ย 7 มม.)</option>
</select>
/* chSetChip อยู่ใน index.html แล้ว — ไม่ต้องเพิ่ม */

3.2 Multi-toggle มือจับ

ปุ่มแบรนด์ติ๊กได้หลายอัน → เปิด/ปิด .hsub-* ราคาบวกสะสมจาก sub select ที่ซ่อน

/* toggleHandleBrand(btn) อยู่ใน index.html แล้ว */
<button data-hbrand="cmech" onclick="toggleHandleBrand(this)">Cmech</button>
/* sub div .hsub-cmech โผล่เมื่อติ๊ก */

3.3 Toggle + reveal ช่องความยาว (toggle+len)

checkbox ติ๊ก → โผล่ input ความยาว · ค่า perLen คำนวณใน COMMON_OPTS แล้ว

<label><input type="checkbox" class="o-beam_support" onchange="calcQuote();">
  เสริมคาน <span>(≤3ม.=4,000)</span>
  ยาว(ม.) <input type="number" class="o-beam_support-len" style="display:none;" ...>
</label>
/* reveal logic: onchange toggle display */

3.4 Conditional reveal มุ้ง (cascade)

เลือก o-mosq ≠ "" → โผล่ .mosq-detail-group ที่ซ่อน

/* mosqGroupToggle(sel) อยู่ใน index.html แล้ว */
<select class="o-mosq" onchange="mosqGroupToggle(this); calcQuote();">...</select>
<div class="mosq-detail-group" style="display:none;">...</div>

4. จุดแก้ใน groupGHOpts (~L1796)

ปัญหาปัจจุบัน: keyword-matching เปราะ — บาง control อาจตกหมวด "อื่นๆ" (bucket สุดท้าย) เพราะ textContent ไม่ตรง keyword ที่กำหนด

keyword ที่ต้องเพิ่ม/แก้ใน CATS (สำหรับ non-roof)

หมวดปัจจุบัน (key)keyword ที่ขาด/ต้องเพิ่มครอบ cls ไหน

เพิ่ม: 'ราง ' (มี space — ครอบ o-bottomrail, o-track)
เพิ่ม: 'ธรณี' (ครอบ o-thresh, o-threshf)
เพิ่ม: 'แบบเปิด' (ครอบ o-awn_mode)
เพิ่ม: 'ประเภทบานเปลือย' (ครอบ o-frametype)
เพิ่ม: 'ช่องแสง' (ครอบ o-solidlight)
เพิ่ม: 'ครอบวงกบ' (ครอบ o-fcsides, o-fcm)
