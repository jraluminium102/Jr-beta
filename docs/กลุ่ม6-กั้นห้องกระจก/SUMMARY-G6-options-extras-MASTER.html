ฟอร์ม/ออปชั่นระดับบาน = ชุดเดียวกับงานบาน G1 (SUMMARY-G1-options-extras-MASTER) · ปุ่มชนิด = HANDOFF-G1G6-6btn-selector

โครง 4 ระดับ: ห้อง→ด้าน→บาน(ชั้น)→ออปชั่น · flow เปิดทีละหน้า: ด้าน A → B → C → … → 🏠 หลังคา → (▭ ฝ้า ถ้าแยก) → 📄 หน้าสรุป

ระดับห้อง ออปชั่นทั้งห้อง (จาก JR จริง · ดู memory glasshouse-options-catalog)

หมวดรายการ
ด้าน (3–8 ด้าน เพิ่ม/ลบ)แต่ละด้าน: กระจก/บาน (→แถบผนังผสมบาน) · ผนังเบา (Isowall/สมาร์ทบอร์ด/คอมโพสิต) · เปิดโล่ง/ติดอาคารเดิม
🏠 หลังคา (ทั้งห้อง)วัสดุ(เมทัล/โพลี-กระจก/ชินโค/ไวนิล/ลามิเนต) · ทรง · ยื่น/เสมอโครง · แนวติดตั้งเสมอนอก/กลาง/ใน · แป เดี่ยว/คู่ · รางน้ำ/โซ่รางน้ำ(สี)/โครงปิดปลายกันน้ำกระเด็น · ระแนงใต้หลังคา(1×5 ยัดโครง/1×1.6 แปะนอก)
▭ ฝ้ารวมในงานหลังคา หรือ แยกเป็นรายการ · นอก/ใน · ตรง/เฉียง · ฉนวน 3 นิ้ว · ฉาบเรียบ/ไม้เทียม remood/อลู ไทยทิพย์/ISOWALL
⚡ งานไฟ (svc-elec)เดินไฟดาวน์ไลท์ +1,500/ดวง · สวิตช์ใหม่ +1,000/จุด · ปลั๊กไฟ/ชุดโคมไฟพร้อมหลอด/พัดลมระบายอากาศ (บริษัทจัดซื้อ+ติดตั้ง)
🧱 ผนัง/พื้นปิดซ่อนสโลปเดิม(สมาร์ทบอร์ด6มม./คอมโพ3มม.) · ถ่ายระดับ OFF-METER + เคลียร์ระดับพื้น · ดรอปพื้น(ฝังธรณี) · ทาสีผนังเบากรุสมาร์ทบอร์ด
❄️ แอร์/พัดลม/น้ำเพิ่มอลูทึบติดแอร์ · เสริมคานติดม่าน-พัดลม · แนวท่อน้ำลง/ปลายท่อ-บ่อพัก
🔧 บริการงานรื้อของเดิม(svc-demo) · ค่าขนส่งตจว.(svc-ship) · แบบ 3D(2 แพ็กเกจ · ยอด>200k หักส่วนลด) · มุ้ง · ม่านซิป
📄 หน้าสรุป (ปิดท้าย)ทุกด้าน(ชนิด+จำนวนบาน+ราคา) + หลังคา + ฝ้า + งานไฟ + บริการ + ราคารวมทั้งห้อง · แตะรายการ=กลับไปแก้

ระดับด้าน แถบผนังผสมบาน

  • ด้านกระจก = แถบผนังเห็นเป็นภาพ · ช่อง(กว้างตามสัดส่วน) × ชั้น(ซ้อนบน-กลาง-ล่าง) · ทุกชั้นเลือกชนิดอิสระ (ผสมได้ทุกแบบ)
  • ปุ่มควบคุม 1 บรรทัด: ◀ ซ้าย · ▶ ขวา · ▲ ขึ้น · ▼ ลง (สลับช่อง/ชั้น) · ＋บน · ＋ล่าง · ลบ
  • ช่องแสงบน/ล่าง = แค่ "ชั้น" เพิ่ม (ไม่ใช่ field พิเศษ)
  • map ข้อมูล: 1 ชั้น = 1 บานย่อย(subitem) เดิม · ภาพ = input aid (MVP) · ราคา=รวมบานย่อย ไม่แตะ engine
