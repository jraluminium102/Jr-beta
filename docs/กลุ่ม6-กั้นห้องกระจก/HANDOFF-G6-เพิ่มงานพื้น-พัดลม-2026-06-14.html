HANDOFF G6 — เพิ่ม 2 อย่าง: งานปูพื้น + พัดลมดูดอากาศ

2026-06-14 · ส่ง dev แชท B · จากตรวจใบจริง 11 ใบกั้นห้อง (ใบยี/ใบเฟริล) · แก้ public/calculator/index.html
ที่มา: ตรวจใบจริงเจอ 3 จุดที่ใบกั้นห้องมีบ่อยแต่ระบบยังไม่มี → พี่นัทเคาะ: ราวกันตกเหล็ก ไม่ทำ (ใช้ราวกันตกกระจกที่มี) · งานปูพื้น + พัดลมดูดอากาศ = ทำเพิ่ม
📍 ตำแหน่ง UI (มติพี่นัท 16 มิ.ย.): ทั้งงานพื้น + พัดลม อยู่ในหัวข้อ "อุปกรณ์เสริม" ที่เดียว (รวมกับ ไฟ/รื้อ/ขนส่ง เดิม) ในหน้า "ระดับห้อง" (accordion ต่อจากหลังคา/ฝ้า) · หน้าระดับห้องเหลือ 2 หัวข้อพับ: ① หลังคา+ฝ้า · ② อุปกรณ์เสริม(ไฟ+พื้น+พัดลม+รื้อ) — เปิดทีละหัวข้อ ไม่รก · ไม่แทรกในแต่ละด้าน A–M (พื้น/พัดลมเป็นของทั้งห้อง) · ดราฟกดเล่น: docs/กลุ่ม6-กั้นห้องกระจก/DRAFT-G6-งานพื้น-พัดลม-ux-2026-06-16.html

1พัดลมดูดอากาศ + ฝาครอบกันแมลง ง่าย — มีโครงอยู่แล้ว

ใช้ custom_item ที่มีอยู่แล้ว (L683 · {id:'custom_item',cat:'เสริม',custom_item:1} · รายการกรอกเอง free-form) — ของซื้อมาติด ไม่ต้องมีสูตรราคา
  • dev: เพิ่ม "ปุ่มลัด/preset" ในหน้า G6 (ส่วนอุปกรณ์เสริมห้อง) ชื่อ "พัดลมดูดอากาศ + ฝาครอบกันแมลง" → กดแล้ว prefill custom_item ตั้งชื่อให้ + เปิดช่องกรอก ขนาด(นิ้ว) · จำนวน(ตัว) · ราคา
  • จากใบจริง: "พัดลมดูดอากาศ สีขาว 8" จำนวน 1 ตัว + ฝาครอบกันแมลง สีขาว 8" จำนวน 1 ตัว"
  • ราคา = กรอกเอง (ของซื้อ ราคาตามจริง) — ไม่ต้องเรตสำเร็จ
AC: กด "พัดลมดูดอากาศ" ในหน้า G6 → กรอกขนาด/จำนวน/ราคา → ขึ้นใบเป็นบรรทัด "พัดลมดูดอากาศ 8" + ฝาครอบกันแมลง" + ราคา · เข้ายอดรวม

2งานปูพื้น product ใหม่ · ระดับห้อง

เพิ่มส่วน "พื้น" ในหน้า G6 room (ระดับห้อง เหมือนหลังคา/ฝ้า/ไฟ) · method per_sqm (เหมือน steel_mesh L662 / ระแนง L742)
วัสดุพื้นตำแหน่งเรต/ตร.ม.ขั้นต่ำ
สมาร์ทบอร์ด 20มม. + โครงเหล็กกัลวาไนซ์พื้นในห้อง5,0005 ตร.ม.
ไม้เทียม + โครงเหล็กกัลวาไนซ์พื้นนอกห้อง5,0005 ตร.ม.
ลามิเนต / SPC (ปูทับ)เสริมบนพื้นกรอกเอง/ตร.ม.—
  • UI: เลือกวัสดุ → เลือก พื้นในห้อง/นอกห้อง → กรอกพื้นที่ (ตร.ม.) → ราคา = พื้นที่ × 5,000 (ถ้า <5 ตร.ม. คิด 5 ตร.ม. = 25,000)
  • โครงเหล็ก = เหล็กกัลวาไนซ์ (กันสนิม · รวมในเรต) → ระบุในใบ "โครงเหล็กกัลวาไนซ์"
  • ลามิเนต/SPC = ปูทับบนพื้น · กรอกราคาเอง/ตร.ม. (รอราคาช่าง)
  • note อัตโนมัติในใบ: "ไม่รับประกันพื้นแอ่นหรือยวบ"
🏷️ ส่วนลดงานใหญ่ (กะเกณฑ์ตั้งต้น · ปรับได้): พื้นที่ ≥ 20 ตร.ม. → ลด 10% (default) · + เว้นช่องกรอก % เอง ให้เซลล์ปรับตามจริง · เหตุผล: งานใหญ่ต้นทุน/หน่วยลด (โครง/แรงเฉลี่ย) · dev: ทำช่อง "ส่วนลดงานใหญ่ %" auto-fill 10% เมื่อ ≥20 ตร.ม. · แก้เลขเองได้
หมายเหตุราคา: เรต 5,000 = ต้นทุน × 2 (กำไร 100% · มติพี่นัท) · ราคาทุนยังไม่ได้เช็คแน่นอน → 5,000 เป็นค่าตั้งต้น อาจปรับเมื่อได้ทุนจริง · reference ตลาด มิ.ย.69: ไม้เทียม WPC รวมติดตั้ง 1,650–3,600 · โครงกัลวาไนซ์ 800–1,200
AC: เลือกวัสดุพื้น + พื้นที่ → ขึ้นใบ "ปูพื้นสมาร์ทบอร์ด 20มม. โครงเหล็กกัลวาไนซ์ (พื้นในห้อง)" + ราคา 5,000/ตร.ม. (min 5) · ≥20 ตร.ม. ลด 10% (แก้ได้) · note ไม่รับประกันแอ่น · เข้ายอดรวมห้อง

✕ราวกันตกเหล็ก — ไม่ทำ (มติพี่นัท)

ใบจริงบางใบมี "ราวกันตกเหล็ก" (แป๊ปกลม/ตันกลม) แต่ พี่นัทเคาะไม่ทำ — ใช้ราวกันตกกระจกที่มีอยู่ (imp1-6) แทน · dev ไม่ต้องเพิ่ม
