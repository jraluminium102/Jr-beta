UX friction ที่พบใน index.html (G6 mode)

จุดปัญหาเสนอแก้
Dropdown สีอลู gh-set-color-row ใช้ <select> height:36px — ต่ำกว่า 44px · แตะยาก mobile ปรับ height:44px หรือเปลี่ยนเป็น chip (เสนอใน DRAFT v2)
สีอลูห้อง vs สีอลูบาน ซ่อน i-color-wrap ทุกบาน แต่ไม่โชว์ feedback "ใช้สีจาก master" → เซลล์ไม่รู้ว่าค่าถูก sync แล้วหรือยัง เพิ่ม badge "สีจาก master" ใต้ row สีในการ์ดด้าน
ป้าย summary ด้าน summary บนหัวการ์ด ch ยังไม่โชว์ขนาด/แบบบาน → เซลล์ต้องเปิดดูทุกการ์ดเพื่อตรวจ เพิ่ม ch-summary แสดง "ด้านA · เลื่อน · 1.8×2.4"
dropdown "แบบ" ยาวเกิน _GM['6'] = 19 cat → dropdown ยาวมาก ต้องเลื่อนยาว · เสี่ยงเลือกผิด ใช้ chip กลุ่มสั้น (บานเลื่อน/บานเปิด/ติดตาย/บานเฟี้ยม) · ตัดออปชั่นไม่เกี่ยวออก (ดูหัวข้อก่อนหน้า)
ชื่อชุด default "กั้นห้องกระจก (ห้อง...)" — "ห้อง..." ทำให้ต้องแก้ · เซลล์มักข้ามทำให้ใบเสนอราคาออกชื่อผิด placeholder แทน value หรือ auto-clear เมื่อ focus
groupGHOpts หมวด "อื่นๆ" ออปชั่นที่ไม่ match keyword ตกลง bucket "อื่นๆ" ทั้งหมด → bucket ยาว ไม่มีลำดับ เพิ่ม keyword ให้ครอบคลุม + เรียงลำดับ bucket ที่เปิดโดย default
