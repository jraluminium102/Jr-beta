# [โค้ดจริง · ส่ง dev] กู้ใบ G6 ให้เป็น 5 บล็อก + Protection หมายเหตุ

**ลงมือแก้ `public/calculator/index.html` เฉพาะ G6 ได้เลย** — ก๊อปโค้ดด้านล่างวางตามจุด · ห้ามรอ

## ปัญหาที่กู้
G1 เปลี่ยนใบเป็น 5 บล็อกแล้ว (genQuote L~5808 ใช้ `d.work/d.spec` จาก `itemDetail`) แต่ **G6 ตกขบวน** — `readItem` G6 ส่งรายการงานเป็น `note` → ใบเพี้ยน (รายการงานไปกองใต้ "หมายเหตุ")

## วิธีไล่ที่ตรวจมาแล้ว (กันเดา)
- `itemDetail` (L~5078) ไม่มี branch room · genQuote ใช้ `d.work/d.spec` จาก itemDetail (ไม่ใช่ของ readItem)
- G6R state **ไม่เก็บสี/กระจกต่อบาน** (freshState: pcs มีแค่ cat/id/w/h/opt) → spec ใช้ค่ามาตรฐาน
- `g6rRoomDetail` (L~6319) = รายการงาน (ใช้เป็น `work`) · ยังไม่มี function ออก spec
