FIX A — groupGHOpts ให้รู้จักหมวด "หลังคา" (จุด ②③④)

ปัจจุบัน groupGHOpts(ch) (L1747) ใช้ CATS ชุดเดียวทุกสินค้า · ทำให้ใช้ keyword 'ชนิด/การเปิด' กับหลังคา · slide ตก catch-all

  • ตรวจหมวด: ก่อนสร้าง CATS ดูว่าเป็นหลังคาไหม — var isRoof = ch.querySelector('.o-roofend') || ch.querySelector('.o-roofbatten');
  • ถ้า isRoof → ใช้ CATS ชุดหลังคา (6 กล่องตามตารางบน) ตัวอย่าง keyword:

FIX B — OPTION ทางเลือกลูกค้า ให้ตรงหลังคา (จุด ①)

OPTION cascade (F2 · ~L2021) ให้ลูกค้าเลือก "หมวด → รายการ" เปลี่ยนของ · ปัจจุบันหลังคาโชว์หมวด กระจก/มุ้ง/มือจับ (ไม่เกี่ยว)
  • กรองหมวดตามสินค้า: ถ้าเป็นหลังคา → เสนอเฉพาะหมวดที่เกี่ยว (เปลี่ยนสี/วัสดุมุง/เปลี่ยนชนิดหลังคา) ตัด กระจก/มุ้ง/มือจับ ออก (เช็ค cat ก่อน build รายการ cascade)
  • แก้ label summary L2181: "เปลี่ยนกระจก/มุ้ง/สี/มือจับ/หลังคา" → context หลังคา = "เปลี่ยนสี/วัสดุมุง/หลังคา" (หรือทำ label ตามหมวดสินค้า)
(เช็คซ้ำกับพี่นัท: หลังคาอยากให้มี OPTION อะไรบ้าง — เปลี่ยนสีอลู? เปลี่ยนชนิดหลังคา? เพิ่ม/ลดของเสริม?)

FIX C — หลังคาเลื่อน: เพิ่ม "ชนิดเลื่อน" + "พื้นที่ กว้าง×ยาว" (มติพี่นัท)

ฟีเจอร์ใหม่ในกล่องหลังคาเลื่อน (optSlide block ~L2312) — แตะ logic เล็กน้อย (เพิ่มช่อง) ไม่ใช่แค่จัดกล่อง

① ชนิดเลื่อน (เลือกอย่างเดียว · single-select) — ราคาเท่ากัน = label only

  • เพิ่มชิป/select .o-slidetype: เลื่อนยื่น / เลื่อนข้าง (default เลื่อนยื่น)
  • มติพี่นัท: ราคาเท่ากัน → เป็นแค่คำลงใบ ไม่แตะ calc · readItem เก็บ optSel.slidetype · genQuote ลงใบ "ระบบหลังคาเลื่อนแบบเลื่อนยื่น/เลื่อนข้าง N บาน (มอเตอร์ N ตัว)"

③ จำนวนบานติดตาย (ในชุดหลังคาเลื่อน)

  • เพิ่ม stepper/input .o-sfixed (default 0–1) = บานที่ไม่เลื่อน (ส่วนติดตาย)
  • readItem เก็บ optSel.sfixed · genQuote ลงใบ "...N บานเลื่อน + M บานติดตาย" · เช็คซ้ำ: บานติดตายกระทบราคาไหม (ถ้าคิดตามพื้นที่หลังคารวมอยู่แล้ว = label · ถ้าคิดแยก บอกเรตมา)

② พื้นที่เลื่อน = กรอก ยาว × ยื่น (แทน auto) · บานเลื่อน/ติดตาย = stepper

  • เดิม .o-sarea = ช่องเดียว (auto) → เปลี่ยนเป็น 2 ช่อง ยาว × ยื่น (.o-sareaw × .o-sareah) · readItem: optSel.sarea = ยาว × ยื่น (ว่าง=auto เดิม) → calc L1441 ใช้ sarea ตามเดิม (สูตรไม่แก้)
  • จำนวนบานเลื่อน (.o-spanels) + บานติดตาย (.o-sfixed) = stepper − [N] + (กดเลื่อน/กรอกเองได้) อยู่ข้างกัน · ค่าเดิม/logic เหมือนเดิม แค่เปลี่ยน control เป็น stepper

④ คำศัพท์งานหลังคา: "กว้าง/สูง" → "ยาว/ยื่น" (label only · มติพี่นัท)

  • ช่องขนาดหลัก .i-w/.i-h ของหลังคา — เปลี่ยน label เป็น "ยาว" (=.i-w) / "ยื่น" (=.i-h) เฉพาะ cat=หลังคา · value/logic เดิม (พื้นที่ = ยาว×ยื่น = w×h เท่าเดิม)
  • รางน้ำอยู่ฝั่งยาว: FIX-13 ความยาวราง default = parseFloat(w) (=ด้านยาว) — ตรงกับ "ฝั่งยาว" แล้ว (ถ้า ยาว=.i-w) · แก้แค่ hint label เป็น "(ว่าง=ใช้ด้านยาว)"
✅ มติพี่นัท 11 มิ.ย.: "เลื่อนยื่น" = "เลื่อนข้าง" ราคาเท่ากัน → .o-slidetype เป็นแค่ label ลงใบ ไม่แตะ calc · พื้นที่ กว้าง×ยาว ใช้สูตรเลื่อนเดิม (L1441 sarea) ได้เลย · สเปกหลังคา (FIX A/B/C) ครบ พร้อมส่ง dev
