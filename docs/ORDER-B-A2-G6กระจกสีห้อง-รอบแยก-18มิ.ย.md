## จุดที่ 1 — กระจก: เพิ่มช่องเลือกชนิด+หนา ต่อช่อง (ราคาขยับ)
**ตอนนี้:** ห้องไม่มีช่องเลือกกระจกเลย · `g6rRoomSpec` (L6812) พิมพ์ `'กระจกเขียว/ใส หนา 6 มม.'` ตายตัว · ราคาไม่ขยับตามกระจก
**แก้:**
- เพิ่ม selector กระจก **ต่อช่อง (per piece/column)** ใน `g6rRenderOpt` (L6667 ใต้บล็อก "เสริมกระจก") — drill ชนิด→หนา · reuse `GLASS` (L605) + `GLASS_CATS` (L1048) + `glassCatOf` (เหมือน glassDrillRender โหมดเต็ม)
- เก็บ `glassIdx` ลง `pc.opt` (ต่อชิ้น) · default = 0 (เขียว 6มม · **ต้องคง default นี้ → golden เดิมนิ่ง**)
- ส่ง `glassIdx` เข้า `g6rOptSel(pc)` → `calcUnit` (L6575 g6rPrice) ใช้ `GLASS[gi].s × area` คิดส่วนต่างเอง (engine เดิมทำอยู่แล้ว)
- `g6rRoomSpec` L6812: เปลี่ยนจาก hardcode → ดึงชื่อกระจกที่เลือกจริง (`GLASS[glassIdx].n`)

## จุดที่ 2 — สีอลู: ขยายจาก 3 สี → COLORS ครบ + คิดค่าสีพิเศษ
**ตอนนี้:** `g6rRenderOpt` L6656 `pick('สีเฟรม','framecolor',[['ขาว'],['ดำ'],['เทา']],...)` — แค่ 3 สี ไม่คิดเงิน

- `g6rRoomSpec`: ขึ้นชื่อสีจริงในใบ (สีพิเศษมีรหัส → ตาม [[quote-item-structure]])

## จุดที่ 3 — สีอลูโครงหลังคาในห้อง: เลือกได้ + คิดค่าสีพิเศษ (พี่นัทเน้น 18มิ.ย.)
