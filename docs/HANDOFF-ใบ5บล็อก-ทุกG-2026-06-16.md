# 📋 [ส่งทุกแชทกลุ่ม G] แก้ใบเสนอราคาเป็น "5 บล็อก"

> มติพี่นัท 16 มิ.ย. 2026 · ใบเสนอราคา **ทุกกลุ่ม G1–G7** แก้เป็น 5 บล็อก · แต่ละแชทเขียนโค้ด itemDetail ของกลุ่มตัวเอง แล้วเตรียมสั่ง dev

## โครง 5 บล็อก (บน→ล่าง)
1. **หัวรายการ** (ตัวเข้ม) = ชื่อ + รุ่น + ขนาด (กว้าง×สูง+ลึกถ้ามี) + จำนวนชุด
2. **รายการ (รูปแบบงาน)** = bullet · **ไม่มีหัวข้อ** · ชิ้นงานที่ทำ/ติดตั้ง (ตัดสเปคในวงเล็บออก)
3. **OPTION** = หัวข้อ "OPTION" (สีแดง) · โชว์เมื่อมี · OPTION ลูกค้าต่อชิ้น (+ราคาถ้ามี)
4. **หมายเหตุ** = หัวข้อ "หมายเหตุ" · โชว์เมื่อมี · ข้อความเฉพาะงาน (i-note)
5. **รายละเอียด** = หัวข้อ "รายละเอียด" · สเปค

ลำดับ: หัว → รายการ → OPTION → หมายเหตุ → รายละเอียด
- OPTION/หมายเหตุ **ว่าง = ซ่อนหัวข้อ** (ไม่ขึ้นหัวข้อเปล่า)
- **"ออปชั่นทั้งใบ" ไว้ท้ายใบเหมือนเดิม** (ไม่ย้ายมาต่อชิ้น)

## กฎแยก "รายการ(งาน)" vs "รายละเอียด(สเปค)"
- **รายการ(งาน)** = สิ่งที่ทำ/ติดตั้ง — บาน/ชั้น/ผนัง/มุ้ง(+เลื่อน/เปิด)/ครอบวงกบ/ชุดล็อค/คาดตาราง/ดรอปพื้น/รื้อ
- **รายละเอียด(สเปค)** = ค่าที่ต้องระบุ:
  - **สีพิเศษ (hasCode) บังคับรหัส** → ไม่กรอก = **⚠ แดง "ต้องระบุรหัสสี"**
  - **กระจก** ระบุชนิด+ความหนา+สี
  - **วัสดุอลู** (ชั้น/เฟรม/เกล็ด) ระบุสี
- เส้นที่ปนกัน เช่น "มุ้งเฟรมใหญ่ บานเปิด (เฟรมตามสีบาน / ผ้าไฟเบอร์เทา)" → แยก: รายการ="มุ้งเฟรมใหญ่ (บานเปิด)" · รายละเอียด="ผ้ามุ้ง: ไฟเบอร์ เทา · เฟรม: ตามสีบาน"
