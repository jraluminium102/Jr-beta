1. บริบท + เป้าหมาย

กล่องฟ้า .sliding-main-block สร้างขึ้น 2 จุดใน buildItemOpts():

  • จุด A — บานเลื่อน/เลื่อนภายใน (L2545–2572) มี field: ชนิดการเปิด + ติดตาย/เปิด + ราง
  • จุด B — บานเปิด/ติดตาย (L2581–2586) มีแค่ label + panels-slot

หลัง build เสร็จ relocation logic (L2849–2855) ย้าย .sliding-main-block ขึ้นฟอร์มหลัก และดึง .i-panels-wrap (จำนวนบาน) เข้ากล่องฟ้าผ่าน .smb-panels-slot

ปัญหาปัจจุบัน (2 ข้อ):

  • ลำดับ: smb-panels-slot วางก่อน o-opentype → จำนวนบานมาก่อนชนิด ขัด flow ธรรมชาติ
  • ปุ่มราง: style="width:100%" บน <label> wrapper ทำให้ชิปกินแถวเต็ม เปลืองพื้นที่

2. การเปลี่ยนแปลง — จุด A (L2550–2560)

บรรทัดอ้างอิง: ~L2550

HTML ย้าย <span class="smb-panels-slot"> ไปหลัง opentype label

diff (จุด A — กล่องฟ้า บานเลื่อน)

h+='<div class="full sliding-main-block" ...>';
h+='<span style="font-size:12px;color:#1E5AA8;font-weight:700;">🔢 บานเลื่อน:</span>';
- h+='<span class="smb-panels-slot"></span>';   // ← ลบออกจากตำแหน่งนี้
h+='<label class="opt">ชนิดการเปิด <select class="o-opentype" ...>...</select></label>';
+ h+='<span class="smb-panels-slot"></span>';   // ← ย้ายมาหลัง opentype
h+='<label class="opt">ติดตาย <input ...> บาน · เปิด ...</label>';

diff (จุด A — label ราง, บรรทัด ~L2558)

CSS ลบ style="width:100%;" ออกจาก <label class="opt"> ของราง 
- h+='<label class="opt" style="width:100%;">ราง ...
+ h+='<label class="opt">ราง ...
ผลลัพธ์: ชิปรางกันน้ำ / รางเตี้ย 7 มม. ไม่กินแถวเต็มอีกต่อไป — นั่งอยู่ในแถวเดียวกับ label "ราง" · กระชับขึ้น ~40px แนวตั้ง

3. การเปลี่ยนแปลง — จุด B (L2582–2585)

บรรทัดอ้างอิง: ~L2582

จุด B (บานเปิด/ติดตาย) ไม่มี o-opentype — smb-panels-slot ตามหลัง label ทันที ซึ่ง ถูกต้องแล้ว ไม่ต้องแก้ลำดับ

แต่ถ้ามีการเพิ่ม field อื่นใน bluebox บานเปิดในอนาคต ให้วาง smb-panels-slot ไว้ท้ายสุดเสมอ

จุด B: ไม่ต้องแก้ HTML ในรอบนี้

4. Relocation Logic — ไม่ต้องแก้

Logic L2849–2855 ทำงานโดยหา .smb-panels-slot แล้ว insert .i-panels-wrap ไปหลัง slot นั้น — เมื่อ slot ย้ายไปหลัง opentype แล้ว panels จะตาม โดยอัตโนมัติ

// L2852-2853 (ไม่ต้องแก้ — แค่อ้างอิง)
var _anchor = _smb.querySelector('.smb-panels-slot') || _smb.firstChild;
_smb.insertBefore(_pw, _anchor && _anchor.nextSibling ? _anchor.nextSibling : null);
หลังย้าย slot แล้ว panels จะอยู่หลัง opentype โดยอัตโนมัติ ไม่ต้องแตะ L2849-2855
