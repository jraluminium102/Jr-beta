3. บานกระทุ้งยูโร ช่อง "แบบเปิด" (awn_mode) แก้แล้ว

ปัญหา
  • awn_mode เป็น select แต่ถูกวาดเป็น checkbox → ติ๊กแล้วราคาเป็น NaN
  • tilt&turn คิดเหมา 5,000 ไม่คูณบาน + คำเตือนน้ำเข้าไม่ขึ้น
วิธีแก้ที่ทำไป (3 จุด)
  • ตัววาดฟอร์ม (ค้น input type="checkbox" class="o-${o.id}"): รองรับ o.type==='select' → วาด <select> · ข้าม opt ที่มี depends
  • ตัวอ่านค่า (ค้น optSel[o.id]=c&&c.checked): select เก็บ c.value
  • ตัวคิดราคา (ค้น if(optSel[o.id]) opt+=o.price): ข้าม select/depends กัน NaN + เพิ่ม tilt&turn = 5,000 × บาน เมื่อ awn_mode='2'
