ออกมาเป็น HTML กดเล่นได้ ลองในหน้า preview

กฎ:
- READ-ONLY: อ่าน public/calculator/index.html ได้ ห้ามแก้ ·
  เขียนได้แค่ไฟล์ใหม่ใน docs/
- สร้างไฟล์ด้วย Write tool ชื่อ: docs/DRAFT-<กลุ่มด้านบน>-ux-<วันที่>.html
  (เช่นกลุ่ม G3 → docs/DRAFT-G3-ux-2026-06-12.html)
  ใช้ Write tool เท่านั้น เพื่อให้ไฟล์เด้งขึ้นช่อง preview อัตโนมัติ
- ไฟล์ต้องสมบูรณ์ในตัว (CSS+JS ฝังในไฟล์เดียว) กดชิป/ปุ่มได้จริง
  ช่องโผล่/ซ่อนได้ ราคาตัวอย่างเด้งตอนกด
- ยึดดีไซน์ต้นแบบ docs/DRAFT-G2-ux-2026-06-11.html:
  เน้นชิป/ปุ่มติ๊ก ไม่เอา dropdown (ตัวเลือก ≤5 = ชิป · รายการยาว = drill-down)
  เรียงช่องสำคัญขึ้นบน · ปุ่มใหญ่แตะง่ายบนมือถือ (ปุ่ม ≥44px)
- ออปชั่นไหน "ไม่ชัวร์ว่าควรมี/ตัด" → อย่าตัดเอง list มาถามก่อน
- เปิดอ่านไฟล์ที่สร้างจริงก่อนบอกเสร็จ (ห้ามมี undefined / ช่องพัง)

ส่งกลับ: path ไฟล์ + สรุป before→after + จุดที่ต้องให้ฉันตัดสิน
