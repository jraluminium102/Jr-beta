## รายละเอียด + selector แต่ละจุด

### จุด 1 — หมายเหตุมาตรฐาน ไม่อยู่ใน B3
- **ดราฟ**: กล่อง ③ มี "📝 หมายเหตุมาตรฐาน (ติ๊กขึ้นใบ)" = o-remark-add + preset tick list
- **เว็บ**: `ch.querySelector('.g4-b3 .o-remark-add')` = null  
  แต่มี `.note-opt-group` อยู่ใน `.chgrid` นอก g4-prebox (เป็น component ร่วมทุกกลุ่ม)
- **เสนอแก้**: inject o-remark-add preset เข้า B3 body (หรือ move note-opt-group ให้ render ใต้ B3 แทนนอก)

### จุด 2 — "งานปิด/ซ่อน/รอยต่อ" ผิดกล่อง
- **ดราฟ ③**: o-rfgc-toggle (ปิดซ่อนราง) / o-rfbc-toggle (ครอบคาน) / o-rfsealer+sealercolor / o-rfchain (โซ่3000/เส้น) / o-rfpvc (ครอบท่อ1500)
- **เว็บ**: ทั้ง 5 อยู่ใน B2 sub-details "🏗️ โครงเหล็กเสริม · ของเสริมหลังคา"
  - `ch.querySelector('.g4-b2 .o-rfgc-toggle')` = found
  - `ch.querySelector('.g4-b2 .o-rfchain')` = found
- **เสนอแก้**: แยก kw ใน CATS isRoof = เพิ่ม kw เหล่านี้เข้า bucket[2] (③) แทน bucket[1] (②)

### จุด 3 — i-rfsampleconfirm อยู่ผิดกล่อง
- **ดราฟ ①**: ท้าย "กล่อง ① สเปกหลัก" = `📸 ลูกค้าเห็นตัวอย่างจริง + ถ่ายรูปยืนยันแล้ว`
- **เว็บ**: `ch.querySelector('.g4-b3 .i-rfsampleconfirm')` = found (อยู่ B3 ไม่ใช่ B1)
- **เสนอแก้**: เพิ่ม `'ลูกค้าเห็นตัวอย่าง'` เป็น kw ใน CATS[0] (①) แทน CATS[2] (③)

### จุด 4 — แป default ผิด
- **ดราฟ**: ชิปแปเดี่ยว (on/selected) default
- **เว็บ**: `ch.querySelector('.o-roofbatten').value` = `'แปคู่'`
- **selector**: `.o-roofbatten` บรรทัดที่สร้าง option ใน index.html
- **เสนอแก้**: แก้ selected option จาก `แปคู่` → `แปเดี่ยว`

### จุด 5 — ปลายหลังคา ข้อความชิป "ปิดปลายกันน้ำกระเด็น"
- **ดราฟ**: "ปิดปลายกันน้ำ 1,000/ม."
- **เว็บ**: `ch.querySelector('.o-roofend')` option[2] = `ปิดปลายกันน้ำกระเด็น` (ขาดราคา)
- **เสนอแก้**: แก้ text option → "ปิดปลายกันน้ำ 1,000/ม." (เพิ่มราคาด้วย)

### จุด 6 (ต้องพี่เคาะ) — กลุ่มวัสดุ/รุ่น/สีวัสดุมุง/ขนาด อยู่นอก B1
- **ดราฟ ①**: ทุกอย่างอยู่ "ใน" กล่องแดง ① มีกรอบแดง border-left ครอบ
- **เว็บ**: `.g3-prodsel` + `.rf-matcolor-wrap` + `.size-row` อยู่ใน `.chgrid` ก่อน i-opts (DOM ลำดับ OK แต่ไม่มีกรอบครอบ)
- **ผลที่เห็น**: user เห็นกลุ่มวัสดุ/รุ่น/สีวัสดุมุง ลอยอยู่ก่อนกล่อง ① โดยไม่มีกรอบ
- **เสนอ**: ถ้าต้องการตรงดราฟ = ต้องย้าย 3 elements เข้า B1 body (แก้ใหญ่ กระทบ skipEls logic) → พี่เคาะก่อน

### จุด 7 (ต้องพี่เคาะ) — ceilmode ชิปรวมกัน 15 ตัว
- **ดราฟ ②**: toggle "เพิ่มงานฝ้า" ก่อน → โผล่ชนิดฝ้า 6 ตัว แยกกัน
- **เว็บ**: ชิปทุกอย่าง (none/in/sep + 6 ชนิด + 2 สี + ตำแหน่ง + แนว) รวมเป็นกลุ่มเดียว 15 ชิป
- **เสนอ**: ถ้าต้องการตรงดราฟ = แยก ceilmode toggle ออกก่อน แล้วโผล่ ceiltype → พี่เคาะว่า UX ปัจจุบัน OK ไหม
