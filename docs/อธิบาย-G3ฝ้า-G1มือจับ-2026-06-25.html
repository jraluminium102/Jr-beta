② งานฝ้าใต้หลังคา — "แยกรายการ" หายไป ขอพี่เคาะ

เดิมเลือก "วิธีคิดเงินฝ้า" ได้ 3 แบบ · ดราฟใหม่เหลือแค่เปิด/ปิด → ตัวเลือก "แยกรายการ" หายไป

เดิม (ก่อนแก้)
3 ปุ่ม — เลือกได้ว่าฝ้าจะรวมยอดหรือแยกบรรทัด
ตอนนี้ (ตามดราฟ)
toggle เปิด = รวมในหลังคา เสมอ · ไม่มีตัวเลือกแยกบรรทัดในโหมดใบปกติ
"แยกรายการ" คืออะไร: ในใบเสนอราคา ฝ้าจะโชว์เป็นบรรทัดแยก พร้อมราคาของมันเอง (ลูกค้าเห็นว่าค่าฝ้าเท่าไร) แทนที่จะกลืนรวมในค่าหลังคา · หมายเหตุ: โหมด "แยกราคา" ในใบรุ่นใหม่ที่เพิ่งทำ จะแตกราคาฝ้าให้เห็นอยู่แล้วทุกกรณี
พี่จะเอาแบบไหน? (กดเลือก)
A) คงตามดราฟ — toggle อย่างเดียว (รวมในหลังคา)แนะนำ
UI สะอาดสุด ตรงดราฟเป๊ะ · ถ้าลูกค้าอยากเห็นราคาฝ้าแยก → ใช้โหมด "แยกราคา" ในใบได้อยู่แล้ว
B) เพิ่ม "แยกรายการ" กลับ — toggle + ปุ่มย่อย รวม/แยก
กดเปิดฝ้าแล้วมีปุ่มย่อยให้เลือก "รวมในหลังคา / แยกรายการ" · ได้ความสามารถเดิมกลับ แต่ UI มีปุ่มเพิ่ม (ต่างจากดราฟนิด)
