## ใบสั่ง dev (สั้น)

**แก้ทันที (2 จุด):**

1. **เพิ่ม รื้อของเดิม ให้ประตูรั้ว** (`p.gate`)
   - บรรทัด ~L6052: ตอนนี้ `if(!p.gate) h+='...<label class="opt"><input ... class="o-removeold">...'`
   - แก้: ลบ `!p.gate` guard — ประตูรั้วควรมี checkbox รื้อของเดิมด้วย
   - ⚠ ตรวจว่า engine `readItem` อ่าน `o-removeold` ของ gate หรือ bypass (ถ้า bypass เพิ่มใน readItem ด้วย)

2. **เพิ่ม งานเสริม/วิศวกรรม ให้ประตูรั้ว** (`p.gate`)
   - บรรทัด ~L6051: ตอนนี้ `if(!p.gate) h+='...<input ... class="o-extrawork">...'`
   - แก้: ลบ `!p.gate` guard — ประตูรั้วควรมี input งานเสริมด้วย
   - ⚠ ตรวจว่า engine อ่าน `o-extrawork` + ใส่ในใบหรือเปล่า (ถ้ายังไม่ใส่ ต้องเพิ่มใน readItem/genLine gate ด้วย)

**เช็คก่อนแก้ (2 จุด รอพี่เคาะ):**

3. **สีอลูระแนง** (C/D): drill 4 หมวด vs ชิปตรง 5 ตัว — รอพี่เคาะ
4. **`o-railreuse` chipify จริงไหม** — CHIPIFY_SELECTS มีชื่อ `o-railreuse` แล้ว แต่ต้องตรวจ DOM ว่า chipifySelect() ทำงานจริงบน element ที่สร้างใหม่ใน gate block (สร้างที่ L5917 หลัง chipify ถูกเรียก) — ถ้ายังเป็น `<select>` โผล่ ต้องเรียก chipify หลัง buildItemOpts
