## ⚠️ จุดเสี่ยง/กับดักที่เคยเจอใน G6 (อ่านก่อนแก้)

1. **engine ร่วม G1 ↔ G6** — บานทุกชนิดคิดราคาผ่าน `calcUnit` ตัวเดียวกับ G1/G3 ผ่าน `g6rPrice()` (L8235). แก้ map ออปชั่นใน `g6rOptSel()` (L8151) ผิด = ราคา G6 เพี้ยนทันที และอาจกระทบ G1. **ห้ามแก้ calcUnit** เพื่อ G6 — ทุกอย่างต้อง map ผ่าน g6rOptSel.
2. **hook blanket box=null crash** — `g6rMount` ผูก event listener แบบ capture บน itemEl (L8476). ถ้า `querySelector('.g6r-mount')` คืน null แล้วใช้ต่อ = crash. โค้ดใหม่ที่อ่าน DOM ในห้องต้อง guard null เสมอ (เหมือน L8473 `if(!mt)return;`).
3. **escape JS ใน inline onclick** — engine เก็บฟังก์ชันเป็น `window.G6R*` แล้วเรียกผ่าน `onclick="G6Rxxx('...')"`. ค่าที่มี `'` หรือ `\n` ต้อง escape. ดูตัวอย่าง L8370 ที่ใช้ `String.fromCharCode` เลี่ยง `.g6r-more` literal — รักษาสไตล์เดิม.
4. **CSS ซ่อนฟอร์ม G6** — `.ch.g6room` ซ่อนฟอร์มบาน G1 ด้วย CSS (L8111–8120). ถ้าเพิ่ม DOM ใหม่ในห้องที่ตรง selector เดิม (`.optbox` ฯลฯ) จะโดนซ่อน. ใช้ class ใหม่ใน namespace `.g6r-*`.
5. **state ชี้ผ่าน pointer G6R** — ทุก public API สลับ `G6R=itemEl.__g6state` ชั่วคราวแล้วคืน (L8478/8507/8521/8535). ฟังก์ชัน room-level ใหม่ (สี/กระจก/services) ต้องเก็บ state ใน `__g6state` ไม่ใช่ตัวแปร global ลอย มิฉะนั้นหลายห้องในใบเดียวจะปนกัน.
6. **โหมดเร็ว** — G6 มีในโหมดเต็ม (.i-*) เท่านั้น. ตรวจว่าโหมดเร็วไม่พังด้วย (เปิดเว็บโหมดเร็ว เพิ่มกั้นห้อง = ต้องไม่ error).

**จุดในโค้ด:** `g6rRoomDetail()` L8521–8534 (ปัจจุบันคายแบบ "ภาพรวมต่อด้าน + ออปชั่นย่อ 1 บรรทัด/บาน")

**before:** detail = ด้าน A (n บาน) = ราคา → `• ชนิด (ขนาด) · ออปชั่นย่อ` (รวมออปชั่นเป็น string เดียวต่อบาน · ไม่แตกราคารายออปชั่น)

**after:** ต้องคาย **2 ระดับ**:
- 📊 ภาพรวม = แบบเดิม (ต่อด้าน/ต่อส่วน + spec ย่อ) → ใช้ `g6rRoomSummary` + `g6rRoomDetail` เดิม
- 🔍 ละเอียด = แตกราคา **รายออปชั่นต่อบาน**: บานฐาน / ล็อก / มุ้ง / มือจับ / คาดตาราง / ลูกฟูก / โช้ค / ครอบวงกบ ฯลฯ แยกบรรทัด+ราคา
  - ต้องให้ engine คาย breakdown รายออปชั่น → เพิ่ม `window.g6rRoomDetailFull(itemEl)` ที่เรียก `calcUnit` แล้วอ่าน `r.addonLines`/`r.msgs` (calcUnit คืน addon รายตัว — ดู readItem L6111 `addonLines`)
  - หรือคำนวณ diff: ราคารวมบาน − ราคาบานฐาน(ไม่มี opt) = ค่าออปชั่นรวม แล้วแตกจาก optSel
  - **แนะนำ:** ใช้ `calcUnit` คืน `r.addonLines` (มีอยู่แล้วใน engine · readItem ใช้) — map เป็นบรรทัด sub
- ในใบ render ปุ่ม `📊 ภาพรวม` / `🔍 ละเอียดทุกจุด` toggle (ดราฟ `billMode()` L359) · default = ภาพรวม

**เกณฑ์ผ่าน:** ออกใบ G6 → เห็น 2 ปุ่ม · default ภาพรวม · กด 🔍 → แตกราคารายออปชั่นทุกบรรทัด ยอดรวมตรงกับภาพรวม
