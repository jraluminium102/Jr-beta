📍 แต่ละขั้นตอน กดตรงไหน?

ไล่ตามนี้ได้เลย — บอกชัดว่าอยู่เมนูไหน กดอะไร แล้วเกิดอะไร

1
รับงาน / นัดลูกค้า
📞
📂อยู่เมนู:คิวงาน
👆ให้กด:เปลี่ยนสถานะคิวเป็น เสร็จ (DONE)
✨ผลที่ได้:
ระบบสร้างงานลูกค้าใหม่ + เก็บเข้าทะเบียนให้อัตโนมัติ
2
เขียนแบบ
📐
📂อยู่เมนู:งานเขียนแบบ
👆ให้กด:เลื่อนการ์ดงานไปคอลัมน์ถัดไป
(รอเริ่ม → กำลังเขียน → รอลูกค้าคอนเฟิร์ม → แก้แบบ → เสร็จ)
✨ผลที่ได้:เห็นชัดว่าใครงานเยอะ งานไหนใกล้เลยกำหนด
3
คิดราคา + เสนอราคา
📄
📂อยู่เมนู:เครื่องคิดราคา
👆ให้กด:เลือกลูกค้า → คิดราคา → กดปุ่มแดง 📤 ส่งเข้าระบบ JR
✓จากนั้น:ไปเมนู ใบเสนอราคา → เปิดใบ → กด อนุมัติ
✨ผลที่ได้:
อนุมัติแล้ว สร้างใบวางบิลต่อได้เลย
4
รับมัดจำ
💰
📂อยู่เมนู:งานทั้งหมด → คลิกงานลูกค้า
👆ให้กด:กรอก ยอดมัดจำ + วันที่ ในแผงงาน แล้วบันทึก
✨ผลที่ได้:
ระบบเลื่อนงานไปขั้นถัดไป + เปิดงานผลิตให้เอง
⚠️ขั้นนี้ ไม่ต้องกดปุ่ม "ไปขั้นต่อไป" — ใช้ฟอร์มมัดจำแทน
5
ผลิต
🏭
📂อยู่เมนู:ผลิต
👆ให้กด:คลิกงาน → เปลี่ยนสถานะไปเรื่อยๆ
(วัดหน้างาน → ผลิต → ตรวจ QC → พร้อมติดตั้ง)
✨ผลที่ได้:
พอตั้ง "พร้อมติดตั้ง" ระบบเปิดงานติดตั้งให้เอง
6
ติดตั้ง + ส่งมอบ
🔧
📂อยู่เมนู:ติดตั้ง
👆ให้กด:เปลี่ยนสถานะ → ตรวจรับ → ตั้ง เสร็จสมบูรณ์
✨ผลที่ได้:
ปิดงาน + ออกใบรับประกัน 12 เดือนให้อัตโนมัติ 🎉
📌 จำง่ายๆ: 3 ขั้นนี้ทำผ่าน "หน้าเฉพาะ" (ไม่ใช่ปุ่มไปขั้นต่อไป)
  • 💰 มัดจำ → กรอกในแผงงาน (เมนูงานทั้งหมด)
  • 🏭 ผลิต → ทำที่เมนู "ผลิต"
  • 🔧 ติดตั้ง → ทำที่เมนู "ติดตั้ง"

นอกนั้นทุกขั้น = เปิดงาน แล้วกด "ไปขั้นต่อไป" พอ

🚩 ลูกค้ามีปัญหา? บันทึกตรงไหน

📂อยู่เมนู:ปัญหางาน
👆ทำได้:ดูว่าลูกค้าคนไหนมีปัญหารอแก้ · กำหนดคนรับผิดชอบ + วันแก้ · บันทึกความคืบหน้า · กดปิดเมื่อแก้เสร็จ
🎨สีบอก:เขียว = ยังมีเวลา · เหลือง = ใกล้ครบ · แดง = เลยกำหนดแล้ว

❓ คำถามที่เจอบ่อย

กดปุ่ม "ไปขั้นต่อไป" ไม่เจอ?

ต้อง คลิกที่ชื่องานลูกค้า ก่อน แผงงานจะเด้งขึ้นมา ปุ่มจะอยู่ บนสุดของแผง (กล่องที่เขียน "ขั้นปัจจุบัน X/24")

กดผิดขั้นจะพังไหม?

ไม่พังครับ ระบบกันไม่ให้กดข้ามขั้นหรือย้อนผิดอยู่แล้ว ถ้ากดไม่ได้แปลว่ายังไม่ถึงเวลาทำขั้นนั้น

อยากดูว่างานลูกค้าอยู่ขั้นไหน?

เมนู "ติดตามงาน" หรือ "งานทั้งหมด" จะเห็นทุกงานพร้อมขั้นปัจจุบัน (X/24)

ทำไมบางขั้นกดปุ่มไม่ได้ ต้องไปหน้าอื่น?

เพราะ 3 ขั้น (มัดจำ / ผลิต / ติดตั้ง) ต้องกรอกข้อมูลจริง ระบบเลยให้ทำผ่านหน้าเฉพาะ แล้วมันจะเลื่อนขั้นให้เองอัตโนมัติ
