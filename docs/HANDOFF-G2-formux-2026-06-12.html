🔴 จุดที่ต้องสะท้อน (มติ)

  • ทำเป็นบาน = "โหมด" ภายในระแนงบังตา (ไม่ใช่หมวดแยก · มติพี่นัท 12 มิ.ย.): เลือกระแนง → กดโหมด "ทำเป็นบาน" → เลือกชนิดบาน (บานเลื่อนเซมิ sliding_sms / ยูโร sliding_euro / บานเปิด casement_euro / บานเฟี้ยม folding / ดัดโค้ง curved_single) · ระแนงสลับเป็น "ไม่โครง" อัตโนมัติ (บานให้โครงเอง) · ราคา = ค่าทำบาน (door base ตาม type จริง) + ค่าระแนงไม่โครง (rate × พื้นที่) · มีช่องกรอกค่าทำบาน override (R3-2) · ตัวอย่าง: บานเลื่อนเซมิ + rn1 ไม่โครง 3×2 = ค่าทำบาน + (3,300×6→20,000)
  • R4 — ราวกันตก: ตัดออปชั่น leak (คาดตาราง/ฝังรางยู/ครอบวงกบ/ดรอปพื้น) · imp1/4 "สแตนเลสสีเงิน" ไม่ซ้ำ (ดู HANDOFF-G2-ROUND4)
  • ราคา dev ดึง engine (มติพี่นัท · ห้ามเดา): ประตูรั้ว (ค่าระแนง×พื้นที่+ค่าทำ+มอเตอร์+ราง) · ระแนงพิเศษ (เลื่อน/เปิด-ปิด) · ราวกันตก ค่ากระจก(glassUp)+สีอลู
