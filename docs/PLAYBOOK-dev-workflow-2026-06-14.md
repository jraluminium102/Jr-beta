## 1. กฎทอง: "1 ไฟล์ 1 มือ" (กันพังหลักสุด)
- **index.html แก้ได้ทีละแชทเท่านั้น** — มี "ช่างแก้" (Chat B / dev) คนเดียว ณ เวลาหนึ่ง
- แชทกลุ่ม (A ออกแบบ UX · G3/G5/G6 ทำสเปก) = **READ-ONLY** ออกดราฟ/REF/handoff ใน `docs/` ไม่แตะ index.html
- **คิวงาน** (ทำทีละกลุ่ม ไม่พร้อมกัน): ดูตารางคิวท้ายไฟล์ · กลุ่มที่ "กำลังแก้" ต้องมีแชทเดียว
- ถ้าจำเป็นต้องแก้ 2 กลุ่มพร้อมกัน → ต้องแน่ใจว่า **คนละโซนโค้ด ไม่ทับกัน** (เช่น G5 แตะ block มุ้ง L722-741 · G3 แตะ block หลังคา) แล้ว commit แยก

## 2. ตาข่ายกันพัง: Golden snapshot (รัน 30 วิ รู้ว่าพังตรงไหน)
สคริปต์: `scripts/golden-snapshot.mjs` — render ทุกสินค้า (143 ตัว G1-5,7) จับ "ยอด/ชุด" เป็นลายนิ้วมือ
```
node scripts/golden-snapshot.mjs --save   # บันทึก baseline (ทำตอนของยังดี · ทำแล้ว 14 มิ.ย.)
node scripts/golden-snapshot.mjs          # เทียบ baseline · ยอดไหนขยับ = เด้งแดง · exit 1 ถ้ามี diff
```
**ใช้ยังไง:**
1. ก่อนเริ่มแก้ → รัน compare ให้เขียวก่อน (ยืนยันจุดเริ่มสะอาด)
2. หลังแก้แต่ละธง → รัน compare อีกที
   - ✅ เขียว = ไม่กระทบตัวอื่น ปลอดภัย
   - 🟡 ยอดเปลี่ยน "เฉพาะตัวที่ตั้งใจแก้" = ถูกต้อง → `--save` อัป baseline ใหม่
   - 🔴 ตัวที่ **ไม่ได้ตั้งใจแก้** ขยับ/พัง = แก้พลาด ทำของกลุ่มอื่นเพี้ยน → revert/แก้ก่อนไปต่อ
3. กดเองในเบราว์เซอร์จริงเหลือไว้ verify **เฉพาะ UX ที่แตะ** (snapshot ไม่จับ UX/หน้าตา จับแต่ราคา)

หมายเหตุ: ❌ G6 (กั้นห้อง) ไม่อยู่ใน snapshot (flow room-builder คิดราคาไม่ผ่าน i-prod เดี่ยว) — ใช้ `test/g6-phaseB-flags.mjs` แทน
มี test เดิมอีกชุดเสริมได้: `test/calc-consolidated.mjs` · `test/quote-fidelity.mjs` · `test/qa-t5-totals.mjs`

## 3. แก้ทีละก้อนเล็ก = 1 ธง 1 commit
- **ห้ามแก้ทีเดียว 20 จุด** (แบบ G6 ที่ผ่านมา) — แตกเป็น "ธง" ย่อย เรียง **เสี่ยงน้อย→มาก**
- 1 ธง = 1 จุดประสงค์ = 1 commit (+ snapshot เขียว) → พังก็ revert ก้อนเดียว ไม่ลามทั้งไฟล์
- ของใหม่/พฤติกรรมเปลี่ยน → ใส่หลัง flag (`(guarded)` แบบที่ทำอยู่ ดีมาก) จนกว่าจะ verify ครบ
- commit message สั้นบอกธง: `fix(G5): สีกรอบเฟรมคิดเงิน — flag mscolorFrame [ธง#3]`

## 4. handoff ที่ dev แก้ได้ไว (ชี้จุดเป๊ะ → mechanical)
แต่ละธงในเอกสารส่ง dev ต้องมี **5 ช่อง**:
| ช่อง | ตัวอย่าง |
|---|---|
| 🎯 จุดแก้ | `function calcUnit` L1257 (block `p.mscolor`) |
| 🔍 ของเดิม | วาง search-string เดิม (คัดลอกตรงจากไฟล์) |
| ✏️ แก้เป็น | โค้ดใหม่ที่ต้องการ |
| ✅ เทส | กรอก imp21 ประตู 1.5×2.0 → ต้องได้ ฿X (เลขชัด) |
| 🚩 flag | ชื่อ flag (ถ้ามี) + default off |

ทำแบบนี้ dev ไม่ต้องเดา = แก้ไว + พลาดน้อย + QA เทียบยอดได้ตรง
