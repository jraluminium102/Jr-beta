  ตัวที่ใช้จริงคือ `JR_บานยก_ฟูจิ` · `JR_เฟี้ยม_SMS_รวม` · `JR_เฟี้ยมยูโร`

## เครื่องมือ

```bash
node scripts/diffxlsx.mjs <เก่า.xlsx> <ใหม่.xlsx> [--full]
```

เทียบค่าในช่องทีละช่อง บอกชีต/ตำแหน่ง/ค่าเก่า→ใหม่ ใช้ตอนไฟล์ตัดประกอบอัปเดตรอบหน้า
