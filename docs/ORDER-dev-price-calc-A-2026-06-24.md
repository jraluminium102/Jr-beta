## 🔑 สูตรจริงที่ขุดจาก engine (ใช้เขียนโหมด 🔍 ให้ตรง)
- `basePrice` (L~1384): bucket = `Math.max(min, monoRate(area, RATES[rates]))`
- `monoRate(area,t)` (L~1383): `max(area×rateOf(area), ค่าสูงสุดของช่วงก่อนหน้า)` — เรตเลือกตาม "ช่วงพื้นที่" ในตาราง RATES (L~564+ · `[[minพื้นที่,maxพื้นที่,เรต/ตร.ม.]]`)
- `roundUp(x)` (L~1375): `Math.ceil(x/1000)*1000` (ปัดขึ้นพันบาท)
- min ต่อรุ่น (PRODUCTS), มุ้ง = min_door/min_window
- **Protection (svc-protect) = ติ๊ก default +2,000** ทุกงาน (เป็น service-level · โชว์เป็นบรรทัดในโหมด 🔍/📊)
- ออปชั่น (มุ้ง/มือจับ/ล็อก/คาดตาราง...) = addon delta จริง (เช่น มุ้ง imp21 บน 1.8×2.1 = +6,000)

ตัวอย่าง verify (ปิด Protection): บานเลื่อน SMS 1.8×2.1 → 5,700×3.78=21,546 → ปัด 22,000 · หลังคา ROOF_STD 4×3 → 6,000×12=72,000 · มุ้ง IMP21 1×2 → 1,700×2=3,400 → ปัด 4,000

## ธง

### F1 — engine `calcUnit` คาย `calcSteps` ต่อรายการ (หัวใจ · read-only)
**ทำ:** ให้ calcUnit return เพิ่ม field `calcSteps` (ไม่กระทบ `sell`) บรรจุ:
`{ method, ratesKey, area, bucketRate (เรต/ตร.ม. ที่เลือก), bucketRange ([min,max]พื้นที่), baseRaw (area×rate), monoBumped (bool), minApplied, rounded, addonLines:[{label, amt}] }`
- addonLines = ออปชั่นที่คิดเงินจริง (มุ้ง/มือจับ/ครอบวงกบ/คาดตาราง/โช้ค...) แต่ละบรรทัด + amt จริง · **ตัวที่ไม่มีราคา ไม่ต้องใส่**
- **ห้ามเปลี่ยนค่า sell / ลำดับคำนวณ** — แค่ "บันทึกระหว่างทาง" แล้ว return ออกมา
**เกณฑ์ผ่าน:** golden 150/150 เป๊ะ (ถ้าขยับ = ไปแตะสูตร = ผิด) · calcSteps ของ sliding_sms 1.8×2.1 = {area:3.78, bucketRate:5700, baseRaw:21546, rounded:22000}

### F2 — UI ปุ่มโหมด 3 แบบ ในหน้าใบ (ตามดราฟ · ปุ่มสวย)
**ทำ:** เพิ่มแถบปุ่มบนหัวใบ: `👤 ลูกค้า (ปกติ)` / `📊 แยกราคาแต่ละส่วน` / `🔍 วิธีคิดราคา (เฟิร์นตรวจ)` · default = 👤 ลูกค้า · สไตล์ปุ่มตามดราฟ (chip ปุ่มใหญ่ on=ทึบ)
**เกณฑ์ผ่าน:** กดสลับ 3 โหมดได้ · ค่าเริ่มต้น = ลูกค้า · หน้าตา/ลำดับตรงดราฟ

### F3 — โหมด 🔍 วิธีคิดราคา (เฟิร์น · ภายใน)
**ทำ:** ใต้แต่ละรายการ แสดง calcSteps อ่านง่าย: `พื้นที่ = กxส = X ตร.ม.` · `เรต (ช่วง a–b ตร.ม.) = R/ตร.ม. × X = baseRaw` · `ปัดขึ้นพันบาท = rounded` · `(ขั้นต่ำ M — สูงกว่า/ใช้ขั้นต่ำ)` · `+ [ออปชั่น] = amt` (เฉพาะที่มีราคา) · ป้าย "ไม่พิมพ์ให้ลูกค้า"
- **reuse:** โครงใบเดิม (qrow) · แค่เติม block calcSteps ต่อ item เมื่อโหมด=firm
**เกณฑ์ผ่าน:** เลขตรง engine (เทียบตัวอย่าง verify ด้านบน) · ออปชั่นไม่มีราคาไม่โผล่ · ไม่มีศัพท์ dev รก

### F4 — โหมด 📊 แยกราคา (ส่งลูกค้า)
**ทำ:** แสดงราคาแต่ละส่วน/ออปชั่นแบบน่าอ่าน (reuse breakdown เดิม · เหมือนใบที่ทำไว้) — ราคาย่อยต่อบรรทัด ไม่มีสูตร
**เกณฑ์ผ่าน:** เหมือนใบเดิม + มีราคาย่อยอ่านง่าย

### F5 — print/ลูกค้า ต้องไม่ติดโหมด 🔍
**ทำ:** เวลาพิมพ์/ส่งลูกค้า = บังคับโหมด 👤 (หรือ 📊) · บล็อก 🔍 มี class กันพิมพ์ (`@media print{display:none}` + ไม่ออกในไฟล์ลูกค้า)
**เกณฑ์ผ่าน:** พิมพ์ตอนเปิดโหมด 🔍 → ใบที่ออกไม่มีวิธีคิด/ไม่มีป้ายภายใน

### F6 — ครบทั้ง 7 กลุ่ม (engine ร่วม)
**ทำ:** เพราะ calcUnit/genQuote ร่วมกัน → ทำ F1-F5 ที่จุดเดียว ใช้ได้ G1-G7 · เช็กกลุ่มที่ method ต่าง (fold/lift/ceLinear/per_sqm/room G6) ว่า calcSteps แสดงถูก (ไม่ใช่แค่ bucket)
**เกณฑ์ผ่าน:** สุ่ม 1 รุ่น/กลุ่ม เปิดโหมด 🔍 → เห็นวิธีคิดถูกตามแต่ละ method
