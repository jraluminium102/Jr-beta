จุดแก้รายละเอียด
1.1 กลุ่มงานครบ 7.qi-group (addQuickItem ~L1766) เดิมมี 2 กลุ่ม → ใส่ครบ 1-7 เหมือนหน้าเต็ม · เปลี่ยน prodOptionsG() → prodOptionsG6() (list สินค้าชุดเดียวกับหน้าทำใบ)
1.2 เพิ่มสีอลู + กระจกเพิ่ม 2 dropdown ในแถวเดิม: .qi-color (colorOpts()) + .qi-glass (glassOpts()) · โชว์เฉพาะสินค้าที่ใส่ได้ — ใช้กติกาเดียวกับหน้าเต็ม (สินค้าที่หน้าเต็มโชว์ .i-color-wrap/.i-glass-wrap) · ซ่อนเมื่อไม่เกี่ยว (เช่น หลังคา/ตู้/ม่านซิป)
1.3 ราคาคิดสี+กระจกจริงreadQuickItem (~L1786) เดิม calcUnit(p,w,h,0,0,panels,{},false) = ล็อกสีขาว+กระจกแรกตลอด → ส่ง gi=qi-glass.value · ci=qi-color.value จริง
1.4 ออปชั่นอื่นไม่เพิ่ม (มือจับ/มุ้ง/ธรณี/คาดตาราง ฯลฯ ตัดทิ้งตามมติ — โหมดนี้ไว้ตีราคาเร็ว)
1.5 จำนวนบาน/labelคงของเดิม (qiWLabel casement "กว้าง/บาน" ทำงานต่อ · usesPanels ซ่อน/โชว์เดิม)

ส่วนที่ 2 — ภาพรวมทุกกลุ่ม (จากดราฟ DRAFT-ALLG-ux-2026-06-13 · UX ผ่านแล้ว)

จุดแก้รายละเอียด
2.1 🔴 ชิปรูปแบบ wrap แนวนอนชิปตระกูล/รุ่น (.fam-prodsel ฯลฯ) เดิมตกแนวตั้งทีละปุ่ม → CSS ชิป flex:0 0 auto + container display:flex;flex-wrap:wrap;gap:6px กว้างตามข้อความ (ดูดราฟ .chips)
2.2 🔴 ประตู/หน้าต่าง = ติ๊กเล็กชิป .i-type เดิม 2 ปุ่มใหญ่เต็มแถว (chip-2up 52px) → segment เล็ก รวมบรรทัดเดียวกับ กว้าง·สูง·จำนวนบาน (ดูดราฟ .seg + .row) — ทั้ง 6 กลุ่มที่มีประเภท
2.3 🟡 แถบสีทั้งใบย้ายลงแถบ "สีอลู/กระจก (ทั้งใบ)" จากหัวรายการ → บรรทัดเดียวในการ์ด ใต้โซนขนาด + ปุ่ม "แก้เฉพาะรายการนี้ ▾" (รอเคาะข้อ A ด้านล่าง)
2.4 จำนวนบาน stepperช่องตัวเลข → stepper −/+ ในแถวขนาด (รอเคาะข้อ B)
