addQuickItem() สร้าง 1 การ์ด:
  ├ เลือกกลุ่มงาน (ชิป 1-7)         → กำหนด renderer ของกลุ่ม
  ├ ฟอร์มเฉพาะกลุ่ม (จากดราฟกลุ่มนั้น)  → เก็บ input

  │                       → เรียก calcUnit() → sell
  └ การ์ดราคาขวา (โชว์ breakdown จาก calcUnit.msgs + sell)
