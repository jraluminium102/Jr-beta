FIX 2 — G1 สี/กระจก: dropdown → drill-down chips (ตามดราฟ)

ใน qiRenderG1 (~L2587-2589) ตอนนี้ใช้ <select class="qi-color"> + <select class="qi-glass"> (dropdown). ดราฟ G1 ทำเป็น drill-down: สี = หมวด→swatch สีจริง · กระจก = หมวด→ชนิดย่อย→รุ่น (3 ชั้น)

โค้ด drill-down พร้อมใช้อยู่ในดราฟแล้ว: public/review/DRAFT-quickmode-ux-2026-06-16.html — ก๊อป logic COLOR_CATS (swatch หมวด→สี) + glassCat/glassSub (กระจก 3 ชั้น) มาใส่ qiRenderG1
วิธีต่อให้ราคาไม่พัง (สำคัญ):
  • เก็บ <select class="qi-color"> + <select class="qi-glass"> ไว้ (ซ่อน display:none) — เพราะ readQuickItem อ่าน 2 ตัวนี้คิดราคา (ห้ามแตะ readQuickItem/calcUnit)
  • เพิ่มชิป drill-down ข้างบน · กดชิป → set select.value = index แล้ว select.dispatchEvent(new Event('change')) → ราคาคิดเหมือนเดิม (gi/ci เป๊ะ)
  • map: ชิปสี → index ใน COLORS (ci) · ชิปกระจก → index ใน GLASS (gi) · ทั้งคู่ global อยู่แล้ว
  • โชว์สี/กระจก เฉพาะสินค้าที่ใส่ได้ (เงื่อนไขเดิมใน qiRenderG1: NO_COLOR_CATS / zipscreen / มุ้ง)
