BUG กล่องฟ้า "บานเลื่อน:" ค้างเมื่อสลับ product

อาการ: เลือกบานเลื่อน/บานเปิด/ติดตาย แล้วเปลี่ยนเป็น หลังคา/ฝ้า/มุ้ง → กล่องฟ้า "🔢 บานเลื่อน: ชนิดการเปิด / ติดตาย-เปิด / ราง รางล่าง(รุ่นกันน้ำ)" ค้างอยู่ ทั้งที่ไม่ควรมี (พี่นัทเจอตอนเล่นหลังคาเลื่อน)
ยืนยันจากแอปจริง: roof_vinyl มี .sliding-main-block ค้างใน .chgrid (นอก .i-opts)

Root cause: relocation บรรทัด 2422-2430 ย้าย .sliding-main-block ออกจาก .i-opts ขึ้นไปไว้ฟอร์มหลัก .chgrid · พอเปลี่ยน product → buildItemOpts สร้าง .i-opts ใหม่ (หลังคาไม่มีกล่องนี้) แต่กล่องที่ย้ายไป .chgrid แล้วไม่ถูกลบ (โค้ดหา .sliding-main-block แค่ใน box=.i-opts เลยไม่เจอ orphan)

วิธีแก้: ตอนต้น buildItemOpts ก่อน rebuild:

  1. หา .sliding-main-block เก่าใน d (ทั้งรายการ ไม่ใช่แค่ box)
  2. ย้าย .i-panels-wrap (ที่ถูกดูดเข้าไปในกล่องฟ้า บรรทัด 2427) ออกมาเก็บก่อน
  3. ลบ .sliding-main-block orphan ทุกตัวทิ้ง
  4. ค่อยสร้าง+relocate ใหม่ เฉพาะ cat ที่ควรมี (บานเลื่อน/เลื่อนภายใน/บานเปิด/ติดตาย)

ทดสอบ: เพิ่มรายการบานเลื่อน → เปลี่ยนเป็นหลังคา → ต้องไม่เหลือกล่อง "บานเลื่อน: ชนิดการเปิด/ราง" · เปลี่ยนกลับเป็นบานเลื่อน → กล่องกลับมาปกติ + จำนวนบานไม่หาย

UX — กรอกง่ายขึ้น (ตรวจโดย subagent)

P1 ยุบ "ของเสริมหลังคา" เป็น dropdown พับ (default ปิด)

บล็อกหลังคามี ~17 ช่อง · ช่อง "ของเสริม" 10+ ตัว (รางน้ำ/คาน/เสา/โซ่/ครอบท่อ/ซ่อนสโลป/ปิดซ่อนราง/ครอบคาน) เคสปกติว่าง

  • ที่: label "ของเสริมหลังคา" บรรทัด ~2316 ครอบ 2317-2327
  • แก้: เปลี่ยนเป็น <details class="optbox"> (มี style พับใน codebase แล้ว 169-172) · summary = "+ ของเสริมหลังคา (รางน้ำ/เสา/คาน/ซ่อนสโลป...)" · ปิด default · เหลือ 4 ช่องหลัก (สี/แป/โครงสร้าง/ปลายหลังคา) โชว์
  • ผล: เคสปกติเห็น ~4 ช่องแทน 17

P2 จำนวนบานเลื่อน = ชิป + stepper (เลิกพิมพ์)

  • ที่: .o-spanels บรรทัด ~2286 (<input type="number"> 50px)
  • แก้: ชิปกดเลือก [2] [3] [4] [6] (แต่ละชิป ≥44px) + stepper [−] N [+] สำหรับเลขแปลก · กดชิป = set ค่า + เรียก rfSlideMotorFill + calcQuote (handler เดิม) · เก็บ input number เป็น source of truth (readItem เดิมไม่ต้องแก้)
  • ดูตัวอย่างในดราฟ (chips ทำงานแล้ว)

P3 ปุ่ม/ช่องแตะง่าย 44px (มือถือ)

  • ช่อง number ทุกตัวสูง 30px · checkbox เล็ก (.opt input{width:auto;height:auto} บรรทัด 62)
  • แก้ (CSS, media มือถือ ~163): .ch .opt input[type=number], .ch .opt select { min-height:44px } + .opt input[type=checkbox]{width:22px;height:22px} + padding label ให้กดทั้งแถบ · เดสก์ท็อปคงคอมแพกต์

P4 หลังคาเลื่อน: มอเตอร์ auto ชัด + พื้นที่ placeholder

  • พื้นที่เลื่อน: เปลี่ยน value="0" → placeholder="auto" ค่าว่าง (logic ราคา sa>0?sa:auto รองรับว่างแล้ว) — เลิกสับสน "0 คือ auto หรือ 0 จริง"
  • มอเตอร์: โชว์ค่า auto เป็น ข้อความ helper อ่านอย่างเดียว "มอเตอร์ 1 ตัว · auto ฿28,000 [แก้ราคา]" · กด "แก้ราคา" ค่อยเปิดช่องพิมพ์ (มี dataset.edited รองรับแล้ว) → เคสปกติ 0 การพิมพ์
  • เรียง: จำนวนบาน → พื้นที่ → มอเตอร์ (มือถือแยกบรรทัด)

P6 ฝ้า/ผนัง — โอเคแล้ว

โชว์ 2-3 ช่องต่อวัสดุ (บรรทัด 2371-2383) ลีนพอ ไม่ต้องยุบ · ได้ P3 (ปุ่มใหญ่) ก็พอ
