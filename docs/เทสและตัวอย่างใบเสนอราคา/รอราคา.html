💰 รายการราคาที่รอเติม

ตัวเลือกที่ "ใส่ในระบบแล้ว ใช้งานได้" แต่ราคายังรอพี่นัทแจ้ง · เติมในช่องสีเหลือง → แจ้ง Claude ใส่ลงระบบ
#รายการใช้กับหมวดสถานะระบบราคาที่ต้องเติมหมายเหตุ
1แผ่นลูกฟูกล่าง (อลู)ทุกหมวดบาน (เลื่อน/เปิด/เฟี้ยม/กระทุ้ง)มี option แล้วราคามีใน R3.9 → ดึงมาพี่นัทบอกราคาอยู่ในสูตรไฟล์เวิร์ด R3.9 แล้ว — แชทถัดไปดึงมาใส่
2แผ่นคอมโพสิทล่างทุกหมวดบานมี option แล้วราคา R3.9 → ดึงมาเหมือนข้อ 1
3กระจกอินซูเลท 2 ชั้น (5+อากาศ+5)หน้าต่าง/ประตู (บานเลื่อน/เปิด/ติดตาย/เฟี้ยม/กระทุ้ง)มี option แล้ว฿_____ /ตร.ม.รอราคาจากนิด · ตอนนี้กรอกผ่าน OPTION± ได้
4งานพื้น (สมาร์ทบอร์ด / ไม้เทียม decking)ทุกหมวด (เลือกได้)มี option แล้ว฿_____ (ต่อรุ่น/ตร.ม.)รอรุ่น + ราคา · ตอนนี้พิมพ์ชนิด + กรอกราคาเองได้
5กระจกเงา 2 ด้านบาน (เลื่อน/เปิด)ยังไม่มี (กรอกเอง)฿_____ /ตร.ม."ไว้ทีหลัง" · ตอนนี้พิมพ์ในหมายเหตุ + OPTION±
6กระจกลอนแก้วบาน/ติดตายยังไม่มี (กรอกเอง)฿_____ /ตร.ม."ไว้ทีหลัง"
7สีอลูชุบทอง / อโนไดซ์ทุกหมวดกรอกเอง (ไม่มีรหัส)กรอกเอง — OKพี่นัทบอก "ปล่อยไป กรอกเอง" — ไม่ต้องเติมในระบบ
วิธีใช้: ราคาที่รอ → ตอนนี้เซลล์กรอกผ่านช่อง OPTION ±บาท หรือ ราคาเหมา ในแต่ละรายการได้เลย (ใช้งานได้ทันที) · เมื่อพี่นัทแจ้งราคาทางการ → Claude ใส่เป็นราคาในสูตร (auto-calc) แทนการกรอกมือ
เพิ่มรายการใหม่: พี่นัทแจ้งมาเรื่อยๆ → Claude เพิ่มลงตารางนี้ + ใส่ option ในระบบ
