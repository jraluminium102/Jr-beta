# USERTEST_FINANCE — ผู้ใช้จำลอง 6 personas เดิน flow การเงิน

ทีม agent สวมบทผู้ใช้จริง เดิน calc → ใบเสนอ → อนุมัติ → ใบวางบิล → ใบเสร็จ (อ่านโค้ดจริง)

## ผล: เดินจบ 4/6 · ตัน 2/6 (accounting, edge-customer)

### ธีมปัญหาซ้ำ
- **T1 (6/6):** ปุ่ม "สร้างใบเสนอราคา" ในเครื่องคิดราคา**หลอก** — `genQuote`/`genQuoteQuick` แค่พรีวิวในเครื่อง ปุ่มจริงคือ `sendToQuotation` (📤 แดง) → ทุกคนกดผิด ตันก้าวแรก
- **T2 (6/6):** ฟอร์มใบเสนอ default ลูกค้า = `customers[0]` เงียบ ๆ → **ออกบิลผิดคน** (snapshot ผิดไหลถึงใบวางบิล/ใบเสร็จ)
- **T3 (5/6):** ช่องชื่อลูกค้าซ้ำ 2 ที่ (ดรอปดาวน์ทะเบียน vs `custName` ใน iframe) งง
- **T4 (3/6):** fuzzy-match `includes` 2 ทาง match ผิดแต่โชว์ banner **เขียว "ยืนยันแล้ว"** → มั่นใจผิด
