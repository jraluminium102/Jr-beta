เรื่องที่ 1 — "+ เพิ่มส่วน" flow ใหม่

ปัญหาเดิม (ยืนยันจากพี่นัทกดเบราว์เซอร์จริง)

BEFORE — toggleAddSecPanel (L1947)
  • กดปุ่ม "+ เพิ่มส่วน" (.set-addpart) → เรียก toggleAddSecPanel(btn, box)
  • ฟังก์ชันสร้าง panel แบบ toggle: กดซ้ำ = ลบ panel ออก
  • ใน panel: ชิป 8 ตัว + ปุ่ม "งานบานทั่วไป" → ต้องกดต่ออีก 1 ครั้งถึงได้การ์ด
  • tap count: เพิ่มงานบาน = 2 tap · เพิ่มซ้ำ = 3 tap (เปิด panel ใหม่)
  • ผล: รู้สึกว่า "กด เพิ่ม แล้วไม่เพิ่ม" + toggle สับสน

ดีไซน์ที่เลือก — แบบ (ก) + persistent strip

AFTER — 2 ส่วนแยก หน้าที่ชัด
  1. Persistent quick-strip — แถวชิปของใช้บ่อย เห็นตลอดเวลา (ไม่ toggle ไม่หาย)
    กดชิป → quickAddItem ทันที (1 tap) · ชิปไม่หายหลังกด → กดซ้ำได้
  2. ปุ่ม "+ เพิ่มส่วน" (งานบานทั่วไป) — กดแล้วได้การ์ดทันที addItem + calcQuote
    ไม่มี toggle ไม่มี panel กลาง · ปุ่ม verb ทำตามชื่อ

เหตุผลที่เลือกแบบนี้

  • แบบ (ก): "เพิ่มส่วน" = เพิ่มทันที ตรงกับชื่อปุ่ม ไม่งง
  • ชิปด่วนเห็นตลอด: เซลล์ที่เพิ่มของบ่อยซ้ำไม่ต้องสะดุดทุกครั้ง
  • ลด tap จาก 2-3 เหลือ 1 ทุกเส้นทาง
  • ไม่กระทบ logic/ราคา — แค่จัด UI ใหม่, quickAddItem เดิมใช้ได้

เรื่องที่ 2 — ชิปจำนวนบานมุ้ง

ปัญหาเดิม

BEFORE — buildItemOpts (L2586)
  • .o-mosqpanels = <input type="number" width:50px placeholder="auto">
  • เซลล์ต้องจำว่าบานประตู (.i-panels) มีกี่บาน → ตัวเองพิมพ์ตัวเลข
  • ไม่มี visual เชื่อมระหว่าง i-panels กับ o-mosqpanels → ผิดพลาดได้ง่าย
  • 3 ช่องเรียงบรรทัดเดียว (กว้าง × ยาว · บาน) — อ่านยาก บน mobile

ดีไซน์ที่เลือก — ชิปจำนวนบาน + fallback

AFTER — ใน mosq-detail-group (แทรกก่อน o-mosqw/h/panels)
  1. ชิปจำนวนบาน (วิธีหลัก): แสดงชิป "auto", 1, 2, …, N โดย N = ค่า .i-panels
    · กดชิป → set .o-mosqpanels.value = ตัวเลข (auto = ว่าง) → fire input event → calcQuote()
    · N > 5 → ซ่อนชิป แสดง stepper แทน (fallback)
  2. ช่องขนาด (กว้าง×ยาว) — พับ default: ย้ายเข้า <details> "กรอกขนาดมุ้งเอง (กรณีแต่ละบานไม่เท่ากัน)"
    · .o-mosqw / .o-mosqh ยังเชื่อมกับ calcQuote ตามเดิม ไม่เปลี่ยน logic
  3. .o-mosqpanels ยังอยู่ในฟอร์ม (hidden หรือ sync) — readItem เดิมใช้ได้ไม่เปลี่ยน

State machine

กรณีUI.o-mosqpanels valueราคา
ชิป "auto"chip auto = on"" (ว่าง)auto คำนวณจากบาน
ชิป "2"chip 2 = on"2"2 บาน × max(min, พื้นที่×rate)
ชิป "4"chip 4 = on"4"4 บาน ×…
N > 5 (fallback)stepper แสดงstepper.valueN บาน ×…
กรอกขนาดเองdetails คลายคงค่าชิปใช้ w/h ที่กรอก แทน auto

เกณฑ์ชิป N > 5

ถ้า i-panels > 5 → ชิปจะมี 6+ ปุ่ม ใหญ่เกิน → ซ่อนชิปทั้งแถว แสดง stepper แทน
ตัวเลข 5 เป็น default ตาม UX principle "ชิป > 5 รายการ เริ่มอ่านยาก"

2. afterBuildOpts — rebuild ชิปตาม i-panels (เพิ่ม helper ใหม่)

ใน buildItemOpts หรือ event handler หลัง build เสร็จ:

function rebuildMosqPanelChips(d){
  // d = .ch div ของบานนั้น
  var bar = d.querySelector('.mosq-panels-bar');
  if(!bar) return;
  var chipWrap = bar.querySelector('.mosq-panel-chips');
  var fallback = bar.querySelector('.mosq-panels-fallback');
  var hiddenInp = d.querySelector('.o-mosqpanels');
  var iPanels = parseInt((d.querySelector('.i-panels')||{}).value||'2') || 2;

  chipWrap.innerHTML = '';
  if(iPanels > 5){
    // fallback stepper
    chipWrap.style.display = 'none';
    fallback.style.display = 'flex';
    var stepper = fallback.querySelector('.o-mosqpanels-stepper');
    if(stepper && hiddenInp.value) stepper.value = hiddenInp.value;
    return;
  }
  chipWrap.style.display = 'flex';
  fallback.style.display = 'none';

  // chip "auto"
  chipWrap.appendChild(makeMosqChip('', 'auto', hiddenInp, d));
  // chip 1…N
  for(var i=1; i<=iPanels; i++){
    chipWrap.appendChild(makeMosqChip(String(i), i+' บาน', hiddenInp, d));
  }
  // mark active chip
  var cur = hiddenInp.value;
  chipWrap.querySelectorAll('.mosq-panel-chip').forEach(function(c){
    c.classList.toggle('on', c.dataset.val === cur);
  });
}

function makeMosqChip(val, label, hiddenInp, d){
  var btn = document.createElement('button');
  btn.type = 'button';
  btn.className = 'mosq-panel-chip chip'; // ใช้ class chip เดิมสำหรับ style
  btn.dataset.val = val;
  btn.textContent = label;
  btn.style.cssText = 'min-height:44px;min-width:44px;padding:0 12px;font-size:14px;font-weight:700;';
  btn.addEventListener('click', function(){
    hiddenInp.value = val;
    hiddenInp.dispatchEvent(new Event('input', {bubbles:true}));  // → calcQuote
    // update active
    var wrap = btn.closest('.mosq-panel-chips');
    wrap.querySelectorAll('.mosq-panel-chip').forEach(function(c){ c.classList.remove('on'); });
    btn.classList.add('on');
  });
  return btn;
}

function syncMosqPanels(stepper){
  // sync stepper → hidden .o-mosqpanels
  var d = stepper.closest('.ch');
  var hid = d.querySelector('.o-mosqpanels');
  if(hid){ hid.value = stepper.value; hid.dispatchEvent(new Event('input',{bubbles:true})); }
}
