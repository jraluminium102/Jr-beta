# ⚠ แจ้งทุกแชท: docs/ จัดโฟลเดอร์ใหม่เป็น "ชื่อไทย" แล้ว (14 มิ.ย. 2026 รอบ 2)

เดิมใช้ชื่ออังกฤษ (G1–G6 / _cross-group / _general 96 ไฟล์) อ่านยาก → **เปลี่ยนเป็นชื่อไทย + แบ่งหมวดเยอะขึ้น**
เปิด **`docs/INDEX.md`** = สารบัญเต็ม

## ตารางแปลง path เก่า → ใหม่
| เดิม | ใหม่ |
|---|---|
| `docs/G1/` | `docs/กลุ่ม1-งานบาน-เลื่อนเปิดเฟี้ยม/` |
| `docs/G2/` | `docs/กลุ่ม2-รั้วระแนงราวกันตก/` |
| `docs/G3/` | `docs/กลุ่ม3-หลังคากันสาดฝ้า/` |
| `docs/G4/` | `docs/กลุ่ม4-ตู้/` |

| `docs/G6/` | `docs/กลุ่ม6-กั้นห้องกระจก/` |
| `docs/_cross-group/` | `docs/งานข้ามกลุ่ม-G1ถึงG6/` |
| `docs/_general/` (96 ไฟล์) | แตกเป็น 5 หมวด ↓ |

## `_general` แตกเป็น (ตามชื่อไฟล์)
- `SPEC-* / handoff-* / PROMPT-*` → `docs/สเปกและส่งdev/`
- `report-* / AUDIT-* / REVIEW-* / VERIFY-* / BUGS-* / QA-* / CHANGELOG-*` → `docs/รายงานตรวจสอบaudit/`
- `TEST-* / SAMPLE-* / quote-* / PILOT-*` → `docs/เทสและตัวอย่างใบเสนอราคา/`
- `คู่มือ* / how-*` → `docs/คู่มือใช้งาน/`
- ที่เหลือ → `docs/อื่นๆเบ็ดเตล็ด/`

## หาไฟล์ไม่เจอ?
1. เปิด `docs/INDEX.md` (สารบัญ)
2. ชื่อไฟล์เดิมไม่เปลี่ยน — เปลี่ยนแค่ชื่อโฟลเดอร์ เช่น
   - `docs/G6/REVIEW-G6-GROUPED-...` → `docs/กลุ่ม6-กั้นห้องกระจก/REVIEW-G6-GROUPED-...`
   - `docs/_cross-group/COMPARE-G1-vs-G6-...` → `docs/งานข้ามกลุ่ม-G1ถึงG6/COMPARE-G1-vs-G6-...`
3. หาไม่เจอจริง → `Glob docs/**/<ชื่อไฟล์>`

## หมายเหตุ
- โค้ดจริง `public/calculator/index.html` **ไม่ได้ย้าย** · ระบบไม่กระทบ
- ดราฟใหม่ออกที่ `docs/` แล้วค่อยจัดเข้าโฟลเดอร์หมวด
