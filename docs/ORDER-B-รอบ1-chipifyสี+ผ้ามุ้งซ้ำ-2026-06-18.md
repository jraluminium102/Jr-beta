## 🟧 โซน Z4 — chipify สี/ผิว (เหมือนกันข้าม G)

### A1. `o-mscolor` สีกรอบมุ้ง 12 สี → ชิป+จุดสี (G5 · L4534)
- ปัจจุบัน: `<select class="o-mscolor">` + `COLORS.map(i>=2)` value=index · ตัวแรก value="" = "ตามสีบาน (ฟรี)"
- แก้: ทำชิป**แบบ ค (ชื่อย่อ+จุดสีกลม)** เหมือน global สีอลู / ชินโค · ใช้ `rfChipsSw` + จุดสีจาก `COLOR_SWATCH` (L~991 · ชุดเดียวกับ colorDrill)
- **คงค่า:** chip value = COLORS index เดิม (≥2) · ชิปแรก value="" = "ตามสีบาน" · ชื่อเต็มลงใบเหมือนเดิม (อ่าน L5716 `parseInt(optSel.mscolor)` ไม่ต้องแตะ)

### A2. `o-ftcolor` สีฝาตู้ 12 สี → ชิป+จุดสี (G4 · L4568)
- **โค้ดเหมือน A1 เป๊ะ** (COLORS.map i>=2 · value=index) ต่างแค่ตัวแรก value="0" = "ขาว/ดำ (ฟรี)"
- แก้: **ทำชุดเดียวกับ A1** (สไตล์เดียวกัน) · คงป้ายเตือน "⚠ สีเส้นสำเร็จ ดูตัวอย่างจริงก่อน" ไว้ · อ่านค่า L4878 ไม่แตะ

### A3. `o-gcfinish` สีอบปิดราง 8 ตัว → ชิป (G3 ปิดซ่อนรางน้ำ · L1537)
- ปัจจุบัน: `<select class="o-gcfinish">` value=ราคา (value="0" ซ้ำ 3 ตัว มี data-n · paid 700/2500/3500) — **โครงเหมือน bsfinish/bocfinish เป๊ะ**
- แก้: เพิ่ม `'o-gcfinish'` ใน `CHIPIFY_SELECTS` (L3314) **+ CHIPIFY_BIG** (8 ตัว > 7 ต้อง big เหมือน bsfinish/bocfinish) → chipify ผ่าน **selectedIndex** = ราคา/ชื่อ (data-n) ตรงเป๊ะ
- verify: กดชิปสีอบขาว/ดำ/ไม่อบ (value ซ้ำ 0) แล้ว ชื่อ+ราคาตรงตัวที่กด (ไม่เด้งตัวแรก)

### A4. `o-rfsealercolor` สีซีลเลอร์ 3 สี → ชิป (G3 · L4401)
- 3 ตัว (ขาว/ดำ/เทา) ≤7 → เพิ่ม `'o-rfsealercolor'` ใน `CHIPIFY_SELECTS` พอ (ไม่ต้อง big)

## 🟨 โซน Z3 — ข้อความใบ (คนละโซน ไม่ชน Z4)

### B1. ตัดผ้ามุ้งซ้ำในรายการ imp21 (G5 · L5730)
- ปัญหา: ใบ imp21 โชว์ผ้า 2 ที่ — รายการ "...ผ้ามุ้งไฟเบอร์" (จากชื่อ `_mqNm` L5730 ตัดแค่วงเล็บ) + รายละเอียด "ผ้าไฟเบอร์ดำ" (`_mSpec` L5722)
- แก้: ใน `_mqNm` (L5730) ตัดคำ "ผ้ามุ้ง..." ออก **เหมือน L5420 ทำแล้ว** (`.replace(/\s*ผ้ามุ้ง\S*\s*/g,' ')` หรือ regex เทียบเท่า) → รายการเหลือ "มุ้งเฟรมเล็ก บานเลื่อน" · ผ้าโชว์ที่รายละเอียดที่เดียว
- ⚠ ใช้กับ **ชื่อมุ้งทุกตัวที่มี "ผ้ามุ้ง" ในชื่อ + มี _mSpec ผ้า** (imp21/22/23 screen_addon) · ตัวที่ผ้าอยู่ในชื่ออยู่แล้ว (mj_*) ไม่มี _mSpec ผ้า → ไม่กระทบ
- **"หัวซ้ำ" (ชื่อโผล่หัว+รายการ) = ไม่ใช่บั๊ก ไม่ต้องแก้** (รูปแบบ 5 บล็อกทุกกลุ่มเป็นแบบนี้)
