HANDOFF G3 — FIX-13: คิดราคา "รางน้ำหลัก" (1,000/ม. × ความกว้าง)

เรื่องราคา (แตะสูตร calc) · ไฟล์ public/calculator/index.html · 11 มิ.ย. 2026 · มติพี่นัท: เรตหลังคาฐาน = ค่าหลังคาเปล่า ไม่รวมรางน้ำ
⚠ FIX นี้แตะสูตรราคา (ต่างจาก FIX-1..12 ที่เป็น wording) — ทำให้หลังคาที่เลือก "ปลายหลังคา=รางน้ำ" ราคาเพิ่มขึ้น w×1,000 · ต้องอัปเดต baseline ของ test/quote-fidelity.mjs ด้วย (ราคาหลังคาในเทสจะเปลี่ยน — เป็นการเปลี่ยนที่ตั้งใจ)

1. ทำไมต้องแก้ (หลักฐาน)

มติพี่นัท 11 มิ.ย.: เรตหลังคาฐาน (เช่น ไวนิล 6,500/ตร.ม.) = ค่าหลังคาเปล่า ยังไม่รวมรางน้ำ → รางน้ำต้องคิดเพิ่ม
สเปกต้นทุน (รายการสูตรราคาประเมิน_ฉบับเต็ม.md · หมวด D หลังคา ข้อ 33):
"ของเสริมหลังคา: รางน้ำ 1,000/ม. / เสาแผง 4,000/ต้น / เสา 4″x8″ 2,000/ต้น / ซ่อนสโลป… / โซ่รางน้ำ 3,000/เส้น" → รางน้ำอยู่กลุ่ม "ของเสริม" = คิดเพิ่ม เหมือนเสาแผง
ใบจริง (5 ใบ):
หลังคาขายเหมา "1 ชุด" รางน้ำไม่แตกบรรทัด แต่ "มีรางน้ำแพงกว่าปล่อยปลาย" (คุณนก: โพลีตันมีรางน้ำ+โซ่ 43,000 vs ปล่อยปลาย 30,000)
บั๊กปัจจุบัน (verify ด้วย render):
ไวนิล 4×3 ปลายปล่อย = 72,000 · ปลายรางน้ำ = 72,000 (เท่ากัน — รางน้ำหลักฟรี ผิด) · เซลล์เลือกรางน้ำคิดว่าคิดเงินแล้ว แต่จริง ๆ ฟรี → เสี่ยงขายขาดทุน

2. จุดแก้ — calc engine

ตำแหน่ง: ในบล็อก if(p.cat==='หลังคา'&&optSel){ … } หลังบรรทัด const _rfend = optSel.rfend || 'ปล่อย'; (ปัจจุบัน ~L1450)
โค้ดปัจจุบัน (L1450–1454) — รางน้ำหลัก "cosmetic ไม่คิดเงิน":
const _rfend = optSel.rfend || 'ปล่อย';
// ข้อ8: ลบ calc "ปิดปลาย" …
// โครงเหล็กชุบซิงค์ — ราคาเท่าโครงอลู …
// แปคู่ — ไม่คิดเพิ่ม
// รางน้ำใหม่ (chain D) — cosmetic ไม่คิดเงิน  ← จุดนี้คือบั๊ก
เพิ่มโค้ด (หลัง const _rfend …):
// FIX-13: ปลายหลังคา=รางน้ำ → คิดรางน้ำหลัก 1,000/ม. × ความกว้าง
//   (สเปก ของเสริมหลังคา ข้อ 33 · มติพี่นัท: เรตฐาน=หลังคาเปล่า)
if(_rfend==='รางน้ำ'){
  const _glen = parseFloat(w)||0;        // ความยาวราง = ความกว้างหลังคา (ชายคาล่าง 1 เส้น)
  if(_glen>0){
    opt += _glen*1000;
    msgs.push('รางน้ำหลัก '+_glen+'ม.×1,000 = '+fmt(_glen*1000));
  }
}
ตรวจ double-count: นี่คือ "รางน้ำหลัก" (จากปลายหลังคา=รางน้ำ) · ช่อง "ของเสริม→รางน้ำ" (o-rfgut) เป็นรางน้ำเพิ่มพิเศษ แยกกัน ไม่ซ้ำ · genQuote ลงใบ "รางน้ำ (ท่อ/โซ่ สี) + ตะแกรง…" อยู่แล้ว — ไม่ต้องแก้ genQuote แค่ราคาเพิ่ม

3. จุดที่ต้องพี่นัท/แชทยืนยัน (1 จุด)

ความยาวราง = ความกว้างหลังคา (w) อัตโนมัติ — ใช้กรณีรางน้ำชายคาล่าง 1 เส้น (เคสปกติ)
ถ้างานมี รางน้ำ 2 ด้าน หรือยาวต่างจากกว้าง → เซลล์ใช้ช่อง "ของเสริม → รางน้ำ" กรอกยาวเพิ่มเอง (มีอยู่แล้ว)
ทางเลือก (ถ้าอยากยืดหยุ่น): เพิ่มช่อง "ความยาวราง (ม.)" ใต้ปลายหลังคา=รางน้ำ (default=กว้าง แก้ได้) → แทน parseFloat(w) ด้วยค่าจากช่อง · แนะนำเริ่มแบบ auto (w) ก่อน — ง่าย+เร็ว

4. ผลกระทบราคา (ตัวอย่าง)

เคสเดิมราคารางน้ำ (+w×1,000)ใหม่
ไวนิล 4×3 (กว้าง 4) ปลายรางน้ำ72,000+4,00076,000
ไวนิล 6×3.5 (กว้าง 6) ปลายรางน้ำ~122,000 (ฐาน 115,500)+6,000~122,000
ไวนิล ปลายปล่อย (ไม่มีราง)72,000+072,000 (เท่าเดิม)
หลังแก้: "มีรางน้ำ > ปล่อยปลาย" → ตรงใบจริงแล้ว
