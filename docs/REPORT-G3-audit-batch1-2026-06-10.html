BASE (ปลายปล่อย): ราคา 72,000 - หลังคาไวนิล สีขาว - โครงอลูมิเนียม สีอบขาว (แปคู่) + ของเสริม (เสาแผง2 / คานถัก4ม. / รางน้ำเสริม4ม. / ซ่อนสโลป / โซ่2เส้น): ราคา 120,000 (+48,000) - หลังคาไวนิล สีขาว ← เหมือน BASE เป๊ะ - โครงอลูมิเนียม สีอบขาว (แปคู่) ← ไม่มีบรรทัดของเสริมแม้แต่ชิ้นเดียว ❌
V4 โครงเหล็กชุบ + แปเดี่ยว: - หลังคาไวนิล สีขาว - โครงเหล็กชุบซิงค์ ← "แปเดี่ยว" หายไป (ควรมี) + ราคาเท่าอลู

จุดที่ต้องแก้ — จัดลำดับ + เลขบรรทัด (ส่งแชทแก้โค้ด)

P1 1. ของเสริมหลังคา 10 รายการ คิดเงินแต่ไม่ลงใบ

ราคาเด้งเข้ายอดรวม แต่ "รายละเอียดงาน" ไม่เขียน → เซลล์ตอบลูกค้าไม่ได้ + อ่านใบย้อนหลังไม่รู้ได้อะไร
  • รายการที่กระทบ: เสาแผง · เสา 4"x8" · คานเหล็กถัก · รางน้ำเสริม (อลู/สแตน) · โซ่รางน้ำ · ปิดปลายกันน้ำ · ครอบท่อ PVC · ซ่อนสโลป · ปิดซ่อนราง · ครอบคาน
  • แก้: ใน genQuote หลังคา L3317–3327 เพิ่มการ build บรรทัดของเสริมจาก optSel (rfgut/rfbeam/rfpolep/rfpole4/rfchain/rfeave/rfpvc/rfhs/rfgc/rfbc) — ค่าราคา/เงื่อนไขมีอยู่แล้วใน calc L1402 ใช้ logic เดียวกัน
  • ระวัง: เพลทเหล็กล่าง + เหล็กดึง (ฟรี) ลงใบอยู่แล้ว — ของที่คิดเงินกลับไม่ลง (inversion) อย่าลบของฟรีออก

P1 2. ซ่อนสโลป — เน้นเป็นพิเศษ (เงินก้อนใหญ่)

เป็น subset ของข้อ 1 แต่เงินเยอะสุด (คอมโพสิต 3,500/ตร.ม. · สมาร์ท 4,000/ตร.ม.) — ควรมีบรรทัด "ซ่อนสโลปคอมโพสิต 3มม." + พื้นที่ ลงใบชัด
  • calc สูตร: comp = (2×สูง+0.1)×ด้าน×ยาว×3,500 · smart = สูง×ด้าน×ยาว×4,000 (L1402)

P1 3. แปเดี่ยว ไม่ลงใบ

  • แก้ L3293: ให้เขียน " (แปเดี่ยว)" ด้วย ไม่ใช่เฉพาะแปคู่ → เช่น _battenSuffix = ' ('+_rfbatten+')'

P2 4. เมทัลชีท / ชินโคไลท์ ทำหลังคาเลื่อนไม่ได้ (เช็คซ้ำ)

  • ถ้าต้องการให้ทำเลื่อนได้ → เพิ่ม optSlide:true ใน imp7–imp20 (L661–674) · ถ้าไม่ทำเลื่อน (วัสดุหนัก) = ปล่อยไว้ แต่ยืนยันกับพี่นัท

P2 5. หลังคากระจกลามิเนต — ไม่มีฟิล์ม/ความหนา

  • เพิ่ม option ความหนา (4+4 / 5+5) + ฟิล์ม (ใส/เขียว/กันร้อน) ให้ roof_laminate · ลงใบในหัวรายละเอียด

P2 6–7. ชินโคไลท์ / เมทัลชีท — ไม่มีสี (เช็คซ้ำใบจริง)

  • เพิ่ม o-roofcolor สำหรับ imp7–20 (เลียนแบบ L2338–2343) — รอพี่นัทให้ลิสต์สีที่ขาย

P2 8. โครงเหล็กชุบซิงค์ — ราคาเท่าโครงอลู

  • ใส่ราคาเหล็กชุบจริง (calc L1406) — รอราคาซัพพลายเออร์

P2 9. ปลายหลังคา "ปล่อย" เงียบเกินไป

  • พิจารณาเพิ่มบรรทัด "ปล่อยชายคา (ไม่มีรางน้ำ)" เมื่อ rfend=ปล่อย (L3294)

P2 10. ท่อน้ำทิ้ง PVC 2.5″ — ไม่มีจำนวนจุด

  • เพิ่มช่องจำนวนจุด (option L2363) + ลงใบ "…N จุด" (L3310)

ดี ที่ทำถูกแล้ว (อย่าแก้)

  • ระบบรางน้ำ ท่อ/โซ่ + ลาย + สี + ตะแกรงกันใบไม้ → ลงใบครบถูก
  • สีวัสดุมุง ไวนิล/ดีไลท์/โพลีตัน (รหัส + % แสงผ่าน) → ครบ
  • หลังคาเลื่อน (ตระกูล optSlide) → ออกบาน+มอเตอร์ลงใบ + คิดเงินถูก
  • โครงอลู + แปคู่ → ลงใบถูก
