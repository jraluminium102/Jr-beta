สเปกแก้ออปชั่น — หมวดหลังคา / ฝ้า-ผนัง (กลุ่มงาน 3)

สำหรับแชทแก้ HTML · ไฟล์: public/calculator/index.html · เลขบรรทัดอิงผลสำรวจ buildItemOpts (~2124-2381) · สร้าง 2026-06-08 จากแชทตรวจออปชั่น (READ-ONLY)

หลักการ: ออปชั่นต้อง "ตรงลักษณะสินค้า" — หลังคา/ฝ้า/ผนัง ไม่ใช่บาน จึงต้องไม่มี คาดตาราง · จำนวนบาน · มือจับ · ฝังรางยู ยกเว้นกรณีเดียว = "หลังคาเลื่อน" (ติ๊ก "ทำเลื่อน")

1. ต้องตัดออก (ออปชั่นผิด — โผล่ทั้งที่ไม่ควร)

ออปชั่นclassบรรทัดปัญหาแก้เป็น
คาดตาราง (มีคาดตาราง).o-gridmark + .o-gm-*2217-2225gate if(!p.grid) → โผล่ทุกหลังคา + ทุกฝ้า/ผนัง (คาดตารางไม่มีในงานหลังคา/ฝ้า)เพิ่มเงื่อนไขตัด หลังคา + ฝ้า-ผนัง (เช่น เช็ค AREA_CATS) → ให้เหลือเฉพาะ "หลังคาเลื่อน" (ดูข้อ 3)
ฝังรางยู.o-uchannel2324 (ไม่ gate)เพิ่มให้ทุก product → เป็นงานพื้นของบาน ไม่เกี่ยวหลังคา/ฝ้าตัดออกสำหรับ หลังคา + ฝ้า-ผนัง
งานเสริม / รื้อของเดิม.o-extrawork · .o-removeold2325-2326 (ไม่ gate)โผล่ทุก product (ข้อความเฉยๆ ไม่คิดเงิน)เก็บได้ แต่ควรจัดเข้ากลุ่ม "หมายเหตุ/งานเสริม" ให้ชัด (ไม่ใช่ออปชั่นหลัก)
ทำเลื่อน + จำนวนบานเลื่อน.o-slide · .o-spanels · .o-sgut2229 (if(p.optSlide))optSlide:true อยู่บนหลังคาทุกตัว (ไวนิล/ดีไลท์/โพลีตัน/ลามิเนต) → "จำนวนบานเลื่อน" โผล่ตลอดแม้ขายหลังคาติดตายดูข้อ 3 — ให้ จำนวนบาน/มือจับ/คาดตาราง โผล่เฉพาะเมื่อติ๊ก "ทำเลื่อน"

2. ออปชั่นที่ถูกต้องของ "หลังคา (ติดตาย/ทั่วไป)"

บล็อก if(p.cat==='หลังคา') บรรทัด 2230-2267 — ของพวกนี้ ถูกแล้ว เก็บไว้:

  • ชนิดหลังคา (เลือกจาก product): ไวนิล / ดีไลท์ / โพลีตัน / กระจกลามิเนต / เมทัลชีท / ชินโคไลท์
  • สีวัสดุมุง .o-roofcolor (เฉพาะ ไวนิล/ดีไลท์/โพลีตัน · เมทัล/ชินโคไม่มี)
  • กว้าง × สูง (พื้นที่)
  • แป .o-roofbatten — default = แปคู่ (ดู F5 ใน handoff หลัก)
  • โครงสร้าง .o-roofframe — อลู (default) / เหล็กชุบ
  • ปลายหลังคา .o-roofend — ปล่อย (default, ไม่มีรางน้ำ) / รางน้ำ / ปิดปลาย
    ↳ ถ้ารางน้ำ → ระบบรางน้ำ .o-guttersys: ท่อ (สี ขาว/ดำ) / โซ่ (ลายทิวลิป default + สี)
  • ของเสริมหลังคา: รางน้ำ อลู/สแตน + ยาว · คานเหล็กถัก · เสาแผง/เสา 4"x8" · โซ่รางน้ำ (3,000/เส้น) · ปิดปลายกันน้ำ · ครอบท่อ PVC · ปิดซ่อนราง · ครอบคาน
  • เสริมเพลทเหล็กล่าง .o-rfplate + เหล็กดึงด้านบน .o-rfpull (ฟรี ติ๊ก)
  • ซ่อนสโลป .o-rfhs — คอมโพสิต 3มม. (3,500/ตร.ม.) / สมาร์ทบอร์ด 6มม. (4,000/ตร.ม.) + สูง/ยาว/ด้าน
เทียบใบจริง ✓ ออปชั่นชุดนี้ตรงกับที่พบในใบจริง (ธนบัตร/นก/หญิง/ใบเฟริล/สุจินต์): แป · ปลายหลังคาปล่อย/ราง · ท่อ PVC สี · โซ่ลายทิวลิป · เสริมเพลท/เหล็กดึง · ซ่อนสโลปคอมโพสิต · เสาแผง

3. "หลังคาเลื่อน" — จำนวนบาน/มือจับ/คาดตาราง โผล่เฉพาะตรงนี้

ปัจจุบัน "ทำเลื่อน" .o-slide (บรรทัด 2229) แสดงตลอดเพราะหลังคาทุกตัว optSlide:true และ "จำนวนบานเลื่อน" .o-spanels ก็โผล่ตามไปด้วย

แก้เป็น chain: ฟิลด์ 3 ตัวนี้ ซ่อนไว้ก่อน · โผล่ก็ต่อเมื่อติ๊ก "ทำเลื่อน" (.o-slide) เท่านั้น:
  • จำนวนบานเลื่อน .o-spanels (default 2)
  • มือจับ (สำหรับบานเลื่อนของหลังคา) — เพิ่มใหม่ ผูกใต้ "ทำเลื่อน"
  • คาดตาราง .o-gridmark — ย้ายมาให้โผล่เฉพาะหลังคาเลื่อน (หลังคากระจกที่ซอยช่อง)
  • รางน้ำบานเลื่อน .o-sgut (มีอยู่แล้ว)

กล่าวคือ: ไม่ติ๊กทำเลื่อน = หลังคาติดตาย → ไม่มีจำนวนบาน/มือจับ/คาดตาราง · ติ๊กทำเลื่อน → โผล่ทั้ง 3

4. "ฝ้า / ผนัง" — ออปชั่นน้อยสุด

สินค้า cat ฝ้า-ผนัง: ceil_cshape · ceil_bsc · ceiling_smooth (ฝ้าฉาบเรียบ) · isowall · wall_ext · wall_int

เก็บไว้ (ถูก)ตัดออก (ผิด)
  • ชนิด (เลือกจาก product)
  • สี/ลาย .o-ckolor (เฉพาะ ceil_cshape/ceil_bsc)
  • กว้าง × สูง
  • ฉนวนกันความร้อน .o-insul (เฉพาะ ฝ้าฉาบเรียบ)
  • คาดตาราง .o-gridmark
  • ฝังรางยู .o-uchannel
  • ทุกอย่างของหลังคา/บาน (สี/กระจก/มือจับ/มุ้ง — ตอนนี้ซ่อนถูกแล้ว)

5. สิ่งที่ "ถูกอยู่แล้ว" — ไม่ต้องแก้

(จาก subagent ตรวจ gate แล้ว — ยืนยันว่าหมวด 3 ไม่ leak)

  • จำนวนบาน .i-panels-wrap — ซ่อนถูกแล้ว (usesPanels()=false สำหรับหลังคา/ฝ้า · บรรทัด 2334-2335)
  • สีอลู / กระจก (.i-color/.i-glass) — ซ่อนถูกแล้วด้วย areaOnly (บรรทัด 2345-2346)
  • มือจับ / Cmech / มุ้ง / มอเตอร์ / ครอบวงกบ / แผ่นทึบล่าง / ธรณี — gate ตาม cat/flag แล้ว ไม่โผล่ในหมวด 3
  • COMMON_OPTS (soft close ฯลฯ) — ไม่มี id หมวด 3 ในลิสต์ ไม่ leak

6. สรุปงานที่ต้องแก้ (เช็คลิสต์แชท B)

  1. คาดตาราง .o-gridmark (2217): ตัดออกจาก หลังคา(ติดตาย) + ฝ้า-ผนัง → ย้ายไปโผล่เฉพาะ "หลังคาเลื่อน"
  2. ฝังรางยู .o-uchannel (2324): ตัดออกจาก หลังคา + ฝ้า-ผนัง
  3. ทำเลื่อน chain (2229): ซ่อน .o-spanels + (มือจับใหม่) + .o-gridmark จนกว่าจะติ๊ก .o-slide
  4. เพิ่ม dropdown "มือจับ" ใต้ "ทำเลื่อน" (เฉพาะหลังคาเลื่อน)
  5. extrawork/removeold (2325-2326): จัดเข้ากลุ่ม "หมายเหตุ/งานเสริม" (optional)
  6. ทดสอบ: render หลังคาไวนิลธรรมดา → ต้องไม่เห็น คาดตาราง/จำนวนบาน/มือจับ/ฝังรางยู · ติ๊กทำเลื่อน → เห็นครบ 3
