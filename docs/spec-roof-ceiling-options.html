2. หลังคา (ติดตาย/ทั่วไป) — ออปชั่นที่ถูก เก็บไว้

บล็อก if(p.cat==='หลังคา') บรรทัด 2230-2267 — ถูกแล้ว:

  • ชนิดหลังคา (product) · สีวัสดุมุง .o-roofcolor · กว้าง×สูง
  • แป .o-roofbatten (default แปคู่) · โครงสร้าง .o-roofframe (อลู/เหล็กชุบ)
  • ปลายหลังคา .o-roofend = ปล่อย (default ไม่มีราง) / รางน้ำ / ปิดปลาย → ถ้ารางน้ำ: ท่อ(สี) / โซ่(ทิวลิป+สี)
  • ของเสริม: รางน้ำอลู/สแตน · คานเหล็กถัก · เสาแผง/เสา · โซ่ 3,000/เส้น · ปิดปลายกันน้ำ · ครอบท่อ PVC · ปิดซ่อนราง · ครอบคาน
  • เสริมเพลทเหล็กล่าง .o-rfplate + เหล็กดึงด้านบน .o-rfpull (ฟรี)
  • ซ่อนสโลป .o-rfhs คอม 3,500 / สมาร์ท 4,000 ต่อตร.ม.

3. หลังคาเลื่อน — ปรับของเดิม (มีโครงอยู่แล้ว ไม่สร้างใหม่)

มีอยู่แล้ว: optSlide:true บน 4 หลังคา (vinyl/delight/polyton/laminate) · UI บรรทัด 2238 (.o-slide ทำเลื่อน + .o-spanels จำนวนบาน + .o-sgut รางน้ำ) · ราคาบรรทัด 1400 (ROOF_SLIDE + tier + มอเตอร์อัตโนมัติซ่อน 1 ตัว)

เป้าหมาย (พี่นัท): หลังคาเลื่อน = ออปชั่นจากหลังคาปกติ มีแค่ 3 ช่อง — โผล่เมื่อติ๊ก "ทำเลื่อน" (.o-slide):

ช่องสถานะเดิมต้องแก้
① จำนวนบานมี .o-spanels (2238)เก็บไว้
② พื้นที่หลังคาเลื่อน (ตร.ม.)ไม่มีช่องแยก — ใช้พื้นที่หลังคารวมเพิ่มช่องกรอกพื้นที่เลื่อน (หรือยืนยันว่าใช้พื้นที่รวมพอ)
③ มอเตอร์ แบบ + จำนวนตัวคิดอัตโนมัติซ่อน (auto-bucket ตามพื้นที่ · fix 1 ตัว · เลือกไม่ได้)เพิ่ม dropdown เลือกแบบมอเตอร์ + ช่องจำนวนตัว → ราคา = แบบ × จำนวน

ตัด/ปรับ: เอา auto-motor ที่ซ่อน (บรรทัด 1400) ออก ให้ใช้ค่าที่ผู้ใช้เลือกแทน · .o-sgut รางน้ำ ไม่อยู่ในสเปก 3 ช่อง (ย้ายไปของเสริม หรือตัด) · ไม่มี มือจับ/คาดตาราง

❓ ต้องการจากพี่นัท: รายการ "แบบมอเตอร์" + ราคาต่อตัว (ตอนนี้ระบบ auto เป็น 18,000/28,000/36,000/72,000 ตามพื้นที่ — จะใช้เป็นตัวเลือกหรือมีชื่อรุ่น/ราคาอื่น?) · และยืนยันราคา = ราคาต่อตัว × จำนวนตัว

4. ฝ้า / ผนัง — จัด UX ใหม่ทั้งหมด (ระบบออกแต่ชื่อ ไม่มีรายละเอียด)

Root cause: ตัวสร้าง "รายละเอียดงาน" (matLines/detail builder บรรทัด 3161-3216) รองรับแค่ อลูมิเนียม / กระจก / มุ้ง — ไม่มี branch สำหรับ ฝ้า-ผนัง → render ออกแต่หัวข้อ+ขนาด วัสดุหายหมด

เทียบใบจริง (ยี/สุจินต์) — ระบบ ไม่ตรงเลยสักบรรทัด:

ใบจริงเขียนระบบออกขาด
"ผนังสมาร์ทบอร์ดพร้อมฉนวนกันร้อนกันเสียง โครงเหล็กชุบซิงค์(ไร้สนิม)" + "แผ่นสมาร์ทบอร์ด หนา 12 มม. พร้อมทาสีรองพื้นสีขาว" + "ฉนวนฯ หนา 3""""ผนังเบาภายใน (ขนาด)" — ไม่มีรายละเอียดหนาบอร์ด · ทาสีรองพื้น · ฉนวน 3" · โครงเหล็กชุบซิงค์
"แผ่น ISOWALL หนา 10 ซม. (รอสรุปสี)""ISOWALL (ขนาด)"ความหนา ซม. · สี
"ฝ้าฉาบเรียบพร้อมทาสีขาว (ฝ้าเฉียงตามแนวหลังคา)""ฝ้าฉาบเรียบ (ขนาด)"ทาสีขาว · ตำแหน่ง/เฉียง · ฉนวน

ต้องเพิ่ม (จัด UX ใหม่ฝ้า/ผนัง):

  1. เขียน matLines branch ใหม่สำหรับ cat 'ฝ้า-ผนัง' (จุดหลัก บรรทัด 3161-3216) ให้พิมพ์รายละเอียดวัสดุได้
  2. ความหนาสมาร์ทบอร์ด dropdown 12 มม. / 20 มม. → "แผ่นสมาร์ทบอร์ด หนา X มม."
  3. ทาสี เลือก "ทาสีขาว" / "ทาสีรองพื้นสีขาว"
  4. ฉนวนกันร้อน/กันเสียง — มี checkbox .o-insul + ราคา (600/ตร.ม.) แล้ว แต่ต้อง เพิ่มบรรทัดข้อความ "ฉนวนกันความร้อนและกันเสียง หนา 3" + เปิด optInsul ให้ isowall/wall_ext/wall_int ด้วย (ตอนนี้มีแค่ ceiling_smooth)
  5. โครงเหล็กชุบซิงค์ (ไร้สนิม) toggle โครงอลู/เหล็กชุบ (ราคาเท่ากัน · มี comment เตรียมที่ 1405)
  6. ISOWALL ความหนา (ซม.) + สี → "แผ่น ISOWALL หนา X ซม."
  7. ฝ้าฉาบเรียบ เพิ่มบรรทัดทาสีขาว + option ตำแหน่ง "ฝ้าเฉียงตามแนวหลังคา"
  8. (พิจารณา) เพิ่ม product งานพื้น (สมาร์ทบอร์ด 20มม. / ไม้เทียม โครงเหล็ก) — ใบจริงมี ระบบยังไม่มี

ฝ้า/ผนัง ตัดออก: คาดตาราง · ฝังรางยู · ของหลังคา/บานทั้งหมด (สี/กระจก/มือจับ ซ่อนถูกแล้วด้วย areaOnly)

5. ถูกอยู่แล้ว — ไม่ต้องแก้

  • จำนวนบาน .i-panels-wrap ซ่อนถูก (usesPanels=false หมวด 3) · สี/กระจก ซ่อนถูก (areaOnly)
  • มือจับ/Cmech/มุ้ง/มอเตอร์(บานยก)/ครอบวงกบ/แผ่นทึบล่าง/ธรณี — ไม่ leak เข้าหมวด 3

6. เช็คลิสต์แชท B

  1. ตัด คาดตาราง .o-gridmark (2217) ออกจากหลังคา+ฝ้า (ทุกกรณี)
  2. ตัด ฝังรางยู .o-uchannel (2324) ออกจากหลังคา+ฝ้า
  3. หลังคาเลื่อน (2238/1400): เพิ่ม dropdown แบบมอเตอร์ + จำนวนตัว · เอา auto-motor ซ่อนออก · จัดให้เหลือ 3 ช่อง (จำนวนบาน/พื้นที่เลื่อน/มอเตอร์)
  4. ฝ้า/ผนัง: เขียน matLines branch ใหม่ (3161-3216) + 7 ฟิลด์ตามข้อ 4
  5. ทดสอบ: หลังคาไวนิลธรรมดา → ไม่มีคาดตาราง/จำนวนบาน/ฝังรางยู · ติ๊กทำเลื่อน → เห็นจำนวนบาน+พื้นที่+มอเตอร์ · ฝ้า/ผนัง render → มีรายละเอียดวัสดุครบ (สมาร์ทบอร์ดหนา/ฉนวน/โครง/ทาสี)
