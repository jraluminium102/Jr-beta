# เป้า: ดันราคา R3.9 → R4.0 + ผูกวัสดุในสโตร์ ให้มีราคาครบ

หมวดในเป้า: **หลังคา/กันสาด · กลาสเฮ้าส์ · บานโซลิด · ระแนง** (28 ส.ค. 2569)

## สถานะรายรุ่น (16 รุ่นในขอบเขต)

| รุ่น | อลูไม่มีรหัส | อุปกรณ์ไม่ผูก | ยังเป็น R3.9 |
|---|---|---|---|
| บานโซลิด | 0 | 0 | — |
| หลังคา · หลังคาจั่ว · หลังคาเลื่อน | 0 | 0 | — |
| กันสาดหลายด้าน · กลาสเฮ้าส์หลายด้าน | 0 | 0 | — |
| ห้องกระจก (ประกอบ) | 0 | 0 | — |
| ระแนงบังตา · ระแนงสลับ · ระแนงเลื่อน | 0 | 0 | — |
| ฝ้าระแนงอลู ×3 | 0 | 0 | ✅ พอร์ตแล้ว |
| ระแนงปรับหมุนได้ | 0 | **1** | — |
| ระแนงบานเกล็ดอลู (38.1) · ระแนงหมุนเปิด-ปิด (38.3) | — | — | **ยังเป็น R3.9** |

## ทำอะไรไปบ้าง

**① ฝ้าระแนงอลู 3 รุ่น: R3.9 → R4.0**
เดิมไม่มีสูตรทุนเลย กรอกราคาขาย/ตร.ม. ล้วน (3,300 / 3,700 / 4,800)
ถอดทุนตามโมเดลใบตัด `JR_บานระแนง_v2` (กล่อง → ด้านโชว์ → ช่องห่าง) ตรึงค่าตามชื่อรุ่น
กำไร วัสดุ×2 · ผลิต×1.5 · ติดตั้ง×2 (ท้ายชีต "คิดทุน ระแนงหมุน" ไฟล์ v9)

> **ตัวยืนยันว่าถอดทุนถูก**: 1.6" เว้น 5 ที่ 12 ตร.ม. ออก **3,708/ตร.ม.** เทียบราคาเดิม R3.9 **3,700** — ตรงกันแทบเป๊ะ

ราคาใหม่ (เจ้าของเคาะใช้ R4.0 แล้ว)

| รุ่น | R3.9 | R4.0 @12 ตร.ม. | R4.0 @24 ตร.ม. |
|---|---|---|---|
| 1×5 ซม. | 3,300 | 4,325 | 5,350 |
| 1.6" เว้น 5 | 3,700 | 3,708 | 4,479 |
| 1.6" เว้น 2 | 4,800 | 5,092 | 6,392 |

ที่ราคาโตตามขนาด เพราะ R4.0 นับเศษเส้นจริง — ใบยาวเกิน 3 ม. ตัดได้ท่อนเดียวต่อเส้น 6 ม. (เศษ 33%) ส่วน R3.9 คิดแบนต่อ ตร.ม. ไม่คิดเศษ

**② ระแนงทุกตัวดึงราคากล่องจากสโตร์ได้แล้ว**
เดิมราคากล่องฝังในสูตร แก้ราคาในสโตร์แล้วไม่ขยับ — เพราะช่อง `box` รับได้แต่ข้อความล้วน แต่ระแนงเลือกกล่องได้ 7 ขนาด
แก้ให้ `box` รับสูตรได้ (หลักเดียวกับ `sku`) → ผูก ระแนงบังตา (ใบระแนง + โครงดาม) · ระแนงสลับ (กล่อง A + B)
พิสูจน์: ตั้งราคากล่อง 1.6×4 ในสโตร์ 1,220 → 2,000 แล้วทุนระแนงขยับ 10,980 → 18,000

**③ ⚠ บั๊กเงิน — ชินโคร์ Shade/Prime คิดทุนแผ่นมุงเป็น 0 มาตลอด**
หลังคา 4 บรรทัดชินโคร์ตรึง `price: 0` ทั้งชุด ("รอราคาทุน") แต่ไฟล์ v9 มีราคาอยู่แล้ว
Shade 4มม = 1,050/ตร.ม. · Prime 10มม = 4,348/ตร.ม.

| หลังคา 400×300 (12 ตร.ม.) | ทุนแผ่นมุงเดิม | หลังแก้ |
|---|---|---|
| ชินโคร์ Shade 4มม | 0 | **13,041** |
| ชินโคร์ Prime 10มม | 0 | **54,002** |

ผูก ROOFMAT ทั้ง 4 รุ่นแล้ว → แก้ราคาที่ตารางราคากลางเด้งทันที

**④ ของที่ราคาออกมา 0 ต้องเตือน**
เดิมเตือนเฉพาะบรรทัดที่มีรหัสสโตร์ → บรรทัดที่ผูกตารางราคากลางหลุดหมด คิดเป็นศูนย์เงียบ ๆ
ตอนนี้เลือกชินโคร์ Nature/Grand แล้วขึ้นเตือนทันทีว่ายังไม่มีราคาทุน

**⑤ รางหลังคาเลื่อน** 4,080/เส้น ฝังในสูตร → ผูก ROOFMAT แล้ว

## เช็ค "มีราคาทุกอันในสโตร์"

- รหัสที่ 4 หมวดนี้ใช้ **32 รหัส → มีในสโตร์ครบ 32** · ราคา 0 เหลือตัวเดียว (JR00504 ซิลิโคน Dowsil สีขาว)
- กล่อง/ฉาก **8 ขนาด → มีราคาครบทุกขนาด**
  (ยกเว้น กล่อง 1×5 ซม. มีแค่ 3 สี: อบขาว/มิว/ดำ — เลือกสีอื่นจะตกไปใช้ราคาฐาน)

## ยังค้าง

1. **ชินโคร์ Nature 6มม / Grand 10มม** — ไม่มีราคาในไฟล์ถอดทุนเลย (ค้นทั้งไฟล์แล้ว) → เจ้าของกรอกที่ตารางราคากลาง ROOFMAT
2. **ระแนงบานเกล็ดอลู (38.1) · ระแนงหมุนเปิด-ปิด (38.3)** — ยังเป็น R3.9 ไม่มีชีตถอดทุน (เจ้าของสั่งข้ามไปก่อน)
3. **ระแนงปรับหมุนได้ · "อุปกรณ์หมุน+จุดหมุน"** — เป็นราคาเหมา (200/ม. + 160/ใบ) ไม่มีของในสโตร์
4. **JR00504 ซิลิโคน Dowsil สีขาว** ราคา 0 ในสโตร์
