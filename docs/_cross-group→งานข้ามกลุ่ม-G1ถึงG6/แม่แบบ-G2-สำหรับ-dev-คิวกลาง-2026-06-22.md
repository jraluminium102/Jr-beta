## 2) กับดัก/ปัญหาที่เจอ — กันพังซ้ำ (สำคัญที่สุด)

- **engine ราคา + UI ร่วม 7 กลุ่ม/2 โหมด** → แก้ที่เดียวลามทุกกลุ่ม (ดู memory `why-work-breaks-shared-arch`)
- **`node scripts/golden-snapshot.mjs` ทุกครั้งก่อน-หลังแก้** (150 ตัว · ราคาเพี้ยน=ธงแดง) — ทุก commit G2 ผ่าน
- **2 โหมด:** เต็ม `.o-*/.i-*` (calcUnit) · คิดเร็ว `.qi-*` (qiG2 แยก) — แก้ฟีเจอร์ต้องดูทั้ง 2
- **jsdom เชื่อ visibility ไม่ได้** — เทส UX ต้องเปิด preview จริง (memory `verify-real-browser`)
- **แตกราคา reconcile:** บานผสม `subItems` ต้องแยกเป็นบรรทัด ไม่งั้นราคาบานย่อยไปกองบรรทัดใหญ่สุด (เคยทำมอเตอร์เป็น 88,720 — แก้แล้ว) · ส่วนต่างใหญ่→บรรทัด "งานเสริม/อื่นๆ" ไม่ปลอม
- **`mosquito:1` บน product = "เพิ่มมุ้งได้" ไม่ใช่ "เป็นมุ้ง"** — อย่าใช้เป็นตัวกรองตัดบาน
- **default flag-driven:** ออปชั่นใหม่ default = พฤติกรรมเดิม (เช่น railreuse=false=วางใหม่=เดิม) → golden เขียว
- **`setRowDet` มี non-breaking space** ในโค้ด — match string ระวัง

## 3) จุดที่พี่นัทต้องการพิเศษ (ต่อยอดให้ G1/อื่น)

1. **กล่องราคา sticky** — อยากได้ทุกกลุ่ม (ตอนนี้ G2)
2. **แตกราคาย่อย** — โครงทำรอแล้ว (ใบ render generic) · **G1 ต้องส่ง `r.breakdown`** จาก calcUnit: door cats โชว์ **ค่าบาน + กระจก + สี เสมอ** (default = "รวมในราคา") — G2 ทำ generic ไว้ที่ return ร่วมแล้ว ใช้ได้เลยถ้าไม่ override
3. **สี L1/L2/L3** — G1 บานผสม/เฟี้ยม ใช้ได้
4. **แก้ข้อความได้ทุกบรรทัด** (รวมหัวข้อ + ชุดจัดกลุ่ม) — ระบบ override พร้อม
5. **ใบไม่มีเลข "ชุดที่ N"** (มีเลข # หน้าแถวพอ)
