## จุดที่ไม่ตรง (เรียงลำดับ 🔴 ก่อน)

### 🔴 #1 — ขาด label "🎨 สีอลู (ทั้งห้อง) — L1 / L2 / L3"
- **ดราฟ**: มี `.flbl` ข้อความ `"🎨 สีอลู (ทั้งห้อง) — L1 / L2 / L3"` ก่อน L1 checkbox (ดราฟ L241)
- **เว็บ**: บรรทัด 8740 มีแค่ subtitle สีเทา `"ระดับห้อง · เกี่ยวกับบานกระจก ไม่ใช่งานเสริม"` แล้วข้ามไป L1 checkbox เลย
- **เสนอแก้**: เพิ่ม `<div style="font-size:12px;font-weight:700;color:#374151;margin:8px 0 4px;">🎨 สีอลู (ทั้งห้อง) — L1 / L2 / L3</div>` ก่อน label L1 checkbox (หลัง subtitle L8740)

### 🔴 #5 — กระจก select ซ่อนเมื่อ L1 ติ๊ก (ขัดดราฟ)
- **ดราฟ**: กระจก select + label `"🪟 กระจก (ทั้งห้อง) (66 รุ่น)"` อยู่ **นอก** `.l2l3` block → โชว์เสมอ ไม่ว่า L1 จะติ๊กหรือไม่ (ดราฟ L255-256)
- **เว็บ**: `g6GlassSelect('g6l2g',...)` อยู่ **ใน** `<div id="g6l2l3">` (L8762-8763) → ซ่อนเมื่อ L1 ติ๊ก (RC.on=0)
- **ผลกระทบ**: ผู้ใช้ที่เลือก "สีตามทั้งใบ" (L1 default) จะมองไม่เห็น glass select เลย ทั้งที่ดราฟกำหนดให้เลือกกระจกได้เสมอ
- **เสนอแก้**: ย้าย label+`g6GlassSelect` ออกมา render หลัง `</div> // /g6l2l3` (L8774) แทน

## หมายเหตุ

- ตรวจด้วยการอ่านโค้ดโดยตรง ไม่ได้ render jsdom (G6 room builder สร้าง HTML ใน JS ซับซ้อน)
- override ต่อด้าน: ดราฟแสดงตัวอย่างแค่ "ด้าน A / ด้าน B" (hardcode) แต่เว็บวนลูปตามด้านจริง — ถือว่าตรงเจตนา
- state `l3GlassIdx` มีใน init (L8404, L9008-9010) แต่ไม่มี UI รองรับ — ยังไม่ใช่ปัญหาเพราะดราฟก็ไม่มี
