## 🔧 ① หัวรายการ G6 + ตัดราคาย่อยในใบปกติ

**1a. หัวห้อง — ที่ L7200** (`if(it.room){ return {prodName:...} }`)
```
// ก่อน:
if(it.room){ return {prodName:'ห้องต่อเติม (กั้นห้องกระจก)', det:'', work:it.work||[], spec:it.spec||[]}; }

// หลัง (เติม "พร้อมหลังคา" เมื่อมีหลังคา):
if(it.room){ var _hasRoof=!!(it.roomHasRoof); return {prodName:'ห้องต่อเติม (กั้นห้องกระจก'+(_hasRoof?'พร้อมหลังคา':'')+')', det:'', work:it.work||[], spec:it.spec||[]}; }
```
> ⚠ ต้องเช็ค: readItem room ส่ง flag หลังคามาไหม (roomHasRoof) — ถ้ายังไม่มี เพิ่มตอน readItem (roofTotalReal()>0)

**1b. ตัด "(เหมา)" + ราคาย่อยรายด้าน ออกจากใบปกติ** (พี่เคาะ: ใบส่งลูกค้าไม่โชว์ราคาย่อย)
- หาที่ readItem สร้าง `it.work[]` ของห้อง (บรรทัด "ด้าน A (...) = 47,000") — ราว L8565/8607
- ใบปกติ: work line = **ชื่อด้านอย่างเดียว ไม่มี "= ราคา"** + เอา "(เหมา)" ออก

## 🔧 ④ วิธีคิดราคา 🔍 โชว์ไม่ครบ — เพิ่ม addonLines (ระวัง double-count)

**ที่ `qCalcStepLines()` L8134** — ตอนนี้โชว์ `u.breakdown` แต่ไม่โชว์ `u.addonLines`

```
// เพิ่มหลัง step 3b (subItems · ราว L8136) — ก่อน step 4:
// 3c) ออปชั่นที่คิดเงิน (addonLines) — โชว์เฉพาะที่ยังไม่อยู่ใน breakdown (กัน double-count)
if(u.addonLines && u.addonLines.length){
  u.addonLines.forEach(function(al){
    if(!(al.p>0)) return;
    if(u.breakdown && u.breakdown.some(function(b){ return Math.abs((b.p||0)-al.p)<1; })) return; // กันซ้ำกับ breakdown
    L.push(A(al.n||al.label||'ออปชั่น')+' = '+R(fmt(Math.round(al.p))));
  });
}
```
> ⚠ **ต้องเทส:** ออปชั่น (มุ้ง/มือจับ/ล็อก) อยู่ใน breakdown หรือ addonLines หรือ msgs — กันโชว์ซ้ำ/ตก · เปิดเว็บสด เลือกบานมีมุ้ง → กดวิธีคิดราคา → ผลรวมบรรทัด = sell เป๊ะ
