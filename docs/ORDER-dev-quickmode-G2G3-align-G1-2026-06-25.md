# ใบสั่ง dev — โหมดคิดเร็ว G2/G3 ทำให้เหมือน G1 (ต้นแบบ)

> วันที่ 25 มิ.ย. · สำหรับ **แชทแก้แชทเดียว** (git-deploy + calculator-dev) · คู่กับดราฟ `docs/DRAFT-quickmode-G2G3-vs-G1-เทียบ-2026-06-24.html`
> เป้าหมาย: ฟอร์มโหมดคิดเร็วทุกกลุ่ม **เรียงเหมือนกัน + มีช่องสี/กระจกครบเหมือน G1**

---

## ⛔ กฎเหล็ก (อ่านก่อน)
1. **แชทเดียวแก้ index.html** — ห้าม 2 แชทแก้พร้อมกัน (ชนไฟล์ งานหาย)
2. ทุกแก้ → `node scripts/golden-snapshot.mjs` ต้อง **150/150** ก่อน push
3. commit **ทีละกลุ่ม** (= จุดนิ่ง ย้อนได้) · push `git push origin HEAD:main`
4. เลขบรรทัดในไฟล์นี้อาจเลื่อน → **ยึดชื่อฟังก์ชัน** ไม่ใช่เลขบรรทัด

## ✅ ส่วนที่ 0 — ก่อนแก้ทุกข้อ เช็กว่า "ทำไปแล้วหรือยัง" (กันแก้ซ้ำ)

มีหลายแชทแตะ index มาก่อน → **อย่าเชื่อว่ายังไม่แก้** ทำ 3 ขั้นนี้ก่อนลงมือทุกข้อ:

```bash
# 1) ดึงล่าสุด + ดูว่าใครแก้อะไรไปแล้ว
git pull --rebase origin main
git log --oneline -20

# 2) รันเช็กรวม — ดูสถานะปัจจุบันก่อนแตะ
node scripts/golden-snapshot.mjs        # ต้อง 150/150 (ถ้าไม่ผ่าน หยุด แจ้งก่อน)
node scripts/dump-controls.mjs g2 rn2   # ดูโครงฟอร์ม G2 ระแนง ปัจจุบัน
node scripts/dump-controls.mjs g3 roof_vinyl
```

**กฎข้าม:** แต่ละข้อใน §3 มีคอลัมน์ "เช็กว่าแก้ยัง" — **รันก่อน** ถ้า**ผ่านแล้ว = มีคนแก้ไปแล้ว → ข้าม อย่าแก้ซ้ำ**

**ใบสั่งข้อ 11 (G1 คิดเร็ว เพิ่มมุ้ง):**

- **ไม่ต้องแตะสูตรราคา** — แค่ป้อนค่าที่ engine อ่านอยู่แล้ว · golden ต้องนิ่ง 150/150

- อ้างอิง UX: full mode `o-mosq` (L4750+) + [[mosq-ui-three-places]] (มุ้งมี 3 ที่ ใช้ engine เดียว)
