> เป้า: ลิสต์ยาว (สี/กระจก/มุ้ง/มือจับ) → **กดหัวข้อใหญ่ → ย่อยโผล่ไปเรื่อยๆ** · ไม่มีช่องพิมพ์ค้นหา · ไม่มีดรอปดาวน์ยาว
> ✅ ดราฟอนุมัติแล้ว (กดดูแพทเทิร์น): `public/DRAFT-redesign-ปุ่มออปชั่น-2026-06-17.html`
> 🔒 **ไม่แตะ value/ชื่อ class/ราคา/logic** — แค่เปลี่ยน "วิธีเลือก" + sync ค่ากลับ `<select>` เดิม (fire input+change) · ราคา/readItem เหมือนเดิมเป๊ะ
> 🧰 มีแพทเทิร์น cascade ในระบบอยู่แล้ว — ลอกได้: `rnSelectorHTML` (ระแนง G2) · `mosqSelectorHTML` (มุ้ง G5)
> ⚠ เสี่ยง — ทำ **ทีละ control** + golden ก่อน-หลัง + fidelity + verify browser ทุกตัว

## หลักการ drill-down (ใช้ซ้ำทุกตัว)
1. แถวหัวข้อใหญ่ (chip ระดับ 1) — กดแล้ว active + เผยขั้นย่อยที่ตรงกัน · ซ่อนขั้นย่อยอื่นอัตโนมัติ
2. ขั้นย่อย = chip single-select → set `.value` ของ select เดิม + fire change
3. สีโชว์จุดสีกลม (swatch) ตาม [[chip-color-swatch-style]]

## ⚠ แก้สำคัญ (พี่นัท 17มิ.ย. · จากภาพจริง): แยก "ทั้งใบ" vs "รายบาน"
สี/กระจก มี 2 ตัว — ทำคนละแบบ:
- **`global-color` / `global-glass` (ทั้งใบ · set ทีเดียว sync ทุกรายการ)** → **revert กลับเป็นดรอปดาวน์เล็ก คงไว้บนสุด** (B เผลอทำ drill-down ไป · ตัวนี้แค่ตั้งค่ารวม ดรอปดาวน์พอ) — ❌ ไม่ทำเลือกทีละชั้น
- **`i-color` / `i-glass` (รายบาน)** → **เลือกทีละชั้น** ✅ B ทำแล้ว (คงไว้)

## ① สีอลูมิเนียม รายบาน (`i-color` · 13 สี) → 4 หมวด
| หมวด | index ใน COLORS |
|------|------------------|
| **มาตรฐาน** | 0 อบขาว · 1 ดำ |
| **ซาฮาร่า/เมทัล** | 2 เทาซาฮาร่า · 3 ดำซาฮาร่า · 4 Aztec gray |
| **ลายไม้** | 5 สักทอง · 6 มะฮอกกานี · 7 ไวท์โอ๊ค · 8 Fuji Oak · 9 Fuji Makha · 11 ลายไม้อบพิเศษ(รหัส) |
| **อบพิเศษ (มีรหัส)** | 10 อบพิเศษ · 12 สีชุบ |
> ขับด้วย selectedIndex (ค่าเดิม = index) · hasCode → โชว์ช่องกรอกรหัสตามเดิม

## ② กระจก รายบาน (`i-glass` · 66 แบบ) → 5 ชนิด → ความหนา
จัดด้วย keyword ในชื่อ option (ไม่แตะ value=index):
| ชนิด | จับจากชื่อ |
|------|-----------|
| **ทั่วไป** | "เขียว/ใส/เคลือบ" + ไม่เข้าหมวดล่าง |
| **เทมเปอร์** | มี "เทมเปอร์" |
| **ลามิเนต** | มี "ลามิเนต" |
| **อินซูเลท** | มี "อินซู" |
| **พิเศษ** | ยูโรเกรย์/ยูโรบรอนซ์ · ดัดโค้ง · ฝ้าพิเศษ |
> กดชนิด → โผล่ chip ความหนา/รุ่นเฉพาะชนิดนั้น · default โชว์ "ทั่วไป"

## ③ มือจับ (un-nest — เลิกปุ่มซ้อนปุ่ม)
แบรนด์ (Cmech/สแตนอร่าม/ดิจิตอล/X/รุ่นอื่น) → กดแล้วสับย่อย (แบบ/สี/ขนาด) **โผล่ใต้ทันที** (ไม่ซ้อนหลายชั้น)

## ④ มุ้ง (`o-mosq` · 15) → ชนิด → ผ้า
ชนิด (เฟรมเล็ก/ใหญ่/จีบ/ม้วน/นิรภัย) → ผ้ามุ้ง (ไฟเบอร์เทา/ดำ/กันแมว/กันหนู) · คิดเร็วทำชิปแล้ว ยกมาโหมดใบเสนอ

## ⑥ OPTION ทางเลือกลูกค้า (`.oc-block` · L4551 + cascade L3136) — เลิกซ่อน/เลิกกดหลายครั้ง
พี่นัท 17มิ.ย. (จากภาพ): กล่องพับ ▶ ต้องกดเปิด → กด "เพิ่ม OPTION" → เลือกเมนูซ้อน = **ซ่อน+กดหลายครั้ง**
→ แก้เป็น: **โชว์เลย (ไม่พับ)** · แถวประเภทเป็นชิป [— ไม่มี —][เปลี่ยนกระจก][ผ้ามุ้ง][สี][มือจับ] → กดประเภท → ตัวเลือกโผล่ใต้ทันที (เลือกทีละชั้น) → ราคา ±บาท คิดให้อัตโนมัติ (logic auto-price เดิม L4847 ไม่แตะ)
- default = "— ไม่มี —" (ไม่มี OPTION) · กรองประเภทตาม `ocCatOptions(d)` ที่สินค้านั้นมีจริง (เดิมมีอยู่แล้ว)
- ดูดราฟ: การ์ด "OPTION ทางเลือกลูกค้า" ใน DRAFT

## ⑤ ป้ายชื่อ — ✅ B ทำแล้ว (f76abbd): โช้คอัพประตู · ทำเป็นบาน · โช๊ค→โช้ค

## 🖥️ ทำให้เหมือนกันทุกจอ (พี่นัท 17มิ.ย.)
drill-down สี/กระจก ต้องเหมือนกัน **3 จอ**:
- ✅ โหมดเต็ม/ใบเสนอ (`i-color`/`i-glass`) — B ทำแล้ว
- 🔴 โหมดคิดเร็ว (`qi-color`/`qi-glass`) — ยังเป็นดรอปดาวน์ → ทำ drill-down
- 🔴 หน้ากั้นห้องกระจก (`gh-color-sel`/`gh-glass-sel`) — ยังเป็นดรอปดาวน์ → ทำ drill-down
(ใช้ฟังก์ชัน drill เดิม colorDrillRender/glassDrillRender ที่ B เขียนไว้แล้ว · แค่ hook เข้าอีก 2 จอ)

## ✅ คงดรอปดาวน์ (มติพี่นัท — ไม่ทำชิป)
สี/กระจก **ทั้งใบ** (global · ดรอปดาวน์เล็กบนสุด) · **G7** ม่านซิป รุ่น/ระบบควบคุม · **เซลล์** · **VAT**

## ขอบเขต/ลำดับ
- สี+กระจก = global ทุกกลุ่ม (i-color/i-glass + global) · มือจับ/มุ้ง = กลุ่มที่มี
- ทำเรียง: ① สี → ② กระจก → ④ มุ้ง → ③ มือจับ → ⑤ ป้าย · **แต่ละตัว snapshot + verify ก่อนไปตัวถัดไป**
- ของที่ chip แล้ว (13 ตัว cd9ea5c) + ชนิดบาน = ไม่ต้องแตะ
