รายละเอียด (สเปค)ค่าที่ต้องระบุชัด: สี (+รหัส) · ความหนา · สีวัสดุย่อย · ชนิดกระจกมีหัวข้อ "รายละเอียด"
เส้นแบ่ง "รายการ" vs "รายละเอียด":
- เป็น ชิ้นงาน/สิ่งที่ทำ (นับเป็นบาน/ชั้น/ด้าน/เมตร ได้) → รายการ

5. จุดแก้ในโค้ด (2 ที่)

5A. itemDetail(it) — L4292 (คืน "รายการ" + "รายละเอียด" แยกกัน)

เดิมคืน det เป็นสตริงเดียว (ทุกบรรทัดปนกัน) · ใหม่ให้คืน 2 ส่วน เช่น { raykan:[...], detail:[...] } หรือคั่นด้วย marker

  • raykan (รายการ) = บรรทัดที่เป็นชิ้นงาน (เดิมอยู่ใน _cLines/prodName subItems) — บานหน้า/ชั้น/ผนัง/มุ้ง/เสริม/รื้อ
  • detail (รายละเอียด) = บรรทัดสเปค — สี+รหัส (จาก .i-color/.i-colorcode) · กระจก (ชื่อเต็ม) · ความหนา
  • ต่อกลุ่ม: cabinet (L4493) · future_tech (L4515) · ฝ้า-ผนัง (L4482) · ระแนง/fin (L4469) · บานกระจก (block ถัดไป) — แยก line ไหนเข้า raykan ไหนเข้า detail ตาม mapping ข้อ 4

5B. ตัวประกอบแถวใบ — L4038–4071 (render 2 บล็อก)

เดิม: ชื่อ → note → addon → "รายละเอียดงาน" (glass) · ใหม่:

  1. หัวรายการ (ชื่อ + ขนาด) — คงเดิม (L4038–4053)
  2. บล็อก "รายการ" — bullet จาก raykan ไม่มีหัวข้อ (ขึ้นใต้ชื่อเลย)
  3. บล็อก "รายละเอียด" — หัวข้อ รายละเอียด (ตัวเข้มแดง) + bullet จาก detail
  4. คง override ของเซลล์ (_detOv/contenteditable L4064–4067) ให้แก้ได้ทั้ง 2 บล็อก
