🗂️ การ์ดโพยคำสั่ง

เปิดดูเวลาลืมว่าจะพิมพ์อะไร · พูดเป็นภาษาคนได้เลย ไม่ต้องเป๊ะ
🅰️ แชท A — ตรวจ + เตรียมงาน
1
"เก็บเป็นก้อนก่อน ยังไม่ส่ง"
→ แชทจดทุกอย่างที่เคาะไว้ ไม่ลืม
2
"ในก้อนมีอะไรบ้าง"
→ แชทโชว์รายการสะสม เช็คว่าครบ
3
"รวมเป็นก้อนเดียว ส่ง Chat B"
→ โชว์ checklist ให้เคาะ → ออกใบสั่ง 1 ใบ
4
"ตรวจงาน G__ หน่อย"
→ (หลัง Chat B เสร็จ) เทียบดราฟ + ใบจริง
🅱️ แชท B — ช่างแก้โค้ด
1
"เช็คว่ามีงานอะไรรอทำ"
→ เห็น 🔴 งานที่เตรียมไว้
2
"ทำ [งาน] ตามที่เตรียมไว้"
→ แชทเปิดใบสั่งทำเอง พี่ไม่ต้องเล่าซ้ำ
3
"เทสกันเพี้ยน แล้วขึ้นเว็บ"
→ เช็คราคา → ขึ้นเว็บ
4
"แคปรูปทุกจุดที่แก้มาดู"
→ ส่งรูปให้ พี่ไม่ต้องเข้าเว็บเอง
ลืมว่าส่งหรือยัง / เสร็จยัง? พิมพ์คำนี้กับแชทไหนก็ได้:
"เช็คสถานะงาน dev"
→ บอกทันที ✅เสร็จ / 🔴รอทำ / ⚪ยังไม่เตรียม (อ่านของจริง ไม่ใช่ความจำ)
⚠️ กฎเดียวที่ต้องรู้: "ช่างแก้โค้ดมีคนเดียว" — อย่าให้ 2 แชทแก้พร้อมกัน (ชนกันพัง) · แชท A หลายตัว = เตรียมพร้อมกันได้ · แชท B = แก้ทีละงาน
🅰️ เตรียม+รวมก้อน → ส่ง → 🅱️ แก้+ขึ้นเว็บ+แคปรูป → กลับ 🅰️ ตรวจ → วนลูป
