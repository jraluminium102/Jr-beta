🔧 จุดที่ทำไม่เหมือนใบจริง + แนวแก้ (จัดกลุ่มตามความเสี่ยง)

ข้อมูล เพิ่มแคตตาล็อก — รอพี่นัทเคาะ "ราคา"

  • กระจก: เงา 2 ด้าน · อินซูเลท (5+air+5) · ลอนแก้ว — เพิ่มใน GLASS (ต้องมีราคา)
  • สี: ชุบทอง/อโนไดซ์ · ลายไม้รหัสรุ่น (KL19022WD) — เพิ่มใน COLORS
  • วัสดุ: ลูกฟูกสำหรับ"บานเลื่อน" (มีแค่บานเปิด) · ฉนวน/อินซูเลทสำหรับ window/door (มีแค่หลังคา) · พื้น(สมาร์ทบอร์ด/ไม้เทียม)
⚠️ การเพิ่มลง array GLASS/COLORS อาจกระทบ baseline (fixture เลือก option ตามลำดับ) — ต้องแก้พร้อม verify · ผมไม่เพิ่มเองเพราะไม่รู้ราคา

UX ปรับการกรอก — ทำได้ ต้องระวัง logic

  • เสริมคาน (o-beamm) โผล่เฉพาะตอนเลือก "ซ่อนราง" → ควรเปิดให้กรอกได้ทุกแบบราง (ใบจริงมีเสริมคานแบบโชว์ราง)
  • OPTION +/- ตอนนี้พิมพ์ข้อความเอง ระบบไม่คิดราคาให้ → เพิ่ม "บรรทัด OPTION + ช่องราคา ±" คิดให้อัตโนมัติ
  • ฝังรางยู / งานเสริมวิศวกรรม → เพิ่ม checkbox/free-text "งานเสริม" ต่อรายการ
  • รื้อของเดิม / ใช้ของเดิม → เพิ่ม checkbox addon (มีบรรทัดงานรื้อท้ายใบแล้ว แต่ไม่มีต่อรายการ)

โครงสร้างใหญ่ ต้องออกแบบ — ตัดสินใจก่อนทำ

  • ชุด multi-side สำหรับผนัง/โรงงาน (ISOWALL+เมทัลชีท ด้าน A-M) — ทำแบบเดียวกับ "ชุดกั้นห้องกระจก" แต่รองรับผนัง/หลังคาโรงงาน + รวมระแนง(g2) เข้าชุดได้
  • โหมดกรอกราคาตรง (lump-sum) สำหรับรายการที่ใบจริงไม่ระบุขนาด/คิดเหมา — ไม่ต้องบังคับ ก×ส
