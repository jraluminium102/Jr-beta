## หมายเหตุสำคัญ

### คาดตาราง — ราคา delta ไม่ตรงสูตรตรงๆ (ไม่ใช่บั๊ก)

ระบบคิดราคา **roundUp (ปัดขึ้นทุก 1,000 บาท)** กับราคารวมทั้งรายการ ไม่ใช่เฉพาะออปชัน  
ดังนั้น delta ที่เห็นจากใบอาจต่างจากตัวเลขออปชันดิบ:

- rawGridCost 1,600 บาท → base 40,000 + 1,600 = 41,600 → roundUp → **42,000** → delta = **+2,000**
- rawGridCost 4,600 บาท → base 40,000 + 4,600 = 44,600 → roundUp → **45,000** → delta = **+5,000**

ถ้าขนาดบานต่างกัน base อาจไม่ใช่ exact-multiple ของ 1,000 → delta อาจเป็นตัวเลขอื่น  
สูตรที่ถูกต้องสำหรับทดสอบ: `expectedDelta = roundUp(baseSell + rawGridCost) - baseSell`

### งานรื้อ — ราคาแต่ละชนิดคำนวณก่อน push รวม (ไม่ roundUp รายชนิด)

- รื้อราวกันตก 4 ม.: 3,000 + 700×4 = **5,800 บาท** (ไม่ใช่ 5,600 หรือ 6,000)
- ยอดรวมงานรื้อจะปรากฏในใบเป็น 1 บรรทัดรวม ไม่มีราคาแยกชนิด (ชนิดอยู่ในหมายเหตุ)

### กั้นห้องกระจก — ค่าทำชุด 5,000 บาท (วาดแบบ + ติดตั้ง)

subtotal ของใบ = ผลรวมราคาทุกส่วน (บาน + หลังคา) + 5,000 ค่าทำชุดกั้นห้องกระจก  
ทดสอบแล้วยืนยันตรง: 61,000 + 5,000 = 66,000 บาท
