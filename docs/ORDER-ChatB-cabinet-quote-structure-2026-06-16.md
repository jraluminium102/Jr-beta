## ผลลัพธ์ที่ต้องได้ "เป๊ะ 100%" (ตู้ 1.2×2.4 ลึก0.6 · 2บาน · 5ชั้นอลู · ผนังซ้ายอลู/ขวากระจก/หลังอลู · สีโครงอบพิเศษ)
```
ตู้อลูมิเนียม (ตู้เสื้อผ้า) ขนาด 1.2 × 2.4 ม. ลึก 0.6 ม.
- บานหน้า Future Tech 2 บาน
- ชั้นวางอลูมิเนียม 5 ชั้น
- ผนังตู้ 3 ด้าน (ซ้าย / ขวา / หลัง)
- ผนัง: ซ้าย อลูทึบ · ขวา กระจก · หลัง อลูทึบ

รายละเอียด
- สีโครง: อบสีพิเศษ · รหัส KL10232A
- ชั้นอลูมิเนียม: อบสีพิเศษ
- กระจก (ผนังขวา): กระจกใส/ใสเขียว หนา 5–6 มม.
```
- บล็อกบน (รายการ) = bullet ใต้ชื่อเลย **ไม่มีหัวข้อ**
- บล็อกล่าง = หัวข้อ **"รายละเอียด"** (ตัวเข้มแดงตามสไตล์ใบ) แล้วตาม bullet

## มติพี่นัท (เคาะแล้ว · ทำตามนี้เป๊ะ)
1. **สีชั้นวาง = ใช้สีเดียวกับโครง** — ดึงค่าสีโครง (`.i-color`) มาแสดงในบรรทัด "ชั้นอลูมิเนียม: [สีโครง]" · ไม่เพิ่มช่องสีแยก · เซลล์แก้มือได้
2. **รหัสสีพิเศษไม่กรอก → ขึ้นเตือน** — ถ้าสีเป็นสีพิเศษ (hasCode) แต่ `.i-colorcode` ว่าง → แสดง **"⚠ ต้องระบุรหัสสี"** (สีแดง) แทนรหัส
3. **กระจกผนังตู้ default** = "กระจกใส/ใสเขียว หนา 5–6 มม." (ระบบไม่มีช่องเลือกชนิดกระจกผนัง → ใส่เป็น default · เซลล์แก้มือถ้าสั่งอื่น) · บรรทัดนี้โผล่**เฉพาะเมื่อมีผนังกระจก**
4. **หัวข้อเดียว** — มีแค่ "รายละเอียด" · รายการไม่มีหัวข้อ

## เงื่อนไขเงื่อนไขแบบมี/ไม่มี (อย่าโชว์บรรทัดที่ไม่เกี่ยว)
- บรรทัด "กระจก ..." โผล่เฉพาะมีผนังกระจก · ถ้าทุกผนังอลู → ไม่มีบรรทัดกระจก
- บรรทัด "ผนัง: ..." โผล่เฉพาะมีติ๊กผนัง · ไม่ติ๊กเลย → "ผนัง: ไม่ติ๊ก (ทุกด้านชนผนังปูน)" (คงของเดิม)
- ชั้นกระจก (shelfmat=glass) → บรรทัด "ชั้น..." เป็น "ชั้นวางกระจก" · รายละเอียดสีชั้น = ไม่มี (กระจกไม่คิดสี)

## จุดแก้โค้ด (2 ที่ · เฉพาะ cabinet)
- `itemDetail(it)` บล็อก `else if(it.p.cabinet){...}` (~L4493) → แยกเป็น 2 ลิสต์: **รายการ** (บานหน้า/ชั้น/ผนัง) + **รายละเอียด** (สีโครง+รหัส/สีชั้น/กระจกหนา) · ย้าย ขนาด+ลึก ไปต่อท้าย "ชื่อหัวรายการ"
- ตัวประกอบแถวใบ (~L4038–4071) → render บล็อก "รายการ" (ไม่มีหัวข้อ) + บล็อก "รายละเอียด" (มีหัวข้อ) · คง contenteditable (`_detOv`) แก้ได้ทั้ง 2 บล็อก

## ⛔ กฎเหล็ก (ห้ามพัง)

## ส่งกลับ (รายงานให้พี่นัท/แชทตรวจ)
1. **ใบ cabinet ที่ออกจริง** (screenshot หรือ HTML `#quoteContent`) ของเคสตัวอย่างข้างบน
2. ผล `golden-snapshot` (ต้องบอกว่า 0 เพี้ยน)
3. ผลเทส 3 ตัว
4. **ถ้าผลออกมา "ไม่เหมือน" target 100%** → ต้อง **อธิบายเปรียบเทียบ before/after** ว่าต่างตรงไหน เพราะอะไร ทำต่อไม่ได้ตรงไหน (ห้ามเงียบ/ห้ามเดาว่าใกล้เคียงพอ)
