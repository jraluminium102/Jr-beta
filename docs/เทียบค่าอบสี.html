ทุน · ค่าแรง · ตัวคูณกำไร · ราคาขาย — เว็บตอนนี้ เทียบ ตาราง R4.1 และ R3.9

ภาพรวมรายรุ่น (สีขาว/ดำ · ทุกขนาดในตาราง R4.1)

ทุน = ทุนค่าของเว็บเทียบตาราง · ขาย = ถ้าใช้ตัวคูณกำไรเท่าตาราง (ค่าแรงขายเท่าตารางอยู่แล้ว) · แดงเกิน +5% · เขียวต่ำกว่า −5%
ขาย (ตัวคูณเท่าตาราง) = ปัดร้อย(ทุนเว็บ × ตัวคูณตาราง + ค่าแรงขายตาราง) · ขายเว็บตอนนี้ = % ที่จูนไว้ 12 ต.ค. · ต่าง = เทียบตาราง R4.1 · แดง/เขียว เกิน ±2%
ค่าสีที่เพิ่ม (ทุน) = ทุนค่าของสีนั้น − ทุนสีขาว · อบ = กก.ที่เข้ากองอบ × เรต/กก. + ตู้อบ · เส้นสี = ซื้อเส้นสีสำเร็จแพงกว่าขาว · ต่าง = ขายเว็บ เทียบ R3.9 · แดง/เขียว เกิน ±2%
