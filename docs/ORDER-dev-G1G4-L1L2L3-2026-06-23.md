# 🎌 ธง A — G1 กล่องสี L1/L2/L3 (g1-rare-section)

> เป้า: ให้เหมือนดราฟ G1 (แท็บ "🪟 G1 บานกระจก") · L1 ติ๊ก default → ปลดติ๊กโผล่ L2(🟢/🔵)+L3 · สีอลู+กระจก = **ดรอปดาวน์** · รหัสสีอยู่ใต้ดรอปดาวน์สี · L3 ชุดเดียว

## A1 🔴 บั๊กราคา: L3 value ชนกัน → เลือกสีใน L3 ราคาไม่เปลี่ยน
**ปัญหา:** option แรก "— ไม่เทียบ —" ใช้ `value="0"` ชนกับ "สีอบขาว" (index 0) · engine check `l3ci>0` ตัด index 0 ออก → เลือกสีอบขาว/ตัวที่ index 0 ใน L3 ไม่มีผล
**แก้ 2 จุด (ต้องทำคู่กัน):**
1. **HTML** (จุด build `_l3CoOpts` / `_l3GlOpts` ~L5702-5703): option "ไม่เทียบ" เปลี่ยนจาก `value="0"` → **`value="-1"`** (ทั้ง g1co-l3c สีอลู + g1co-l3g กระจก)
2. **engine `g1CoOptNote`** (L1262-1274): เปลี่ยน check ทุกจุดจาก `l3ci>0` → **`l3ci>=0`** และ `l3gi>0` → **`l3gi>=0`** · จุดที่ต้องแก้:
   - L1263 `var l3ci=l3c?(parseInt(l3c.value)||0):0` → `parseInt(l3c.value)` อาจได้ -1 (truthy) OK แต่ "ไม่เทียบ"=-1 · เก็บ `||0` ไม่ได้ (−1||0=−1 ✓ truthy) → คงไว้ได้ แต่เปลี่ยน semantic: -1=ไม่เทียบ, ≥0=เทียบ
   - L1267 `if((l3ci>0&&l3ci!==baseC)||(l3gi>0&&l3gi!==baseG))` → `if((l3ci>=0&&l3ci!==baseC)||(l3gi>=0&&l3gi!==baseG))`
   - L1268 `colorPrice(l3ci>0?l3ci:baseC,...)` → `l3ci>=0?l3ci:baseC`
   - L1269 `GLASS[l3gi>0?l3gi:baseG]` (2 จุด) → `l3gi>=0?l3gi:baseG`
   - L1272 `if(l3ci>0&&l3ci!==baseC)` → `l3ci>=0&&...` · L1273 `if(l3gi>0&&l3gi!==baseG)` → `l3gi>=0&&...`
**เกณฑ์ผ่าน:** เลือก L3 = "สีอบขาว" (index 0) ขณะ baseline เป็นสีอื่น → OPTION line ขึ้น + ราคา diff ถูก (ลบได้) · เลือก "ไม่เทียบ" → ไม่มี OPTION line

## A2 🔴 L3 ซ้อน 2 ชุด (พี่นัทบอก "มั่ว") → เหลือชุดเดียว
