1. กั้นห้องกระจก — กรอกอย่างไร แก้ใหม่

⚠ เข้าใจผิดที่พบบ่อย: "กั้นห้องกระจก ให้กรอกราคาเหมาเอง" — ไม่ใช่แล้ว
ระบบรุ่นใหม่ คิดราคาจากบานแต่ละด้านรวมกันอัตโนมัติ ไม่ต้องพิมพ์ราคาเหมา
ขั้นตอนที่ถูกต้อง:
  1. กดปุ่ม "+ กั้นห้องกระจก" → ระบบสร้างชุดให้ พร้อม "ด้าน A" อัตโนมัติ
  2. กรอกบาน ด้าน A (เลือกชนิดบาน + กว้าง × สูง + สี/กระจก)
  3. กด "+ เพิ่มส่วน" เพื่อเพิ่ม ด้าน B, C, D… (ป้ายด้านขึ้นให้อัตโนมัติ ไม่ซ้ำกัน)
  4. ถ้ามีหลังคา กด "+ เพิ่มหลังคา" ในชุดเดียวกัน
  5. ระบบ รวมราคาทุกบาน + หลังคา = ราคาชุด ให้เอง (ดูในเซลล์ยอดรวมของชุด)
✓ สรุป: ไม่ต้องกรอกราคาเหมา · กรอกแค่ "ขนาดแต่ละบานแต่ละด้าน" แล้วระบบคิดให้ — ราคาตรงและตรวจสอบย้อนได้ทุกบาน

2. ค่าบริการ / ค่าติดตั้ง

นอกจากราคาสินค้า อย่าลืมค่าบริการเสริม (ติ๊กในแถบ "บริการเพิ่มเติม"):

รายการราคาหมายเหตุ
Protection พื้น/ผนังขั้นต่ำ 2,000 + 1,000/จุดติ๊กไว้เป็น default
นั่งร้าน (ชั้น 2+)5,000/ชั้นตามจำนวนชั้น
ค่าขนของขึ้นบันไดพื้นที่×500 + 300/ชั้นกรณีของเข้าลิฟต์ไม่ได้
ค่าติดตั้งม่านซิป (zipscreen)5,000 + 600/ตร.ม.ม่านซิปคิดค่าติดตั้งแยกจากตัวม่าน อย่าลืมบวก
เดินไฟดาวน์ไลท์1,500/ดวงระบุจำนวนดวง
ค่าเดินทาง/ขนส่ง ตจว.ตามระยะทาง/ยอดดูในแถบบริการ
