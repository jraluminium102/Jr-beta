> ขอบเขตเล็ก: ส่วนใหญ่ label ดีอยู่แล้ว — แก้แค่ด้านล่าง

## 1. ความไม่สม่ำเสมอ "ทำเป็นบาน" (ระแนง→บาน)
ตอนนี้มี 2 แบบในโค้ด → ทำให้ตรงกัน
- หา `ค่าประตู (เลือกรุ่น)` → แทน `ทำเป็นบาน (เลือกรุ่น)`
- หา `ทำเป็นบาน · ค่าประตู (เลือกรุ่น)` → แทน `ทำเป็นบาน (เลือกรุ่น)`
- (ผล: ทั้ง 2 จุดเป็น "ทำเป็นบาน (เลือกรุ่น)" เหมือนกัน)

## 2. ความไม่สม่ำเสมอ สี/ผิว ระแนง
มี `อบสี/ผิว` · `สี` · `ผิว/สี ระแนง` ปนกัน → ใช้คำเดียว
- มาตรฐาน: **"สี/ผิว"** (ระแนง) · ให้ dev ดู label ของ `o-finish` ทุกจุดแก้ให้ตรง

## 3. ศัพท์ดิบ / สะกด
- หา label ของ `o-closer` ที่ขึ้นต้น `[Up3]` หรือ `โช๊ค (combo สแตน)` → แทนเป็น **"โช้คอัพประตู"**
- คำสะกด **"โช๊ค" → "โช้ค"** ทั้งไฟล์ (มาตรฐานตาม G6 room builder ที่ใช้ "โช้คอัพ") — ⚠ ตรวจว่าไม่ใช่ค่า value/key (เป็นแค่ข้อความโชว์)

## 4. ลักษณะการเปิด (เช็คตรงแล้ว — อ้างอิง)
`o-awn_mode` = "ลักษณะการเปิด" ✅ (บางจุดทำแล้ว · ดูให้ครบทุก branch)
