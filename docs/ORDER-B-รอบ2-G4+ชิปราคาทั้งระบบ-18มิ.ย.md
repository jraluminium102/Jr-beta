## 2. ชิปราคาย่อทั้งระบบ (Z4 · เคาะ 18มิ.ย.: ย่อป้าย+ราคาสั้น)
**กฎเดียวทุก G:** ชิปที่ใส่ราคา+หน่วยยาวในป้าย → **ย่อ: คงราคาสั้น ตัดหน่วย "/ม.²" "/ตร.ม." "/ม." + วงเล็บ** (เซลล์ยังเห็นราคา · ป้ายไม่ล้นจอแคบ · กัน "ม.²" แสดงเพี้ยน)
- G4 วัสดุผนัง: "อลูทึบ (+4,000/ม.²+ค่าสี)" → **"อลูทึบ +4,000"** · "กระจก (+3,000/ม.² ไม่มีค่าสี)" → **"กระจก +3,000"**
- G6 ห้อง: "ดิจิตอล 10,000+" คงได้ · "สแตนเลส 1,500+" คง · "ฉนวน +600/ตร.ม. ✓" → **"ฉนวน +600 ✓"** · "ลูกฟูก/คอมโพ (3,500/ตร.ม.)" → **"ลูกฟูก/คอมโพ +3,500"** · "คาดตาราง (200/ม.)" → **"คาดตาราง +200"** · "ดรอปพื้น (5,000+)" คง
- ราคา/หน่วยเต็ม → ใบเสนอราคา (เหมือนเดิม) · **value/ราคา ไม่แตะ**
