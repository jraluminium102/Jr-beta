# 18 คำถาม option ทุกหมวด — รอพี่นัทตอบ (ส่งต่อแชทใหม่ 2026-06-07)

> ตอบ "เลขข้อ = คำตอบสั้น" · ข้อ [ผมเดา] ถ้าโอเค = "ตามนั้น"
> **ตอบครบ → implement ทุกหมวด** (subagent แก้ + verify ราคาไม่เพี้ยน · ต้นแบบ = บานเลื่อนที่เสร็จแล้ว)

## A. ราคา/ตัวเลข (R3.9 ไม่มี)
1. ธรณีกันน้ำ (บานเปิด/เฟี้ยม) รวมในราคาบาน หรือคิดเพิ่ม? [เดา: รวมแล้ว]
2. หลังคาแปคู่ คิดเพิ่มจากแปเดี่ยวไหม เท่าไหร่?
3. โครงหลังคาเหล็กชุบซิงค์ (เมื่อมีฝ้า) ส่วนต่างจากอลู เท่าไหร่?
4. ปิดปลายหลังคา = 1,000/ม. [เดา: ตามนั้น]
5. รื้อประตู-หน้าต่างเดิม คิด/ตร.ม. เท่าไหร่ (หรือ/บาน)?
6. โช๊คล่าง บานเปลือยสวิง ราคาเท่าไหร่?
7. มือจับสแตนอร่าม = 30.5ซม.1,500/45-60ซม.2,000/80ซม.2,500/100ซม.3,000/120ซม.3,200 [เดา: ตามนั้น]

## B. โครงสร้าง/ตัวเลือก
8. บานหมุน ต้องมีตัวเลือกมือจับ (ดิจิตอล/Cmech) ไหม?
9. บานเฟี้ยม/บานยก ต้องมีมือจับดิจิตอลไหม?
10. คาดตาราง ใส่ได้ทุกหมวดบาน/คิดเงินไหม? [เดา: ทุกหมวด ยังไม่คิดเงิน]
11. tilt&turn เปิดออกนอกเท่านั้น เตือนในระบบ [เดา: ตามนั้น]
12. ราวกันตกแนวตรง/ระเบียง (ไม่ใช่บันได) คิดแบบเดียวกับบันได (imp1-6) หรือมีแบบอื่น?

## C. งานบริการ/ข้อความ
13. Shower พิมพ์ "กระจกเทมเปอร์ใส 10มม. + ราวสแตนเลส" ตายตัว [เดา: ตามนั้น]
14. งานไฟ เพิ่ม control: เดินไฟ 2 ดวง 3,000 · สวิตซ์ใหม่ +1,000/จุด [เดา: ตามนั้น]
15. งานรื้อของเดิม (หลังคา/ราว/กรีดพื้น/ประตู) = checkbox + ข้อความ "รวมงานรื้อ..." ไม่พิมพ์ราคา/หน่วย [เดา: ตามนั้น]

## D. นโยบาย
16. D-series/E-series/aluinch ยกเลิกขายจริงไหม (R3.9 ยังมีราคา · โค้ดติดป้ายยกเลิกแล้ว)
17. กั้นห้องกระจก รื้อมาใช้ "บานหลัก+บานย่อย" เลย หรือคงแบบพิมพ์ด้าน A-H ไปก่อน?
