UX DESIGN MASTER — ฟอร์มกรอกมุ้ง G5

2026-06-14 · สรุปหน้าตา/แนวคิด UX + การโชว์ราคา · ยึดแม่แบบ UXDESIGN-G1-MASTER · คู่ดราฟกดเล่น DRAFT-G5-ux-FULL-2026-06-14.html

สรุปสั้น: ฟอร์ม 1 รายการมุ้ง · มือถือ-เฟิร์นกรอกไว · เลือกชนิดมุ้งเป็น 5 ปุ่ม → รุ่นย่อย → ออปชั่นกรองตามชนิด → เห็นราคาทุกจุดขณะกรอก → พรีวิวใบเสนอราคาแยกราคาท้ายฟอร์ม · ธีมแดง JR · เรตจริง (เทสเบราว์เซอร์ 13 เคสตรง engine)

1) ลำดับฟอร์ม (บน → ล่าง) · 10 ขั้น

1กลุ่มงาน — ปุ่ม G1–G7 (เลือก 🦟 มุ้ง)
2ชนิดมุ้ง — ปุ่มการ์ด 5 กลุ่ม (เฟรม / จีบ / จีบรังผึ้ง / ม้วน / นิรภัย) → ชิปรุ่นย่อย
3ติดกับ — ชิป ประตู/หน้าต่าง (มีผลต่อ min · เฉพาะเฟรม) + จำนวนบาน
4ขนาด & จำนวน — กว้าง·สูง·จำนวนชุด · ม้วนเตะ: เตือนถ้ากว้างเกินรุ่น (maxWidth)
5ผ้ามุ้ง เฉพาะเฟรม — ชิป: ไฟเบอร์(ฟรี)/กันแมว+800/กันหนู+1,200/นิรภัย(เฉพาะเฟรมใหญ่) + สีผ้า(ดำ/เทา/ขาว/เงิน)
6สีกรอบมุ้ง (mscolor) — ตามสีบาน(ฟรี) / สีพิเศษ(ทำสี ×0.5) เฟรมก็คิดเงิน (มติ 06-14 · dev เพิ่ม logic)
7การติดตั้ง / เสริม — ติดมุ้งบานเดิม(โหมด B + ค่าเสริมกล่อง/ราง) · เสริมวงกบ · รื้อมุ้งเดิม
8OPTION ลูกค้า — เลือกหมวด → รายการย่อย · กดเติม แก้/ลบ/กรอกเอง
9ตำแหน่ง / หมายเหตุ
10ออปชั่นทั้งใบ (ท้ายสุด · หมวดเหมือนข้อ 8 · ปรับทุกชุด ±/ชุด)
฿แถบราคารวม ติดล่างตลอด (sticky)

2) การโชว์ราคา — 4 ระดับ (เหมือน G1)

ระดับโชว์ที่ไหนทำอะไร
① บนชิปทุกออปชั่นที่กดติดขึ้น ฿ ตรงชิปทันที (ผ้ามุ้ง = พื้นที่×เรต)
② ต่อกล่องมุมขวาหัวข้อทุก sectionsubtotal กล่องนั้น (secsum) โชว์เสมอ
③ พรีวิวใบเสนอราคาการ์ดท้ายฟอร์มแยกราคา (ฐานมุ้ง + ผ้า + OPTION) + รวม/ชุด + ออปชั่นทั้งใบ + ยอดรวม
④ แถบรวมล่างจอ stickyยอดรวมทั้งใบ realtime

3) สูตรราคามุ้ง (ตรง engine · REF §0)

มุ้งเฟรม (imp21/22/23 · screen_addon):
sell = ปัดพัน( max(min_door|win × จำนวนบาน, พื้นที่ × rateOf) + ผ้ามุ้ง )
· ผ้ามุ้ง/ตร.ม.: ไฟเบอร์ 0 · กันแมว 800 · กันหนู 1,200 · นิรภัย rateOf(A,IMP31) เฉพาะ imp23
มุ้งอื่น (generic): sell = ปัดพัน( max(min, พื้นที่ × rateOf) ) + (สีกรอบ ×0.5 ถ้าเลือก)
rateOf: area < ขั้นต่ำ tier → คืนเรต tier แรก · roundUp = ปัดขึ้นพัน
กฎราคา: ตัวเลขจริง = ฐานมุ้ง(พื้นที่×เรต) · ผ้ามุ้ง(กันแมว/หนู/นิรภัย) · โหมด B(ค่าเสริมกรอกเอง) · "ตามเรตจริง" (dev ดึง colorPrice) = สีกรอบพิเศษ · ทุกช่องราคา แก้ได้

4) ฟีเจอร์ดีไซน์สำคัญ (ปรับจาก G1 ให้เหมาะมุ้ง)

ฟีเจอร์รายละเอียด
5 ปุ่มชนิด → รุ่นย่อยเฟรม(imp21/22/23/30) · จีบ(imp28/sd_basic) · จีบรังผึ้ง(blackout/sd_twoway/keep×2) · ม้วน(imp29/kick150/300/600) · นิรภัย(imp31/32/screen_safety)
ผ้ามุ้งโผล่เฉพาะเฟรมimp21/22/23 เท่านั้น (screen_addon) · ผ้านิรภัยโผล่เฉพาะ imp23 (เฟรมใหญ่)
ติดกับ ประตู/หน้าต่างมีผลต่อ min (เฉพาะเฟรม) · door = min สูงกว่า window
maxWidth warn (ม้วนเตะ)kick 150/300/600 · กรอกกว้างเกินรุ่น → เตือน soft (เช็คซ้ำ #3: ไม่มี guard ตอนขายเดี่ยว)
โหมด B ติดบานเดิมcheckbox + ช่องค่าเสริมกล่อง/ราง (กรอกเอง · default 0)
OPTION แบบหมวดเลือกหมวด (ผ้า·สี/กรอบ·ติดตั้ง/ราง·งานเพิ่ม·ส่วนลด) → รายการย่อย → เติม แก้/ลบ/กรอกเอง
imp33 (กันแมว/หมา) + imp35 (กันหนู) = ซ่อนจากเมนูชนิด (มติพี่นัท 2026-06-12, ยืนยัน 06-14) — เป็นชนิดผ้า ไม่ใช่รุ่น · ลูกค้าได้กันแมว/หนูผ่าน ผ้ามุ้งบนเฟรม (cat +800 / rat +1,200) · เก็บสินค้า/เรตในระบบไว้ (เผื่อใบเก่า) แค่ไม่โชว์ในเมนู

5) สไตล์ / หลักดีไซน์ (ยึดเหมือน G1)

1. เน้นปุ่ม/ชิป ไม่เน้นดรอปดาวน์ · 2. กรองตามชนิด โชว์เฉพาะที่มีจริง (ผ้ามุ้ง=เฉพาะเฟรม) · 3. เห็นราคาทุกจุด (ชิป/กล่อง/พรีวิว/แถบรวม) แก้ได้ · 4. สำคัญขึ้นบน เสริม/หมายเหตุล่าง ราคาท้าย · 5. กรอกง่าย ≤2 แตะ · ธีมแดง JR #B3151D การ์ดขาว มือถือ max-width 560
