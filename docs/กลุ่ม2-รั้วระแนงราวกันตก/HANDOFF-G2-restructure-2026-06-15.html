1) โครงหมวดใหม่ = 4 หมวด (เดิมกระจาย 6)

หมวดวิธีเลือก (ชิป cascade)
🚪 ประตูรั้วบานเลื่อนเท่านั้น (ตัดสวิง/บานเปิด/เลื่อนล่าง-บน) → ลายระแนง (ขนาดเส้น→หน้าโชว์·ระยะ ไม่โครง) → ขนาด → สีอบ → ชนิดราง(ตรง/โค้ง) → มอเตอร์(stepper) → ธรณี
🪟 ระแนง (3 ชนิด)ชิปชนิด: กล่อง / เกล็ด Z / เลื่อน Inception
• กล่อง: ขนาดกล่อง → หน้าโชว์ → ระยะห่าง → ทำเป็นอะไร(ติดตาย/ทำบาน) → โครง
• เกล็ด Z: ขนาด(1"/1.6"/4") → ทำเป็นอะไร → โครง
• เลื่อน Inception: ขนาด → เลือกบาน G1/ติดตาย → สีอบ
🛡️ ราวกันตกทรง(เฉียง/ตรง) → ระบบยึด(หมุด/ยู/เสา) → ยาว → ความหนากระจก → ราวมือจับ → (ยู/เสา) สีอลู
⚙️ ระแนงพิเศษ (2)ระแนงหมุนเปิด-ปิด / บานเกล็ดอลู → ขนาด → ทิศ(ตั้ง/นอน) → (เปิด-ปิด) มอเตอร์+สีอบ
หมายเหตุโครง: ประตูบ้านปกติ (บานเปิด/เลื่อน) = อยู่ G1 ไม่เอามา G2 · ระแนงพิเศษเหลือ 2 ตัว (เลื่อน=Inception ย้ายเป็นชนิดระแนง · ตัดออกจากพิเศษ)

2) 🔴 ระแนงกล่อง — จัดกลุ่ม "ขนาดกล่อง → หน้าโชว์ → ระยะ" (รวมบังตา+ผนัง)

ปัญหาเดิม: 1"x1.6" โชว์หน้าเดียว (บังตา=หน้า 1" · ผนัง=หน้า 1.6" แยกคนละหมวด) · cascade รวมหน้าโชว์+ระยะเป็นปุ่มเดียว
แก้: รวม ระแนง-บังตา (76) + ระแนง-ผนัง (6) เป็น "กล่อง" เดียว แล้วแยกชั้น ขนาดกล่อง → หน้าโชว์ → ระยะห่าง → โครง
ผลลัพธ์ (กล่อง→หน้าโชว์):
  • 1x5 cm. → หน้า [1cm., 5cm.] · 1"x1.6" → หน้า [1", 1.6"] (รวมบังตา+ผนัง) · 1"x4" → [1", 4", 4"ทึบ] · 1.6"x4" → [1.6", 4"]
  • กล่องจัตุรัส (1"x1", 1.6"x1.6", 4"x4") → หน้าเดียว (ถูกต้อง)
  • รวม 82 รุ่นกล่อง (76 บังตา + 6 ผนัง) + 6 เกล็ด Z = 88 ครบ
ราคา (per_sqm · เรต+สูตรใน engine เดิม): roundUp( (a×rate + a×fin×[ทำบาน?0.85:1])×(1−ranaeDisc) + ค่าทำบาน ) · a=กว้าง×ranaeH(สูง) · ทำเป็นบาน=ระแนงไม่โครง+ค่าทำบาน(basePrice G1)

3) 🚪 ประตูรั้ว — บานเลื่อน + ราคาจริง (engine L1246)

roundUp( พื้นที่×mk + พื้นที่×rnRate×(1−disc) + มอเตอร์×30,000 + 2×กว้าง×railr [+บานโค้ง] )
mk (ค่าทำ/ตร.ม.): พื้นที่ ≤6=4,000 · ≤8=3,500 · ≤10=3,000 · >10=2,500 · railr: ตรง 1,500 / โค้ง 2,500 · บานโค้ง ⌈กว้าง/0.75⌉×4,000 · rnRate=ลายระแนงบังตา ไม่โครง
เปลี่ยน: o-gatetype เหลือ "บานเลื่อน" อย่างเดียว (เดิม swing/casement/slide_bottom/slide_top — พี่นัทบอกผิด)

4) 🚪 ระแนงเลื่อน Inception (bar_slide · ลูกฟูกเรียบ 2 ทาง · engine L1166)

ชนิดที่ 3 ในกลุ่มระแนง (พี่นัท: "เพิ่มระแนงเลื่อนลูกฟูกเรียบ 2 ทาง เข้าไป เลือกบานหรือติดตายได้")
roundUp( ค่าประตู + max(3,000, พื้นที่×1,000) + max(3,500, กว้าง×Hร×3,500) + finRate×พื้นที่ )
ค่าประตู = basePrice บาน G1 ที่เลือก (เลื่อนเซมิ/ยูโร·เฟี้ยมเซมิ/ยูโร·เปิดยูโร) หรือ 0 ถ้าติดตาย · ลูกฟูกเรียบ 2 ทาง: Hร=ปัด 1/1.5/2/3 ม.

5) ⚙️ ระแนงพิเศษ 2 ตัว — คิดราคา (engine L1146/L1203)

ระแนงหมุนเปิด-ปิด (bar_openclose): roundUp( ns×max(20,700, A/ns×6,900) + ns×D×2,000 + [มอเตอร์] ns×⌈D/3⌉×10,000 + finRate×A ) · ns=min(3,⌈Dขนาน/3⌉)
บานเกล็ดอลู (bar_grid_z): roundUp( max(5,500, A×5,500) + (ns−1)×(max(500, A/ns×1,500)+1,000) ) · ns=⌈D/1.5⌉ · ⚠ มอเตอร์ 38.1 ไม่บวก — engine return ที่ L1164 ก่อนถึงโค้ดมอเตอร์ L1497 (latent bug · dev ตรวจว่าตั้งใจหรือไม่)
