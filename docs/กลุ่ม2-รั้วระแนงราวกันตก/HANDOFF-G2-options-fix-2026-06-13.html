🔴 จุดที่ 1 — “มีคาดตาราง” โผล่บนระแนง/ประตูรั้ว

ที่: buildItemOpts() บรรทัด ~2993 (checkbox o-gridmark)

ปัญหา: exclude list ไม่มี หมวดระแนง/ประตูรั้ว → คาดตาราง (เส้นกริดคร่อมบาน) โผล่บน ระแนงบังตา/ผนัง/เกล็ด · ระแนงพิเศษ(เลื่อน/เกล็ดอลู/เปิด-ปิด) · ประตูรั้ว ซึ่งเป็นตัวระแนงอยู่แล้ว ไม่มีงานคาดตาราง

(imp1–imp6)		ความหนากระจก 10/12 · ราวมือจับด้านบน(ยู/กล่อง) · สีอลู 3 สี เฉพาะ imp2/3/5/6 · งานเสริม · รื้อของเดิม— (ไม่ leak · ถูกแล้ว) imp1/imp4 ไม่มีสีอลู ✓
✅ ที่ตรวจแล้วว่า “ไม่ leak” (ของจริง gate ถูกต้อง — ไม่ต้องแก้):
  • มุ้ง (o-mosq) — gate ด้วย if(p.mosquito) · G2 ไม่มี flag → ไม่โผล่ ✓
  • ติดตาย (o-fixed) — อยู่ใน sliding-main-block เฉพาะบานเลื่อน/เปิด → G2 ไม่โผล่ ✓

  • สีอลู imp1/imp4 — gate ด้วย if(p.railalu) · imp1/4 เป็น railstud → ไม่มีสีอลู ✓
