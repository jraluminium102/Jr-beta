## ที่มา
ใบจริงระบุชื่อสีลายไม้เฉพาะ (Golden Teak SMS ฯลฯ) + พี่นัทอยากให้ G2 เลือกสีอบ "เหมือนงานบาน G1" (กดหมวด→เลือกต่อ) แทนชิปแบนเรียงยาว · audit ใบจริงเจอ P2 ชื่อสีหาย

## ขอบเขต — 5 select สีอบ G2 + แก้ป้าย G1
`o-gfin` (ประตูรั้ว) · `o-finish` (ระแนง) · `o-bgcolor` (เกล็ดอลู) · `o-bsfinish` (เลื่อน) · `o-bocfinish` (หมุนเปิด-ปิด)
→ ทั้ง 5 อยู่ใน `CHIPIFY_SELECTS` แล้ว (L3314) · ต่อยอดจากชิปปัจจุบัน

## A. โครงเลือกสี = 4 หมวดเหมือนงานบาน (อ้าง COLOR_CATS L1004 / COLORS L970)
จัดตัวเลือกของแต่ละ select เข้า 4 หมวด:
1. **มาตรฐาน** — สีอบขาว · สีดำ · ไม่อบสี
2. **ซาฮาร่า** — (ตัด "เมทัล" ออก)
3. **ลายไม้สต๊อก**
4. **อบพิเศษ** — กรอกชื่อสี (ดูข้อ C)

## B. กติกาแสดงผล (มติ 18 มิ.ย.) — สำคัญสุด
- **ในหมวด "มีตัวเดียว" → โชว์ชิปตัวจริงเลย กดจบ** (ไม่ต้องกด 2 ที)
- **มี ≥2 ตัว → ชิปหมวด กดแล้วเลือกตัวจริงต่อ** (drill-down เหมือนงานบาน)
- ของจริง: drill เกิดเฉพาะ **ซาฮาร่า ของเลื่อน/เปิด-ปิด** (เทา/ดำ/Aztec = 3 ตัว) · จุดอื่นซาฮาร่า/ลายไม้มีตัวเดียว = กดจบ
- 💡 ดูเครื่องยนต์ drill งานบาน `colorDrillRender` (L1001+) เป็นแม่แบบ — แต่ G2 select โครงตัวเลือกต่าง (fin object/hardcode) ต้องเขียน renderer ขนานที่ "อ่านตัวเลือกจริงของ select นั้น" แล้วจัด 4 หมวด · **อย่า hardcode รายการ** ให้อ่านจาก option จริง (กันรุ่นที่ไม่มีลายไม้สต๊อก)

## C. ช่องกรอกชื่อสีพิเศษ (ยุบงาน colorname เดิมมารวม)
เลือกตัวในหมวดอบพิเศษ → โผล่ `<input>` ชื่อสี → ขึ้นใบ (บล็อกรายละเอียด/spec):
- กรอก → `สีอบพิเศษ (Golden Teak SMS)` · ไม่กรอก → `สีอบพิเศษ · ⚠ ระบุชื่อสี` (เตือนช่าง)
- **ตัวที่ทริกช่องชื่อ** = ชื่อมี "พิเศษ" **+ "Fuji"** (มติ 18 มิ.ย. นับ Fuji เป็นอบพิเศษ ต้องกรอกชื่อ) → regex `/พิเศษ|Fuji/`
- buildItemOpts rebuild → reset ช่อง (กันค้างค่าเก่า) · readItem เก็บ `optSel.Xcolorname` · ไม่กระทบราคา

## D. แก้งานบาน G1 ด้วย (พี่นัทสั่ง "บอกงานบานด้วย")
`COLOR_CATS` **L1006** ป้ายหมวด `'ซาฮาร่า/เมทัล'` → **`'ซาฮาร่า'`** (ตัดคำ "เมทัล") · แค่ป้าย ไม่แตะ idx/ราคา
