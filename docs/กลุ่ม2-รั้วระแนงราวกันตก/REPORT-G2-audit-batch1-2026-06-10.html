จุดที่ต้องแก้ — จัดลำดับ + เลขบรรทัด (ส่งแชทแก้โค้ด)

P1 1. ประตูรั้ว: ไม่มีให้เลือกลักษณะการเปิด (hardcode บานเลื่อน)

ใบจริงมี บานสวิง / บานเปิด / บานเลื่อนเปิดคู่กลางรางบน · ระบบ fix เป็นบานเลื่อน ราง 2×กว้างเสมอ
  • แก้: เพิ่ม o-gateopen (สวิง/เปิด/เลื่อนคู่กลาง) → ชื่อ+สูตรรางเปลี่ยนตาม · จุด: L590 (name), L1163 (calc), L2406 (opts)

P1 2. ประตูรั้ว: รายละเอียดงานไม่ลงบรรทัดลูกค้า

ระแนงติดตายด้านข้าง / ซี่ระแนง 1"x1.6" โชว์หน้า เว้นระยะ / สีระแนง — อยู่แค่ msg เทาภายใน ไม่ขึ้นใบ
  • แก้: ผลัก detail ของ gate เข้าบรรทัด "รายละเอียดงาน" (เหมือน rn/บาน) · จุด: L1163 msgs[] → genQuote

P1 3. ประตูรั้ว: สีพิเศษคิดเพิ่ม = 0 บาท (key ไม่ตรง)

o-gfin ใช้ค่า "สีอบพิเศษ/สีลายไม้อบพิเศษ/สีดำซาฮาร่า/สีลายไม้สต๊อก" แต่ fin ของระแนงใช้ "อบสีพิเศษ/อบสีลายไม้" → match ไม่ได้ → +0 (เฉพาะ "สีเทาซาฮาร่า" ที่ตรง)
  • แก้ option value ให้ตรง key จริง + ตัด "สีดำซาฮาร่า/สีลายไม้สต๊อก" (rn ไม่มี key นี้) · จุด: L2406 vs L695-770

P1 4. ระแนงเลื่อน bar_slide: เลือกประตู fence_gate แล้วแอปแครช

doorOpts มี 'fence_gate' ปน → basePrice(fence_gate) ไม่มี method/rates → TypeError
  • แก้: ตัด 'fence_gate' ออกจาก array · จุด: L2411

P1 5. ระแนงเกล็ด bar_grid_z: ไม่มี selector สี + ทิศ/สี ไม่ลงใบ

มีแค่ o-bgdir (ทิศ) ไม่มีช่องสีเลย · และทิศก็ไม่ลงบรรทัดใบ
  • แก้: เพิ่ม dropdown สีอบ (แบบ bar_openclose) + ผลักทิศ/สี ลงรายละเอียดงาน · จุด: L587, L2407

P1 6. ระแนงเกล็ด bar_grid_z: มอเตอร์นับผิดเมื่อทิศตั้ง

motorCount = ceil(W/3) ใช้กว้างเสมอ · ทิศตั้ง (v) ควรใช้สูง (H)
  • แก้: เลือก D ตามทิศ (v→H, h→W) · จุด: L1371-1376

P1 7. ระแนงเลื่อน/เปิด-ปิด: สีที่เลือกไม่ลงใบ

o-bsfinish/o-bocfinish กระทบราคาแต่ไม่ถูก render เป็นบรรทัดสีในใบ → ลูกค้าไม่เห็นสีที่จ่ายเพิ่ม
  • แก้: genQuote ดึง bsFinish/bocFinish (data-n) มาเป็นบรรทัด "สี…" · จุด: L2415/2420 + readItem L2651/2656 → genQuote

P1 8. ชื่อสินค้าหลุดศัพท์ภายในลงใบลูกค้า

"(ข้อ 38.1/38.2/38.3)", "ลูกฟูกเรียบ 2 หน้า/ทาง", "47.1 … (ทำยากสุด)" — เป็นโค้ดภายใน ไม่ควรอยู่ในใบเสนอราคา
  • แก้: แยก field ชื่อสำหรับลูกค้า (เช่น qname) หรือ strip ข้อ/วงเล็บภายในตอน genQuote · จุด: L587-589, L655-660

P2 9. ราวกันตกกระจก: ไม่มีบรรทัดอุปกรณ์สแตนเลส

ใบจริง "อุปกรณ์มาตรฐานผู้ผลิต สแตนเลสสีเงิน" — ระบบไม่มี (กระจกเทมเปอร์ 10/12มม. ลงถูกแล้ว)
  • แก้: เพิ่มบรรทัดอุปกรณ์ default ให้ราวกันตกกระจก (เช็คซ้ำ ความหนา 10 vs 12 ต่อเคส)

P2 10. ระแนงบังตา: default สีควรเป็น "สีเทาซาฮาร่า" (เช็คซ้ำ)

ระบบ default สีอบขาว · ใบจริงทุกใบใช้สีเทาซาฮาร่าเป็นหลัก → ควรตั้ง default ให้ตรงงานจริง

P2 11. ระแนงบังตา: รูปแบบคำขนาดซี่ต่างใบจริง (เช็คซ้ำ)

ระบบ "1x5 cm. โชว์ 1cm. 5cm." · ใบจริง "1"x1.6" โชว์หน้า 1" เว้นระยะห่าง 2.5 ซม." (หน่วยนิ้ว + คำ "เว้นระยะห่าง") — อ่านออกแต่คำไม่ตรง

🟢 ดีแล้ว ไม่ต้องแก้

  • ราวบันได: กระจกเทมเปอร์ใส 10 มม. ลงใบถูก (glassDef:14)
  • ขนาดท้ายบรรทัด "(X × Y ม.)" / "(ยาว X ม.)" ถูกทุกตัว
  • หน่วย "1 ชุด" ตรงใบจริง (lump sum)
