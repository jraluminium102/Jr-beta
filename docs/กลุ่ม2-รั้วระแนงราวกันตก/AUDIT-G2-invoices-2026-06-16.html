ระดับจุดที่มาจากใบจริงสถานะในระบบเสนอแก้
ผิดแน่ ระแนงบังตา ขนาดโชว์หน้า/ระยะเว้น ไม่ครบแบบ
ใบหญิง: โชว์หน้า 1.6" เว้น 3 ซม.
ใบนก (ใต้หลังคา): โชว์หน้า 1" เว้น 5 ซม.
ใบบุญญารัตน์: โชว์หน้า 1" เว้น 2.5 ซม.		 ใบจริง 3 ใบใช้ระยะเว้น/โชว์หน้าต่างกัน 3 แบบ — ระบบปัจจุบัน CHECK-G2 บอกว่า rn2 มี product แต่ไม่ระบุว่า field "ระยะเว้น" กรอกได้หรือ hardcode CHECK-G2 ไม่ตรวจ field นี้โดยตรง — ไม่ทราบว่าระบบให้กรอกเองหรือเปล่า ตรวจว่า rn2/rn38 ให้กรอกระยะเว้น+โชว์หน้าได้ไหม ถ้า hardcode ต้องแก้เป็น input
ผิดแน่ ชนิดกระจกราวกันตก — ใบจริงระบุในหมายเหตุท้ายใบ ไม่อยู่ในรายการ บุญญารัตน์: "กระจกเทมเปอร์ใส หนา 10 มม. (ข้อ 3, 12)" — เขียนรวมท้ายใบ ไม่ใช่ในแถวของรายการที่ 3 CHECK-G2: .o-railglass มีใน product แต่ไม่ทราบว่าใบระบบพิมพ์ชนิดกระจกที่แถวรายการหรือท้ายใบ เช็คซ้ำว่าใบระบบพิมพ์ spec กระจกราวกันตกที่ไหน — ถ้าไม่พิมพ์ในรายการต้องเพิ่ม
รอเคาะ ครอบวงกบระแนง (o-fcsides) ใบจริง 3 ใบ ไม่มีครอบวงกบในงานระแนง/ประตูระแนงเลย CHECK-G2: 🟡 "ดราฟต้องการมี" แต่ระบบยัง block โดย AREA_CATS ถาม: ครอบวงกบใช้ในงานระแนงจริงไหม? ถ้าไม่ใช้ → ลบออกจาก spec ดราฟ ถ้าใช้ → แก้ exception
รอเคาะ ประตูระแนงรางบน (ข้อ 25/26 บุญญารัตน์) — map ระบบชนิดใด ใบระบุ "บานเลื่อนเปิดคู่กลางรางบน" ราคา 112k/141k — ชื่อแตกต่างจาก fence_gate CHECK-G2 มี bar_slide (Inception) และ fence_gate แยกกัน ยังไม่ชัดว่า "รางบน" map ตัวไหน เช็คซ้ำ: ระแนงเลื่อนรางบน (bar_slide) vs ประตูรั้วเลื่อน (fence_gate) — ต้องดูสเปก product_id
รอเคาะ OPTION ลายไม้ในใบจริงเขียนเป็นราคาอีกชุด ไม่ใช่ราคาเพิ่ม บุญญารัตน์ข้อ 1: "OPTION ลายไม้ = 65,000 บาท" (ราคาใหม่ทั้งหมด ไม่ใช่ +บาท)

สรุป 5 คำถามจากสเปก vs ใบจริง

#คำถามจากใบจริงสถานะ
1 รายการ G2 ปรากฎในใบจริงอย่างไร? ระแนง/ประตูระแนง: ใช้ชื่อ "ระแนงอลูมิเนียมบังตา" / "ประตูระแนงบานเปิด/สวิง/เลื่อน" · ราวกันตก: ใช้ชื่อ "ราวกันตกกระจก" · ไม่มีการเขียนแยกรายการย่อย (ความยาว/ขนาด) ในตาราง — ระบุในรายละเอียดท้ายใบ ชัดเจน
2 ครอบวงกบระแนง — มีในใบจริงไหม? ไม่มีในใบทั้ง 3 ใบ — ไม่แม้แต่เป็น OPTION รอเคาะพี่นัท
3 สีระแนง — ระบุในใบจริงอย่างไร? ระบุในส่วน "รายละเอียดงาน" ท้ายใบ เช่น "ระแนงอลูมิเนียมกล่อง สีเทาซาฮาร่า ขนาด 1"x1.6" โชว์หน้า 1" เว้น 2.5 ซม." · ไม่ใส่ในแถวรายการ ตรงรูปแบบ
4 มอเตอร์ประตูรั้ว — ระบุอย่างไร? ไม่ปรากฏในใบทั้ง 3 (ไม่มีงานรั้วบ้านจริงในตัวอย่างเหล่านี้) ไม่มีตัวอย่าง
5 ราวกันตก — ความยาว/ชนิดกระจก/สีอลูระบุอย่างไร? บุญญารัตน์: ราคา 10,000 บาท · กระจกเทมเปอร์ใส 10 มม. ระบุท้ายใบ · ไม่มีความยาวหรือสีราวในรายการ
หญิง: ราวกันตกเดิมถูกรื้อออก ไม่ได้ติดใหม่		 ขาดรายละเอียดใน row
