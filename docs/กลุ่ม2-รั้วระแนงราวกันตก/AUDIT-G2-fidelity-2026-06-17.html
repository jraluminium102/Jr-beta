ใบจริงระบุ "เว้นระยะห่าง 2.5 ซม." ชัดเจน · ระบบออกใบไม่มีระยะห่าง		 ลูกค้าไม่รู้ระยะห่างจริงจากใบ genQuote ไม่ดึง spacing (ซม.) ของ product มาแสดงในรายละเอียด ส่วน genQuote G2 รายละเอียด (เช็คซ้ำ) เพิ่ม "เว้นระยะห่าง X ซม." ในบล็อกรายละเอียดของ rn-series ทุกตัว
P1-6 ทิศทางระแนง (แนวตั้ง/แนวนอน) ไม่ขึ้นในใบ
ใบจริงธนบัตรระบุ "แนวตั้ง" · o-grdir มีใน code แต่ hidden		 ลูกค้าไม่ทราบทิศทางจากใบ o-grdir ถูก set display:none · genQuote ไม่อ่านค่า grdir o-grdir SELECT + surrounding div (display:none) — เช็คซ้ำบรรทัด แสดง o-grdir เมื่อ user ต้องการ + ดึง value มาออกใบในรายละเอียด
