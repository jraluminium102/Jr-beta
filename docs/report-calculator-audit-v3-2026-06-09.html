ปิดปลายหลังคา — คิดเงินได้ 3 ทาง ราคา 1,000/ม. เท่ากัน แก้ ยืนยันเอง
  • ทาง 1: สินค้าแยก roof_eave_cover "โครงปิดปลายกันน้ำ" (บรรทัด 624) 1,000/ม.
  • ทาง 2: ตัวเลือกในชุดหลังคา o-roofend='ปิดปลาย' → 1,000 × กว้างชุด (auto)
  • ทาง 3: ตัวเลือก o-rfeave "ปิดปลายกันน้ำ" (บรรทัด 2281) → 1,000 × ยาวที่กรอก
  • ทาง 2 กับ 3 อยู่ในฟอร์มเดียวกัน → เผลอกรอกทั้งคู่ = คิดซ้ำ 2 เท่า
  • เหลือทางเดียวในชุดหลังคา — ตัด o-rfeave หรือตัด "ปิดปลาย" ใน o-roofend
  • เก็บสินค้าแยก roof_eave_cover ไว้เฉพาะงานที่ไม่ได้สั่งชุดหลังคา
  • เช็คก่อน: ตั้งใจให้มีทั้งคู่ไหม
รางน้ำหลังคา — สินค้าแยก vs ตัวเลือกในชุด ราคาตรงกัน เช็คก่อน ยืนยันเอง

  • ตัวเลือกในชุดหลังคา o-rfgut (บรรทัด 2278) = อลู S 1,000 / สแตน M 2,000 / สแตน L 3,000 ตรงกันทุกไซต์
  • ถ้าใช้ทั้งสินค้าแยก + ตัวเลือกในชุด = ได้รางน้ำ 2 ชุด
  • เช็คเจตนา: สินค้าแยกไว้ใช้กรณีไม่มีชุดหลังคาใช่ไหม

OPTION ระดับชุด (preset ทั้งชุด)🔴 โชว์ราคาในใบ แต่ไม่บวกเข้ายอด → ขายขาดทุน ยืนยันเอง
  • ปุ่ม "OPTION สำเร็จรูป" ตั้งค่า .set-optdelta
  • ตัวอ่าน (2556) อ่านเป็น groupOptDelta แต่นำไปแสดงข้อความอย่างเดียว (3270)
  • ไม่เคยบวกเข้า sell/gTotal/subtotal → ใบบอก "+N บาท" แต่ยอดรวมไม่รวม
  • (รูปแบบเดียวกับบั๊กมุ้งต่อบานที่เพิ่งแก้)
  • ถ้ายังใช้ preset ทั้งชุด → บวก groupOptDelta เข้า sell บานแรกในชุดครั้งเดียว
  • ถ้าเลิกใช้แล้ว (ย้ายไป OPTION ต่อบาน F2) → ซ่อนปุ่ม/ช่อง preset ทั้งชุดออกจาก UI
ส่งออก Excel (exportQuoteExcel)🔴 ฮาร์ดโค้ด VAT 7% ไม่อ่านช่อง VAT ยืนยันเอง
  • บรรทัด 3389 คิด vat = (net+svc)*0.07 ตายตัว
  • เลือก "0% (ไม่มีใบกำกับ)" → Excel ยังชาร์จ 7% → ไม่ตรงใบ HTML
  • ไฟล์ Excel ยังพลาด OPTION ระดับชุดด้วย (วนทีละ item)
  • บรรทัด 3389 อ่าน vatPct จาก #vat-pct ใช้ net*vatPct/100 แทน 0.07
  • ใช้ตัวแปร VAT ตัวเดียวกับใบ HTML
ส่วนลดค่าประเมิน (discFlat)🟡 ไม่มีเพดาน → ยอดสุทธิติดลบได้ ยืนยันเอง
  • net = subtotal − discAmt − discFlat
  • ถ้า discFlat > subtotal → net ติดลบ → VAT ติดลบ
  • ส่วนลด % มี clamp แต่ discFlat ไม่มี
  • ใส่ net = Math.max(0, net) หรือเตือนเมื่อ discFlat เกินยอด
โหมดเหมา (lumpsum)🟡 ตั้งราคาเหมาแล้วยังบวก OPTION/subItems ทับ ยืนยันเอง
  • บรรทัด 2528 ตั้ง sell = ราคาเหมา
  • บรรทัดถัดมา optDelta/OPTION/subItems ยังบวกทับ
  • ถ้าเจตนา "เหมา = ราคาตายตัว" จะบวกเกิน
  • ถ้าเหมา=ราคาล็อก → เปิดเหมาแล้วข้ามการบวก OPTION/subItems
  • ถ้าเหมา=ฐาน+ออปชั่นได้ → คงไว้ แต่เขียนกำกับให้ชัด
มัดจำ / งวดชำระ🟡 ไม่มีตารางมัดจำ-งวด เช็คซ้ำ
  • ใบมียอดรวม/ส่วนลด/VAT/รวมทั้งสิ้นครบ
  • แต่ไม่มีตารางแบ่งมัดจำ-งวด (มีแต่คำว่ามัดจำในเงื่อนไข)
  • ถ้าต้องระบุในใบ → เพิ่มตารางงวด (มัดจำ X% · งวดติดตั้ง · งวดสุดท้าย)
  • ถ้าตั้งใจไม่ใส่ → ผ่าน
