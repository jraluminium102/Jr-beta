3 เรื่องที่ต้องทำ

#เรื่องรายละเอียด
E1แก้ข้อความได้ทุกจุด (โหมดแก้ไข)กดดินสอ → editable ทั้งหมด: ชื่อรายการ (มีแล้ว) + ทุกบรรทัด "รายละเอียดงาน" + หมายเหตุ · เพิ่ม/ลบบรรทัดรายละเอียดได้ · เก็บเป็น override (คล้าย _nameOv → ทำ _detOv) · ออกปุ่ม/ค่าที่แก้ลงใบ
E2ลบ "คิดราคาเหมา" (ยกเลิก)เอา checkbox คิดราคาเหมา + ช่อง "ราคาเหมาต่อชุด" ออก (ซ้ำซ้อน) · ราคาแก้ได้ตรงๆ ในช่องราคา/หน่วย (โหมดแก้ไข) อยู่แล้ว — ใช้อันนั้นแทน
E3OPTION เลือก/พิมพ์เอง + ราคาเองบล็อก "+ OPTION ทางเลือกลูกค้า": เลือกหมวด (กระจก/มุ้ง/สี/มือจับ/หลังคา/อื่นๆ) → เลือกรายการ preset หรือพิมพ์เอง + กรอก ±ราคาเอง → ออกใบ "OPTION : {ข้อความ} (ราคา ±N)" · ระบบเติม "OPTION :" หัวบรรทัดเอง (ผู้ใช้ไม่พิมพ์) · ใส่หลายตัวได้
หมายเหตุ: ดราฟ interactive โชว์ครบทั้ง 3 (กดดินสอ → แก้ข้อความ/เพิ่มบรรทัด/แก้ราคา · OPTION dropdown+พิมพ์เอง+ราคา) — ให้ดูเป็นต้นแบบ UX
