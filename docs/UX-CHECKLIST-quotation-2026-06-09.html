หมายเหตุ: เครื่องคำนวณถูก 100% แล้ว (ดู TEST-REPORT) · รายการนี้คือ UX + ข้อมูล + คู่มือ ไม่บล็อก deploy แต่ช่วยให้ใช้งานง่าย/กันกรอกผิด · ใช้ ข้อความค้นหา หาจุดแก้ (เลขบรรทัดขยับ) · เรียงตามความสำคัญ P1→P4

P1 — ทำเลย (เล็ก + กันพลาด/กันงง) 2 จุด

1. สีกรอบมุ้ง addon เปลี่ยนแล้วราคาไม่รีเฟรช (BUG-001) 🔴

ปัญหา
เลือกสีกรอบมุ้งใน addon ต่อบาน แล้วราคาไม่อัพเดท ต้องกด field อื่นก่อน (select ขาด event)
แก้
  • ค้น o-mosqcolor → เติม onchange="calcQuote()" ใน select นั้น (1 attribute)

2. ลบ dead code "ปิดปลาย" ในใบเสนอราคา 🟢

ปัญหา
ตัดตัวเลือก "ปิดปลาย" auto ออกแล้ว แต่ยังมี if(_rfend==='ปิดปลาย') ค้างใน buildQuoteDoc (value ไม่มีทางมาแล้ว)
แก้
  • ค้น _rfend === 'ปิดปลาย' → ลบ branch นั้นทิ้ง

P2 — UX สำคัญ (กันกรอกผิด/เข้าใจผิดราคา) 🔴 5 จุด

3. ราวกันตก กรอก "ความยาว" ในช่องที่ป้ายว่า "กว้าง" 🔴

ปัญหา
imp1-6 (method per_length_tier) อ่านความยาวจากช่อง "กว้าง" → ผู้ใช้ใหม่กรอกความกว้างราว ราคาเพี้ยนทันที
แก้
  • ค้น per_length_tier → เปลี่ยน label ช่องแรกเป็น "ความยาว (ม.)" + ซ่อนช่อง "สูง" สำหรับสินค้ากลุ่มนี้

4. ครอบท่อ PVC / ปิดซ่อนรางน้ำ — ช่องกว้าง×สูง ไม่ตรงความหมาย 🔴

ปัญหา
ครอบ PVC ใช้ช่อง "กว้าง" เป็นจำนวนท่อน · ช่อง "สูง" ไม่มีผล แต่ยังโชว์ → งงว่ากรอกอะไร
แก้
  • ค้น pvc_cover / gutter_cover → โชว์ช่องเดียว + ป้าย "จำนวนท่อน (1.5 ม./ท่อน)" หรือ hint อธิบาย W,H

5. โช้คบานเปิด — ยูโร (dropdown) กับ X-series (checkbox) ไม่เหมือนกัน 🔴

ปัญหา
สินค้าเดียวกันแต่ UI โช้คคนละแบบ → switch รุ่นแล้วงงว่าโช้คอยู่ไหน
แก้
  • ค้น o-closer + casement_xseries → รวมรูปแบบให้เหมือนกัน (เลือกแนวเดียว)

6. หน้าสรุปยอด (summary box) ไม่โชว์ VAT/ยอดรวมจริง 🔴

ปัญหา
เลือก VAT 7% แต่หน้าหลักโชว์ "(ก่อน VAT)" → ต้อง preview ก่อนถึงเห็นยอดที่คุยกับลูกค้า
แก้
  • ค้น ก่อน VAT / .sum → เพิ่มบรรทัด "VAT 7%" + "รวมทั้งสิ้น (รวม VAT)" ใน summary box เมื่อ vatPct>0

7. แท็บ "คิดเร็ว" ไม่บอกว่าใช้กระจก/สีอะไรคำนวณ 🔴

ปัญหา
คิดด้วยกระจกใส 6มม.+สีมาตรฐาน (index 0) แต่ไม่แจ้ง → อาจยกราคาให้ลูกค้าโดยไม่รวมกระจกพิเศษ
แก้
  • ค้น readQuickItem → เพิ่มหมายเหตุใต้ยอด "ราคานี้ใช้กระจกใส 6มม. สีมาตรฐาน"

P3 — UX ปานกลาง 🟡 7 จุด

8-14. รายการ 🟡 (รวม)

  • resetQuote ("ล้างทั้งหมด") ล้างไม่ครบ — ค้น resetQuote → เพิ่มล้าง custAddress/custContact/custPhone/sellerName/qdate/svc-*
  • ช่องผู้ขาย (Sales) ซ่อนใน accordion ส่งได้โดยไม่เตือน → ดึงออกมานอก หรือบังคับเลือก
  • ระบบสีมุ้ง 2 แบบไม่ตรงกัน — สินค้าใช้ดัชนีเลข (o-mscolor) / addon ใช้คีย์ข้อความ (o-mosqcolor) → รวมเป็นดัชนีเดียว
  • ม่านซิป / เมทัลชีท ป้ายออปชั่นไม่บอกราคา-หน่วย → เพิ่ม hint สั้นๆ (เช่น "ผ้า ~xxx บ./ตร.ม.")
  • ปุ่ม "+ กั้นห้องกระจก" ไม่มีคำอธิบายบนมือถือ → เพิ่ม hint ใต้ปุ่ม 1 บรรทัด
  • Protection พื้น default ติ๊ก แต่ยอดไม่บวกจนกด calc → เรียก calcQuote() ตอนโหลดหน้า (DOMContentLoaded)
  • ส่วนลด% เงื่อนไข <50,000 ลดไม่ได้ ไม่บอกล่วงหน้า · AWN twin ไม่ auto-fill บาน=2 → เพิ่ม hint/auto

P4 — ข้อมูล / คู่มือ 5 จุด

15-19. ข้อมูล + คู่มือ (รวม)

  • คู่มือผิด: กั้นห้องกระจก เขียน "กรอกราคาเหมาเอง" แต่โค้ดคิดจากบานย่อยรวมกัน → แก้คู่มือ คู่มือ/คู่มือกรอกใบเสนอราคา.html แก้
  • สินค้า "ยกเลิกขาย" 5 ตัว (E-series, aluinch×3, D-series) ยังโผล่ใน dropdown → ค้น ยกเลิกขาย → disable หรือ filter ออก เช็ค
  • คู่มือไม่มีค่าบริการ/ค่าติดตั้งม่านซิป (jobServices + 5,000+600/ตร.ม.) → เพิ่มหัวข้ออธิบาย เพิ่ม
  • mj_sd_sahara มีเป็นสินค้าแต่ไม่มีใน addon ต่อบาน → ตัดสินใจว่าต้องการไหม เช็ค
  • กระจกโค้ง margin ต่ำ (★ ใสดัดโค้ง 10มม. ทุน 6,750/ขาย+8,550) → ยืนยันราคากับพี่นัท เช็ค
