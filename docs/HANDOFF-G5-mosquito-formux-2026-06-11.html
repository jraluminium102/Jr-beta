1) ลำดับฟอร์มมุ้งใหม่ (บนลงล่าง)

  1. ติดมุ้งบานเดิม (โหมด B) o-screen_existing + ค่าเสริมกล่อง/ราง o-screen_extra — กล่องส้มเด่น บนสุด
  2. แบบ (เลือกสินค้า) + ขนาด กว้าง×สูง + จำนวนบาน/ชุด — หลัก ทุกสินค้า
  3. ประเภท i-type — ชิป ประตู/หน้าต่าง (มีผลต่อ min) ชิปแล้ว
  4. ผ้ามุ้ง + สีผ้า — ชิปหลัก เห็นทันที (เฉพาะ screen_addon = imp21/22/23)
  5. ครอบวงกบอลู o-fcsides — ชิป ชิปแล้ว
  6. accordion อุปกรณ์เสริม → สีกรอบมุ้ง (12) + หมายเหตุ (18) — คง dropdown

ตัดหายทั้งหมดจากมุ้ง: กระจก (i-glass-wrap) · สีอลู (i-color-wrap) · คาดตาราง (o-gridmark)
