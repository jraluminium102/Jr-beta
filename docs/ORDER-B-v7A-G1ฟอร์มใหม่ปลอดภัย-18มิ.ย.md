## 1. คาดตาราง — ขึ้นใต้มุ้ง (ออกจากกล่องพับ)
ย้าย control คาดตารางขึ้นเป็นออปชั่นหลัก ใต้มุ้ง (ของใช้บ่อย) · แค่ลำดับ section

## 2. มือจับ → "ล็อค" (ไม่มี / มีล็อค / มีล็อค+กุญแจ)
- เปลี่ยนหัวข้อ "มือจับ" → "ล็อค" 3 ตัวเลือก (ชิป)
- มือจับแบบละเอียด (สแตนเลส/HYDA/Metro/ดิจิตอล) → ย้ายไปกล่อง "OPTION ทางเลือกลูกค้า" (oc-block)
- ⚠ ไม่แตะราคา/logic มือจับเดิม — แค่ย้ายที่ + เปลี่ยน label

## 3. ขนาด — สลับลำดับ
กว้าง / สูง / **จำนวนบาน / ชุด** (บานมาก่อนชุด)

## 4. ของไม่บ่อย → กล่องพับ "อุปกรณ์เสริม"
ครอบวงกบ(ทั้งชุด) / ฝังรางยู / ดรอปพื้น / ธรณี / เสริมคาน / รื้อ → ยุบกล่องพับ (default ปิด)

## 5. ใบ 5 บล็อก เก็บหัว (`itemDetail` L5069 · `_g1FB`)
- เอา "มุ้ง + ขนาด" ออกจาก `prodName`: จุดเติม non-sliding L5176-5184 (`prodName += _mosqNm+_mqDim`) + บานเลื่อน `_mosqStr`/`_mqDim` ใน `_slideName` L5155-5168 (ขนาดใส่ผ่าน `_qSz` ครั้งเดียวแล้ว)
- **เพิ่มบานหลักเป็นบรรทัดแรกของ `_g1Work`** (บานเปิด/บานเลื่อนรางล่าง/กระจกติดตาย) — ตอนนี้รายการมีแต่มุ้ง/คาดตาราง ไม่มีตัวบาน
- **ไม่เพิ่มบานหลักซ้ำ** (หัวบอกแล้ว · พี่นัทย้ำ)

## 6. 3 จุดเคาะใบ (พี่นัทเลือกแล้ว)
- ก = หัวข้อบล็อกล่าง = **"รายละเอียด"** (สั้น)
- ข = **ใส่ขนาดในหัว**
- ค = สีอบพิเศษ **รหัสเดียว** (`.i-colorcode` รับรหัส/ชื่อสีอยู่แล้ว)

## 7. ผนังเบาสเปกเต็ม (`wall_ext`/`wall_int` · registry #8)
- **ภายนอก (wall_ext):** "ผนังสมาร์ทบอร์ดพร้อมฉนวนกันร้อนกันเสียง โครงเหล็กชุบซิงค์(ไร้สนิม) 1.2 มม. พร้อมโครงคร่าวซี-ไลน์เสริมแรง"
- **ภายใน (wall_int):** "ผนังยิปซั่มพร้อมฉนวนกันร้อนกันเสียง โครงคร่าวซี-ไลน์เสริมแรง" ← **ยิปซั่ม ไม่ใช่สมาร์ทบอร์ด**
