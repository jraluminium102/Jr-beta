## 🎯 รวมเข้า "ออกแบบระบบปุ่ม/ออปชั่นใหม่ทั้งหมด" (มติพี่นัท 17 มิ.ย.)
> หลักการ: **แบนที่สุด · ไม่ซ่อนลึก · ไม่เอาหลายดรอปดาวน์ · ออกแบบปุ่มใหม่** (เหมือนหลัก flatten ในสกิล form-ux) · งานนี้ "รอใบสั่งรวบรอบเดียว" ห้ามแก้แยกย่อย

ของที่ต้องเก็บกวาดตอน redesign (เจอในรอบ 17 มิ.ย.):
1. **Label เป็นศัพท์ dev / กำกวม** → ตั้งชื่อใหม่ให้คนเข้าใจ:
   - `o-closer` label จริง = "[Up3] โช๊ค (combo สแตน)" → "โช้คอัพประตู"
   - `o-awn_mode` = "แบบเปิด" → "ลักษณะการเปิด" · `o-bsdoor` = "ค่าประตู (เลือกรุ่น)" → "ทำเป็นบาน" · `o-finish` = "ผิว/สี ระแนง" · `o-wallmodel` = "รุ่น/ความหนา"
2. **ชิป/ออปชั่นชื่อยาว** → ย่อ: "เวเทอร์บล็อค ตราช้าง 9 มม. (ฟอยล์ กันร้อน/น้ำ/รา)", "บานเปิด D-series (ยกเลิกขาย)"
3. **ซ่อนลึก (ปุ่มซ้อนปุ่ม/accordion)** → ดันขึ้นจอเดียว: มือจับ multi-toggle (sub Cmech/digital/stainless/xseries ซ้อนใน toggle) · กล่อง "อุปกรณ์เสริม/ออปชั่น" ที่ยังพับลึก
4. **ดรอปดาวน์ที่ยังเหลือ** (พิจารณาในดีไซน์ใหม่): `o-mosq` (มุ้งต่อบาน 15 · **พี่นัทชี้เอง 17มิ.ย. full mode** — คิดเร็วเป็น drill-down ชิปแล้ว ควรยกแบบเดียวกันมา full mode), `i-color` (13 สี), `i-glass` (66 กระจก), `o-remark-add` (หมายเหตุ — กำลังทำติ๊กแยก [[remark-preset-tick]]), G7 ม่านซิป (o-zctrl/zmodel/zgrp) · ของพวกนี้เยอะ → ต้องคิด pattern ใหม่ (ค้นหา/หมวด/การ์ด/drill-down) ไม่ใช่ดรอปดาวน์ยาว
5. **ออปชั่นย่อยอื่นๆ ที่ยัง dropdown >7** (o-cmechawn 8 / o-cmechcolor 7 / o-digi / o-stainless) → ดีไซน์ใหม่ด้วย
