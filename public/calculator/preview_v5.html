สิ่งที่ยังต้อง flag — รอพี่นัทตัดสิน

1. series tag ตำแหน่งตอนนี้ใส่ท้ายชื่อสินค้า เช่น "บานเลื่อน เซมิยูโร (รุ่นM เซมิยูโร)" — อยากให้อยู่ในวงเล็บหัวรายการแทนไหม เช่น "หน้าต่างชั้น 1 (รุ่นM เซมิยูโร)"?
2. series tag หัวรายการใบจริงปีเตอร์ใช้ "(ชุดยูโร)" — ตอนนี้ agent ใส่ "(รุ่นL ยูโร)" ตาม spec พี่นัท — ยืนยันใช้รูปแบบนี้ได้เลย?
3. ราคา folding_euroตั้ง unit_rate=9000 เท่า folding เซมิยูโร ตาม spec "ราคาเท่า M" — ยืนยันถูกต้อง?
4. สีอลูมิเนียม defaultถ้าผู้ใช้ไม่เลือกสี (index 0 = สีอบขาว) จะโชว์ "อลูมิเนียม สีอบขาว" — ถ้าต้องการ default เป็นสีดำ ต้องปรับ default index
5. awning_aluinchยังไม่ได้ใส่ (ยกเลิกขาย) — รอยืนยันว่า aluinch กระทุ้งยกเลิกด้วยหรือเปล่า (pivot_aluinch + sliding_eseries + lift_aluinch ใส่แล้ว)
6. หมายเหตุท้ายใบ M/Lspec ข้อ 10 ให้เพิ่มข้อความ "เฟรมเซมิยูโร (M) และ ยูโร (L) แข็งแรงเทียบเท่า..." — ยืนยันตำแหน่ง (ก่อนลายเซ็น? หลังตาราง?)
