สรุปคำสั่ง/เทคนิคที่ใช้ได้จริง · เรียงตามที่พี่นัทใช้บ่อย

⭐ /goal — คำสั่งที่พี่นัทชอบ (ตั้งเป้า ทำจนจบ)

/goal <เป้าหมาย>ตั้งเป้า → Claude ทำจนสำเร็จเอง ไม่หยุดกลางคัน (มี Stop hook กันหยุดจนกว่าจะเสร็จ) · เคลียร์เองเมื่อจบ
/goal clearยกเลิกเป้าก่อนกำหนด (ปกติไม่ต้องใช้ มันเคลียร์เองตอนสำเร็จ)
เคล็ดเขียนเป้าให้ดี: บอก "ทำอะไร + เสร็จแบบไหนถึงเรียกว่าจบ + ห้ามอะไร" เช่น "รวม 2 repo, build ผ่าน, push ขึ้น repo X, ห้ามแก้ DB" — ยิ่งระบุเงื่อนไขจบชัด ยิ่งทำได้ตรง

🧠 วางแผนก่อนลงมือ (Plan Mode)

  • กด Shift+Tab หรือพิมพ์ "วางแผนก่อน อย่าเพิ่งแก้"
  • Claude อ่านโค้ด+เสนอแผน ให้พี่นัทอนุมัติก่อนทำจริง
  • เหมาะกับงานใหญ่/เสี่ยง — กันทำผิดทาง

👥 Subagent — แตกทีมช่วยกัน

  • พิมพ์ "spawn subagent 5 ตัวมาช่วยเทส..." → ทำงานขนานกัน เร็วขึ้นมาก
  • เหมาะกับ: เทสหลายส่วน, ค้นหาหลายที่, ตรวจหลายมุมพร้อมกัน
  • เก็บทีมไว้ในโปรเจกต์ได้ที่ .claude/agents/ (เช่น accountant, qa-tester)

✅ "Crosscheck" = เทคนิค (ไม่ใช่คำสั่ง)

  • ให้ ข้อมูลจริง (เช่น ใบเสนอราคาจริง) แล้วสั่ง "เทียบผลคำนวณกับใบนี้ทีละเคส"
  • Claude คำนวณอิสระแล้วเทียบ → จับเลขผิดได้แม่น
  • คำที่ช่วย: "verify", "เทียบกับของจริง", "ตรวจซ้ำก่อนสรุป"

🔁 คำสั่ง/skill อื่นที่ควรรู้

/loop <งาน>ทำงานซ้ำเป็นรอบ (เช็คสถานะทุก X นาที)
/verifyรันแอพจริง ดูว่าฟีเจอร์ทำงานไหม
/code-reviewตรวจโค้ดที่เพิ่งแก้ หาบั๊ก/จุดปรับ
/security-reviewตรวจช่องโหว่ความปลอดภัย
/scheduleตั้งงานอัตโนมัติตามเวลา (cron)

🚀 6 เคล็ดให้งานออกมาเร็ว+ดีแบบที่ผ่านมา

1. เป้าชัด + เงื่อนไขจบใช้ /goal บอกให้รู้ว่า "เสร็จ" หน้าตาเป็นไง (build ผ่าน / push แล้ว / เทสเขียว)
2. ให้ของจริงเทียบแนบใบจริง/ตัวอย่าง/รูป → ได้ crosscheck แม่น (เหมือนรูป VAT ที่พี่นัทส่ง)
3. สั่งให้ verify เอง"รันเทส/build/ดูผลก่อนบอกว่าเสร็จ" — กันงานหลอกว่าเสร็จ
4. แตก subagentงานใหญ่หลายส่วน → ขนานกัน เร็วกว่าทำทีละอย่าง
5. ทำทีละเฟส + commit"ทำเสร็จแต่ละส่วนแล้ว commit" — ย้อนกลับง่าย เห็นความคืบหน้า
6. ถามเมื่อไม่ชัวร์เรื่องเงิน/ธุรกิจ Claude จะถามก่อน ไม่เดา — ตอบสั้นๆ พอ
เกร็ด: แยกชื่อคนเวลา commit ได้ด้วย git as-nut / git as-manao (ตั้งไว้แล้วในโปรเจกต์ jr-beta) · Claude จำเรื่องโปรเจกต์ข้ามรอบได้ผ่าน CLAUDE.md + memory — บอก "จำไว้ว่า..." ได้เลย
